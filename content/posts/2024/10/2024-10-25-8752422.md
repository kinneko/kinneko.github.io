　LED付いているので、まずはLチカからかなと思って、サンプルスケッチをビルドしてみたのだけど、なんか素直にそのままビルドはできなかった。うーむ。

　ボードマネージャー側は、以前はPico用が分かれていたようだけど、いまはPicoだといっても特別なものはない。Arduino ESP32の中に、ATOMも入っている。なので、普段ESP32を使っているのであれば、とくにやることはない。

　ライブラリマネージャーではM5ATOMを入れる。このへん、最近はユニファイドで吸収されているのだろうか？

![](/2024-10-25/8752422-01.png)

　ATOM_DTU_CAT1に依存しているようだけど、これなんだろう？ あとで調べることにして、Install allを押す。

![](/2024-10-25/8752422-02.png)

　これらしい。SIMcomのSIMA7680C用らしい。こんなの依存しなくても良さそうなのに。

> GitHub - m5stack/ATOM_DTU_CAT1<br>

　サンプルスケッチはわりと充実している。

![](/2024-10-25/8752422-03.png)

　Basics -> LEDSetを選ぶ。

　このスケッチは、LITEやMatrixで、ボタンを押すとLEDの色を変えるサンプル。コメントが中国語なので日本語にしておく。

```text
/*
*******************************************************************************
* Copyright (c) 2021 by M5Stack
*                  Atom-Lite/Matrix用のサンプルソースコード
*                  Atom-Lite/Matrix配布用のサンプルソースコード
* 詳細は次のサイトをご覧ください: https://docs.m5stack.com/en/core/atom_matrix
* 詳細は次のサイトをご覧ください：https://docs.m5stack.com/zh_CN/core/atom_matrix
*
* 説明: RGB LEDの点灯例
* 日付: 2021/7/21
*******************************************************************************
*/
#include "M5Atom.h"

/* Atom-Matrixが起動またはリセットされた後
setup()関数内のプログラムが実行され、この部分は1回しか実行されません */
void setup() {
    M5.begin(true, false,
             true);  // Atom-Matrixの初期化（シリアルポート、LEDの初期化）
    delay(50);                    // 50ms待ち
    M5.dis.drawpix(0, 0x00ff00);  // 指定したRGBカラー00ff00でLEDを点灯（Atom-Matrixは1つのLEDのみを持つ）
}

uint8_t FSM = 0;  // ボタンが押された回数を記録する

/* setup()関数内のプログラムが実行された後は、loop()関数内のプログラムが実行され続けます
loop()関数は無限ループで、その中のプログラムは繰り返し実行されます */
void loop() {
    if (M5.Btn.wasPressed()) {  // ボタンが押されたかどうかを確認
        switch (FSM) {
            case 0:
                M5.dis.drawpix(0, 0xfff000);  // 黄色
                break;
            case 1:
                M5.dis.drawpix(0, 0xff0000);  // 赤色
                break;
            case 2:
                M5.dis.drawpix(0, 0x0000f0);  // 青色
                break;
            case 3:
                M5.dis.drawpix(0, 0x00ff00);  // 緑色
                break;
            default:
                break;
        }
        FSM++;  // 状態を更新（ボタンが押された回数を増加）
        if (FSM >= 4) {
            FSM = 0;  // 4回以上押された場合、カウントをリセット
        }
    }

    delay(50);  // 50ms待ち
    M5.update();  // ボタンの押下状態を更新
}
```

　スケッチからすると、Matrixとの違いはLEDの数なのかな？ なんか１個ずつ変えられたような気もするけど。

　そのままビルドして書き込む。

　通電すると、ボタンを押すとボタンの下のLEDが赤緑青白と変わるようなスケッチが書き込まれている。
