　送信データは28bitなので、不足分の先頭は0が補完する。受信データは34bitなのだけど、ライブラリは32bitまでしか扱えない感じ。32bitで送ってみる。

```text
void loop() {
  StickCP2.update();
  if (StickCP2.BtnA.wasPressed()) {
    // フロントボタンでLEDの電源ONを送信する
    uint64_t code64 = 0x1FE48B7; // ONのデータ
    uint16_t bits = 32; // ビット数
    uint32_t code = (uint32_t)code64; // 下位32ビットを取得
    // プロトコル、コード、ビット数、バースト回数、リピート回数
    sendIR(NEC, code, bits, 1, 1);
    Serial.printf("送信したNECコード: %#llx, ビット数: %d\n", code64, bits);
    delay(1000); // 送信後1秒待機
  }
}
```
