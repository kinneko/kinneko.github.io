　リモコンがわりにCPlus2を使うことはうまくいったのだけど、このままだと不便という点はどうしようもない感じ。ボタンないしね。

　とはいっても、M5Stick C Plus2ではボタンの数が絶対的にない。最大でも３つになる。外付けのボタンユニットもあまりボタン数があるものはないのだった。キーボードユニットとかつけるといいのかもしれない。IRリモコンなので、装置側のステイトを取得することができないので、ONだたtらOFFを送るというようなこともできない。

　しかたがないので、REST APIでアクセスする方式に変更しよう。

　ボタンAでの画面リセットはもとにもどしておく。

　まず、無線接続をするようにスケッチを追記。こんな感じでいいかな。

```text
#include <WiFi.h>
// Wi-Fi credential configuration omitted

void setup() {
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print("."); }
  Serial.println("");
  Serial.println("WiFi connected");
  Serial.print("IP address: ");
  Serial.println(WiFi.localIP());
}
```

　書き込んでシリアルのログを見る。つながっているようだ。


　Webサーバーを追加する。とりあえず、ON/OFFできればいいかな。

```text
#include <WebServer.h>

WiFiServer server(80);

struct IRCode {
  uint64_t code;
  uint16_t bits;
};

IRCode irCodes[] = {
  {0x1FE48B7, 32}, //ON
  {0x1FE58A7, 32}, //OFF
};

void setupServer() {
  server.on("/send_ir", handleIRSend);
  server.begin();
  Serial.println("HTTP server started");
}

void setup() {
  setupServer();
}

void handleIRSend() {
  if (server.hasArg("code")) {
    int codeIndex = server.arg("code").toInt();
    if (codeIndex >= 0 && codeIndex < (sizeof(irCodes)/sizeof(irCodes[0]))) {
      uint64_t code = irCodes[codeIndex].code;
      uint16_t bits = irCodes[codeIndex].bits;
      sendIR(NEC, code, bits, 1, 1);
      server.send(200, "text/plain", "IR code sent.");
      Serial.printf("送信したNECコード: %#llx, ビット数: %d\n", code, bits);
    } else {
      server.send(400, "text/plain", "Invalid code index.");
    }
  } else {
    server.send(400, "text/plain", "No code index provided.");
  }
}

void loop() {
  server.handleClient();
}
```

　書き込む。起動してきた。

```text
11:40:44.302 -> WiFi connected
11:40:44.302 -> IP address: 192.168.0.2
11:40:44.302 -> HTTP server started
```

　テストする。code=0でLEDが点灯、code=1で消灯した。
