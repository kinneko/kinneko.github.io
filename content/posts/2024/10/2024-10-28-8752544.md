　さて、買ったATOM Liteだけど、ボタンの押しごこちはいいので、なんかに使えないかと考えてみる。

　ポテチを食べながら、Xのタイムラインを読むのに下カーソルボタンにするのがよさげだな。電池ないけど、そこはまぁいいか。充電しないと使えないのだけど、使おうとして電池切れているとムキーってなるしね。充電するまで使えないし。

　Arduinoでは、下カーソルキーのキーコードは、0x91かKEY_DOWN_ARROWで、普通は、Keyboard.write(KEY_DOWN_ARROW)という感じらしい。

　便利なBLE keyboardのライブラリを作ってくれている人がいるので、それをそのまま使うことにする。この界隈では定番らしい。

> ESP32 BLE Keyboard library<br>
> <https://github.com/T-vK/ESP32-BLE-Keyboard>

　残念なことに、ライブラリマネージャー経由ではインストールできないので、手動インストールになる。プロジェクトからzipファイルESP32-BLE-Keyboard-master.zipをダウンロードする。

　ArduinoIDEのメニューで、スケッチ -> ライブラリをインクルード -> zip形式のライブラリをインストールでESP32-BLE-Keyboard-master.zipを選択する。

　インストールが終わったら、入っているのを確認する。

![](/2024-10-28/8752544-01.png)

　スケッチはこんな感じでいいかな？ 認識するキーボード名を決めて、BLEで接続していれば、ボタンを押したときに下カーソルキーのイベントを送る。ディレイは最小限にしたけど、だめなら伸ばす感じ。LEDはボタンの下でどうせ見えないし、コンソールメッセージもなし。ダメだったら考える。

```text
#include <M5Atom.h>
#include <BleKeyboard.h>
BleKeyboard bleKeyboard("XDownCursor");

void setup() {
  M5.begin(true, false, true);
  bleKeyboard.begin();
}

void loop() {
  if (bleKeyboard.isConnected()) {
    if (M5.Btn.isPressed()) {
      bleKeyboard.write(KEY_DOWN_ARROW);
    }
  }
  delay(50);
  M5.update();
}
```

　再ビルドで通った。

　macOSでペアリング。キーボード自動判定のためにキーを押せ的なダイアログが出るけど、閉じる。

![](/2024-10-28/8752544-02.png)

　普通に使えるな... つまらん。ディレイを小さくしたおかげか、普通に押しっぱなしのキーリピートで連続スクロールもできる。

　これで、Xのタイムライン消化が少しは楽になるかな？

　本体のボタンを押しすぎると、ボタンだけ壊れる可能性もあって面倒なので、ボタンは外にしたほうがいいかもしれない。

　あと、ボタンのLEDつけてないというのに、ボタンのところが熱いのよね。というわけで常用は無理かも。

　PCのそばで使ってみると、2.4GHzのWiFiが妙に遅い。同じ周波数のBLEとはいえ、これは、やっぱダメかも。
