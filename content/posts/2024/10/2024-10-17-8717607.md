　なかなか面白そうなものがGAされていた。管理コンソールでの操作をCFnに吐き出すことができるらしい。やってみる。

> 　　Convert AWS console actions to reusable code with AWS Console-to-Code, now generally available | AWS News Blog<br>
> <https://aws.amazon.com/jp/blogs/aws/convert-aws-console-actions-to-reusable-code-with-aws-console-to-code-now-generally-available/>

　10/15現在では、わたしの持っているアカウントではメニューに出てこないので使えないのかな？ 対応しているサービスは、VPC, EC2, RDSだけ。まだまだ使い物にはならないな...

　EC2の管理コンソールでリロードしたら出てきた。

![](/2024-10-17/8717607-01.png)

　Amazon Qのアイコンの下に出ているコンソールに矢印出ているようなアイコン。これが、AWS Console-to-Codeウィジェット。

![](/2024-10-17/8717607-02.png)

　クリックすると、こんなのが開く。記録を開始して、普通にEC2のオペレーションを実行する。

![](/2024-10-17/8717607-03.png)

　『無料利用枠の上限を超えた後にコードを生成するには、Amazon Q Developer Pro サブスクリプションが必要です。』とあるので、限定的に無料のサービスだった。このくらい無料で出せばいいのになぁ...

　「記録を開始」ボタンを押すと、「記録が進行中」という画面に変わる。

![](/2024-10-17/8717607-04.png)

　EC2とRDSでは、作成した過程をコード化できるという機能なのだけど、VPCは実際にVPCを作成しなくても「Preview Code」でConsole-to-Codeが使えるそうな。なんで、全部そうならないかな...

![](/2024-10-17/8717607-05.png)

　停止ボタンを押す。

![](/2024-10-17/8717607-06.png)

　アウトプットする項目にチェックを入れる。

![](/2024-10-17/8717607-07.png)

　CLIをコピーすると、こんなのがコピーされた。

````text
aws ec2 create-key-pair --key-name "Console-to-Code" --key-type "ed25519" --key-format "pem"
aws ec2 create-security-group --group-name "launch-wizard-4" --description "launch-wizard-4 created 2024-10-15T08:01:38.963Z" --vpc-id "vpc-0ef1a46da4e9bb897"
aws ec2 authorize-security-group-ingress --group-id "sg-04227b830f9e7bcf6" --ip-permissions '{"IpProtocol":"tcp","FromPort":22,"ToPort":22,"IpRanges":[{"CidrIp":"0.0.0.0/0"}]}'
aws ec2 run-instances --image-id "ami-0b20f552f63953f0e" --instance-type "t2.micro" --key-name "Console-to-Code" --block-device-mappings '{"DeviceName":"/dev/sda1","Ebs":{"Encrypted":false,"DeleteOnTermination":true,"Iops":3000,"SnapshotId":"snap-0164a96d4eb5bbc49","VolumeSize":8,"VolumeType":"gp3","Throughput":125}}' --network-interfaces '{"AssociatePublicIpAddress":true,"DeviceIndex":0,"Groups":["sg-04227b830f9e7bcf6"]}' --credit-specification '{"CpuCredits":"standard"}' --tag-specifications '{"ResourceType":"instance","Tags":[{"Key":"Name","Value":"Console-to-Code"}]}' --metadata-options '{"HttpEndpoint":"enabled","HttpPutResponseHopLimit":2,"HttpTokens":"required"}' --private-dns-name-options '{"HostnameType":"ip-name","EnableResourceNameDnsARecord":true,"EnableResourceNameDnsAAAARecord":false}' --count "1"
````

　ほかにも、CFnのYAMLやCDKに対応したコードを吐き出すことができる。

![](/2024-10-17/8717607-08.png)

　Pythonを選ぶとこんな感じになった。コピーだけでなく、ダウンロードができる。

![](/2024-10-17/8717607-09.png)

　下にはこんなアラートが表示された。なんかめんどくさいね。

![](/2024-10-17/8717607-10.png)

　コードを生成するには、Console-to-Code では、この AWS アカウント内でクロスリージョン呼び出しを実行することについてのお客様の同意が必要です。Console-to-Code の設定でクロスリージョンの詳細設定を更新できます。

　リセットを押すと、こんなダイアログが出た。

![](/2024-10-17/8717607-11.png)

　EC2の画面によっては記録がうまくできないものもある感じ。ちょっと、まだまだだね。
