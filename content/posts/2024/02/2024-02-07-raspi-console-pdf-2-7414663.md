　パッケージはbusterというだいぶ古いディストリビューションに対応したものしかなかったが、インストールはできたようだ。動作確認をやってゆく。

　ヘルプを表示してみる。実行は問題なさそう。

```text
kinneko@raspberrypi:~ $ jfbview --help

jfbview 0.6.0

Usage: jfbview [OPTIONS] FILE

Options:
	--help, -h            Show this message.
	--fb=/path/to/dev     Specify output framebuffer device.
	--password=xx, -P xx  Unlock PDF document with the given password.
	--page=N, -p N        Open page N on start up.
	--zoom=N, -z N        Set initial zoom to N. E.g., -z 150 sets
	                      zoom level to 150%.
	--zoom_to_fit         Start in automatic zoom-to-fit mode.
	--zoom_to_width       Start in automatic zoom-to-width mode.
	--rotation=N, -r N    Set initial rotation to N degrees clockwise.
	--color_mode=invert, -c invert
	                      Start in inverted color mode.
	--color_mode=sepia, -c sepia
	                      Start in sepia color mode.
	--format=image, -f image
	                      Forces the program to treat the input file as an
	                      image.
	--format=pdf, -f pdf  Forces the program to treat the input file as a
	                      PDF document. Use this if your PDF file does not
	                      end in ".pdf" (case is ignored).
	--cache_size=N        Cache at most N pages. If you have an older
	                      machine with limited RAM, or if you are loading
	                      huge documents, or if you just want to reduce
	                      memory usage, you might want to set this to a
	                      smaller number.

jfbview home page: https://github.com/jichu4n/jfbview
Bug reports & suggestions: https://github.com/jichu4n/jfbview/issues
```

　起動オプションなどを調べる。

　jfbviewのmanファイルはこれ。 (htmlpreview.github.ioって便利ねw)

> <https://htmlpreview.github.io/?https://github.com/jichu4n/jfbview/blob/master/doc/jfbview.1.html>

　表示テストに使うPDFを用意する。

　ちょっとサイズが大きいカラーのデータで、日本語ファイル名と日本語文字表示のものにしてみる。コンテンツの中身は特殊なフォントを使っていて、画像化はしていない。そして、macOSの機能で作った意地悪系のPDFだ。

　scpでRaspiにコピーしておく。

```text
kinneko@raspberrypi:~ $ ls -alh SecJAWS資料案d.pdf
-rw-r--r-- 1 kinneko kinneko 101M Feb  5 18:18 SecJAWS資料案d.pdf
```

　とりあえず、オプションは何も指定しないで表示してみる。

```text
kinneko@raspberrypi:~ $ jfbview SecJAWS資料案d.pdf
```

　HDMI側に表示された。なんか、フォントも日本語も問題なくて拍子抜けじゃん...

![](/2024-02-07/7414663-01.png)

　使用するフレームバッファは１つしかないので、明示で指定する必要はないようだ。

　起動したコンソールはブラックアウトした。起動したsshコンソールのほうで、qを押すと終了した。リモートからの制御もできそうでいい。

　上下カーソルでページが切り替わる。ページのロードには三秒程度かかる。ちょっとかかりすぎかな... 一度表示してレンダリング済みのデータがキャッシュに入っていれば表示は早い。メモリに制限のある環境では、キャッシュサイズは「--cache_size」オプションで指定できる。

　A5の薄い本のデータを表示してみたら、画面が切れた。

![](/2024-02-07/7414663-02.png)

　オプションの「--zoom_to_fit」を試す。

![](/2024-02-07/7414663-03.png)

　レンダリングのサイズが小さいのと、基本的に文字と小さい画像が中身の薄い本は、ページめくりの負荷があまりないのか、少しひっかかりがあるけれど、見るのに不都合のない速度で表示された。

　見にくいが左側中央左にチカチカするカーソルのようなものが表示されている。

![](/2024-02-07/7414663-04.png)

　見開きモードのオプションは持っていないようだ。

　オプションの一覧には、スクリーンのローテーションには対応するものは、--rotationってオプションがある。しかし、-r 90で指定してみたけど、真っ黒... 使えないっぽい。

![](/2024-02-07/7414663-05.png)

　Raspi側のフレームバッファをあらかじめ回転しておくというのはどうだろう？

　/boot/firmware/config.txt(以前は/boot/config.txtだった)を書き換えて、「display_hdmi_rotate=1」と90度回転（時計回り）の設定をしておく。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/firmware/config.txt
display_hdmi_rotate=1

kinneko@raspberrypi:~ $ sudo reboot
```

　あれ？ これは想定したのと違うわ...

![](/2024-02-07/7414663-06.png)

　最近は「/sys/class/graphics/fbcon/rotate_all」をさわる設定が正しいようだ。

```text
kinneko@raspberrypi:~ $ echo 1 > /sys/class/graphics/fbcon/rotate_all
-bash: /sys/class/graphics/fbcon/rotate_all: Permission denied
```

　あらら、エラーになった。ユーザーでは権限が足りていない。

　しょうがない。

```text
kinneko@raspberrypi:~ $ sudo su -
root@raspberrypi:~# echo 1 > /sys/class/graphics/fbcon/rotate_all
```

　表示が回った。

![](/2024-02-07/7414663-07.png)

　しかし、jfbviewで表示してみても、前と変わらない挙動になっている。ダメだな...

　jfbviewは直接フレームバッファを制御していて、fbconの設定は参照しないようだ。

　最終的な解としては、ディスプレイでポートレイトモードで表示するには、PDFのデータのほうで対応したものを用意する必要がありそう。

　というわけで、コンテンツのほうを横にして作っておかないとダメらしい。

　あらかじめ回転したPDFを用意する。

![](/2024-02-07/7414663-08.png)

　ただ起動すると表示が切れるな...

![](/2024-02-07/7414663-09.png)

　--zoom_to_fitするとうまく表示できた。
