　ネットワークごしに、ESP32のMicroPythonにアタッチできるのは便利なのだけど、DHCP環境で使っていると、割り当てIPアドレスが変わった場合にupydevからの到達が不便なので、mDNSで名前解決ができると便利だ。

　MicroPythonそのものでは、mDNSを扱うことはできないようだが、ライブラリを作ってくれている人がいた。

> cbrand/micropython-mdns: MDNS implementation for MicroPython with Service Discovery<br>
> <https://github.com/cbrand/micropython-mdns>

![](/2024-01-05/7250565-01.png)

　しかし、micropython-mdnsのドキュメントを読むと、v1.12以降のESP32実装のMicroPythonでは、mDNSの通知だけであれば、このライブラリを使う必要はないと書かれている。

　なるほど。標準サポートはうれしいね。しかし、そのようなドキュメントはどこにもない感じ... そういうとこだゾ...

> micropython/ports/esp32 at master · micropython/micropython<br>
> <https://github.com/micropython/micropython/tree/master/ports/esp32>

　探してみると、mDNSサポートについて少し書かれているWebサイトが見つかった。

> ESP32 WiFi Manager and mDNS | SeanD<br>
> <https://www.sdoherty.com/2020/02/esp32-wifi-manager-and-mdns.html>

　以下のようにすることでmDNSでのアナウンスができるようだ。

```text
wlan.config(dhcp_hostname = 'mydevicename')
```

　gistにサンプルもアップロードされている。

> MicroPython Wifi Manager & mDNS<br>
> <https://gist.github.com/deanstheory/699cd3d8a083b7356e0df2fc49873ef5>

```text
import network
import wifimgr
from config import device_config

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.config(dhcp_hostname = device_config['device_id'])

wlan = wifimgr.get_connection()
if wlan is None:
    print('Could not initialize the network connection')
    while True:
        pass

print('dhcp_hostname: {}'.format(wlan.config('dhcp_hostname')))
print('network config: ', wlan.ifconfig())
```

　さらに調べてみると、v1.16までは、固定値のEspressif.local.でのアナウンスが行われる仕様であったようだ。

　以前は固定IPで書いてあるので、このままmDNSアナウンスを追加してみる。

```text
esp32@upydevice:~ $ vim main.py
import network
import machine
import time
sta_if = network.WLAN(network.STA_IF)
sta_if.active(True)
sta_if.connect('MyPlace', 'XXXXXXXX')
ip = '192.168.0.132'
subnet = '255.255.255.0'
gateway = '192.168.0.1'
dns = '8.8.8.8'
sta_if.ifconfig((ip, subnet, gateway, dns))
sta_if.config(dhcp_hostname = 'mydevicename')
while not sta_if.isconnected():
    time.sleep(1)
print("Connected:", sta_if.isconnected())
print("Network config:", sta_if.ifconfig())
print('dhcp_hostname: {}'.format(sta_if.config('dhcp_hostname')))
```

　デフォルトのmDNS機能は諦めないとダメっぽい。

　ソースを見てみると、ESP32でのmDNSの実装は、espressif-idfのライブラリを呼んでいるだけのようなので、micropythonの中での問題ではなさそう。
