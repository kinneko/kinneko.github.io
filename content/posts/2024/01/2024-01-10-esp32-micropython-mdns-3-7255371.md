　ESP32向けのMicroPython実装に含まれている、mDNSでの名前引きというかIPアドレス解決は前回までにできた。

　とくに必要があって組み込みの機能ではできなかった固定IPでmDNSでのアナウンスをしたいわけではないのだけど、名前解決だけでなく、サービスアナウンスもしたいことがあるかもなので、micropython-mdnsを使ってみるか... ドキュメントにメモリ食いだと書かれているので、あんまり乗り気にはなれないのだけど。

　mipでは依存関係のあるライブラリのインストールは行われないようだ。micropython-mdnsのドキュメントには、uasyncioが必要と書かれている。それも入れる必要がある。

　uasyncioは、フットプリントの小さいPython互換環境であるPycopyのために書かれたライブラリであるpycopy-libに含まれている。CPythonの非同期IOライブラリのasyncioのMicroPython向けの再実装である。MicroPython用というわけではないようだ。

> pfalcon/pycopy-lib: Standard library of the Pycopy project, minimalist and light-weight Python language implementation<br>
> <https://github.com/pfalcon/pycopy-lib>

![](/2024-01-10/7255371-064.png)

> pycopy-lib/uasyncio at master · pfalcon/pycopy-lib<br>
> <https://github.com/pfalcon/pycopy-lib/tree/master/uasyncio>

　micropython-mdnsのサンプルがあるので、それを参考にする。

> micropython-mdns/examples at main · cbrand/micropython-mdns<br>
> <https://github.com/cbrand/micropython-mdns/tree/main/examples>

　サンプルは４つある。

```text
　・request_a_record.py :
　　　getaddrinfo()でAレコードを名前解決する。普通のDNSクエリにも対応。
　・service_discovery_constant.py :
　　　継続的なmDNSサービス検出。アナウンスのあったサービスを通知。
　・service_discovery_once.py :
　　　タイムアウトを設定して、一回だけmDNSのサービス検出を実施。
　・service_responder.py :
　　　サービスのアナウンスとレスポンダー。
```

　名前解決だけの提供はなさそうだ。いまのところ、なにもサービスは動いていないのだけど、とりあえずhttp80くらいのアナウンスにしておくか。

　中を見てみる。こんな感じ。

```text
import network
import uasyncio
from mdns_client import Client
from mdns_client.responder import Responder

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("<SSID>", "<Password>")
while not wlan.isconnected():
    import time
    time.sleep(1.0)
own_ip_address = wlan.ifconfig()[0]

loop = uasyncio.get_event_loop()
client = Client(own_ip_address)
responder = Responder(
    client,
    own_ip=lambda: own_ip_address,
    host=lambda: "my-awesome-microcontroller-{}".format(responder.generate_random_postfix()),
)

def announce_service():
    responder.advertise("_myawesomeservice", "_tcp", port=12345, data={"some": "metadata", "for": ["my", "service"]})
    # If you want to set a dedicated service host name
    responder.advertise(
        "_myawesomeservice",
        "_tcp",
        port=12345,
        data={"some": "metadata", "for": ["my", "service"]},
        service_host_name="specialcontrollerservicename",
    )

announce_service()
loop.run_forever()
```

　これなら、loopでリクエストの待受けさせないで、アナウンスだけさせたら、名前引きだけできるようになりそう。
