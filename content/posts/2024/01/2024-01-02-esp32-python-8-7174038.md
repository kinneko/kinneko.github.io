　ターゲットであるESP32側をDHCPにしていると、アドレス変わってしまってめんどくさい。固定アドレスで運用したほうがいいかも。

　現在のmain.pyはこんな感じ。sta_if.isconnected()とsta_if.ifconfig()はシリアルでつないであってもコンソールにアウトプットされないので、あんまり意味ない。

```text
esp32@upydevice:~ $ cat main.py
import network
import machine
import time
sta_if = network.WLAN(network.STA_IF)
sta_if.active(True)
sta_if.connect('MyPlace', 'XXXXXXXXXXX')
sta_if.isconnected()
sta_if.ifconfig()

led = machine.Pin(2, machine.Pin.OUT)
while True:
    led.value(1)
    time.sleep(1)
    led.value(0)
    time.sleep(1)
    led.value(1)
    time.sleep(1)
    led.value(0)
    time.sleep(5)
```

　接続を完了するのを確認して、コンソールに出すように変更する。

```text
while not sta_if.isconnected():
    time.sleep(1)
print("Connected:", sta_if.isconnected())
print("Network config:", sta_if.ifconfig())
```

　DHCPでアドレス変更になっても面倒なので、固定アドレスを設定してみる。

```text
import network
import machine
import time
sta_if = network.WLAN(network.STA_IF)
sta_if.active(True)
sta_if.connect('MyPlace', 'XXXXXXXXXXX')
ip = '192.168.0.132'
subnet = '255.255.255.0'
gateway = '192.168.0.1'
dns = '8.8.8.8'
sta_if.ifconfig((ip, subnet, gateway, dns))
while not sta_if.isconnected():
    time.sleep(1)
print("Connected:", sta_if.isconnected())
print("Network config:", sta_if.ifconfig())

esp32@upydevice:~ $ exit -r
```
