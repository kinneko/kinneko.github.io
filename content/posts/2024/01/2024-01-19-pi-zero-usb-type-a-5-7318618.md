　組み立ては済んだので、起動して動作確認してみる。

　組み込んだのはRaspberry Pi Zero Wなので、SoCはBCM2835で初代Raspiと同じ。コアはARM1176JZF-Sなので、ターゲットは32bitになる。メモリが512MBと少ないので、Liteを入れる。WiFiとユーザーの設定をしておく。SDカードは8GBのものを使った。

![](/2024-01-19/7318618-01.png)

　ケースは、SDカードを入れると指では取り出せない。

![](/2024-01-19/7318618-02.png)

　カード側にタブを付けて取り出せるように細工しておくか、ピンセットや毛抜きのような道具を用意しておく必要がある。面倒だな。

![](/2024-01-19/7318618-03.png)

　無事起動したようだ。

![](/2024-01-19/7318618-04.png)

　ケースの上蓋をしたままでも、カメラの配線用の穴からLEDが確認できる。

![](/2024-01-19/7318618-05.png)

　ssh接続をする。avahiは起動していないので、mDNSで名前解決はできない。コンソールを接続して割り当てられたIPアドレスを確認した。

　USBの動作を確認。USBキーボードを接続しているので、それでチェックする。

```text
kinneko@raspberrypi:~ $ lsusb
Bus 001 Device 003: ID 258a:000c HAILUCK CO.,LTD USB KEYBOARD
Bus 001 Device 002: ID 1a40:0101 Terminus Technology Inc. Hub
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
```

　「Linux Foundation 2.0 root hub」はPiZero内臓HUBで、次の「Terminus Technology Inc. Hub」がHATに内臓されたUSB HUB、「HAILUCK CO.,LTD USB KEYBOARD」がUSBキーボード。

　４つあるポートに順に差し込んでみたが、いずれも問題なく認識している。

```text
Bus 001 Device 004: ID 258a:000c HAILUCK CO.,LTD USB KEYBOARD
Bus 001 Device 005: ID 258a:000c HAILUCK CO.,LTD USB KEYBOARD
Bus 001 Device 006: ID 258a:000c HAILUCK CO.,LTD USB KEYBOARD
```

　HUBのコントローラーはこれのようだ。

![](/2024-01-19/7318618-06.png)

　Liteとはいえ、メモリーはちょっと厳しいかな...

```text
kinneko@raspberrypi:~ $ free -h
               total        used        free      shared  buff/cache   available
Mem:           428Mi       104Mi       268Mi       1.0Mi       105Mi       324Mi
Swap:           99Mi          0B        99Mi
```

　HDMIは、ダミープラグを接続せずに起動しても、あとでケーブルを差し込んだだけで動作した。

　動くのがあたり前とは言えない中華製品で、トラブルなく、すんなり動いてしまったので、あんまりリポートするところがないw waveshare製というのは安くはないのだけど手堅い。

　USBが４ポートに増えたので、USBデバイスをいろいろ差し込んで動作させることができそうだ。給電が足りればだけどw
