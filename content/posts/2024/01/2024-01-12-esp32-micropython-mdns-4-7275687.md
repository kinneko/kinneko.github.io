　main.pyにサンプルコードをそのままコピペする。

```text
import network
import machine
import time
sta_if = network.WLAN(network.STA_IF)
sta_if.active(True)
sta_if.ifconfig()
sta_if.disconnect()
sta_if.connect('MyPlace', 'XXXXXXXX')
while not sta_if.isconnected():
    time.sleep(1)
print("Connected:", sta_if.isconnected())
print("Network config:", sta_if.ifconfig())

import uasyncio
from mdns_client import Client
from mdns_client.responder import Responder

own_ip_address = sta_if.ifconfig()[0]

loop = uasyncio.get_event_loop()
client = Client(own_ip_address)
responder = Responder(
    client,
    own_ip=lambda: own_ip_address,
    host=lambda: "my-awesome-microcontroller-{}".format(responder.generate_random_postfix()),
)

def announce_service():
    responder.advertise("_myawesomeservice", "_tcp", port=12345, data={"some": "metadata", "for": ["my", "service"]})
    # If you want to set a dedicated service host name
    responder.advertise(
        "_myawesomeservice",
        "_tcp",
        port=12345,
        data={"some": "metadata", "for": ["my", "service"]},
        service_host_name="specialcontrollerservicename",
    )

announce_service()
loop.run_forever()
```

　これをimportして起動する。（再起動してもいいんだけど）

```text
esp32@upydevice:~ $
>>> import main
```

　しょうがないのでサンプルの中身を見てみる。

　responderが呼ばれるとホスト名が更新される。loopが呼ばれる度に、ホスト名が変更されている。これはダメね。

　ホスト名は事前に作成して、それを呼ぶだけにしておく。すると毎回呼ばれても、固定のホスト名がセットされるはずだ。

```text
own_ip_address = sta_if.ifconfig()[0]
host_name = "my-awesome-microcontroller"

loop = uasyncio.get_event_loop()
client = Client(own_ip_address)
responder = Responder(
    client,
    own_ip=lambda: own_ip_address,
    host=lambda: host_name,
)
```
