　これはマズいなと思ったのだけど、電源を入れ直したらGUIで起動してきた。

　液晶はTFTで、800x480と解像度は低い。起動してから、GUIが表示されるまでに、１分くらいはかかっている。

　タッチも正常に反応している。操作感は軽い感じ。タッチも指でやって問題がない程度。

　画面の輝度は高くて眩しい感じ。

　しばらくするとスリープでブラックアウトした。画面をタッチすると画面全体が赤くなったあとにGUIが出てくる。

　とりあえず輝度は下げたい。輝度調整とスリープの抑制については、専用の解説ページが用意されている。

　sshで接続して操作する。

　輝度設定は、/sys/class/backlight/rpi_backlight/brightnessに対して、0-255を書き込むだけのよう。デフォルトは100。

　でも、そういうファイルはないのよね。

```text
kinneko@raspberrypi:~ $ ls -al /sys/class/backlight/rpi_backlight/brightness
ls: cannot access '/sys/class/backlight/rpi_backlight/brightness': No such file or directory
kinneko@raspberrypi:~ $ ls -al /sys/class/backlight/rpi_backlight/
ls: cannot access '/sys/class/backlight/rpi_backlight/': No such file or directory
kinneko@raspberrypi:~ $ ls -al /sys/class/backlight/
total 0
drwxr-xr-x  2 root root 0 Dec  5 12:08 .
drwxr-xr-x 57 root root 0 May 13  2023 ..
lrwxrwxrwx  1 root root 0 Dec  5 12:09 10-0045 -> ../../devices/platform/soc/3f205000.i2c/i2c-11/i2c-10/10-0045/backlight/10-0045
```

　とりあえず、ドキュメント通りにしてみる。

```text
kinneko@raspberrypi:~ $ sudo su -
root@raspberrypi:~# echo 10 > /sys/class/backlight/rpi_backlight/brightness
-bash: /sys/class/backlight/rpi_backlight/brightness: No such file or directory
```

　まぁ、そうなるよね... シンボリックリンクは作られているようなので、たぶん、制御できる口は出ているのだろう。探す。

```text
root@raspberrypi:~# ls /sys/class/backlight/
10-0045
root@raspberrypi:~# ls /sys/class/backlight/10-0045/
actual_brightness  bl_power  brightness  device  max_brightness  power	scale  subsystem  type	uevent
```

　現在地は255になっていて、輝度最大だ。

```text
root@raspberrypi:~# cat /sys/class/backlight/10-0045/brightness
255
```

　100に設定するとまぶしさはなくなった。

```text
root@raspberrypi:~# echo 100 > /sys/class/backlight/10-0045/brightness
```

　この値は自動で保持はされないのかと思ったら、再起動しても保存されている。どっかに書かれているのかな？ Linuxシステム側には設定の痕跡はなかったので、DSIの側で保存されている感じ。

```text
kinneko@raspberrypi:~ $ cat /sys/class/backlight/10-0045/brightness
100
```

　しかし、この調子だと、提供されるドキュメントの内容は古くて鵜呑みにはできないね。
