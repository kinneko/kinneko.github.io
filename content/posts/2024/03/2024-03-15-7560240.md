　輝度設定と、スリープの抑制はできた。スクリーンキャプチャでちょっと躓いたが、続きをやってゆく。

　現在は、デフォルトの横長表示だが、スマホのように縦長表示にしたい。

![](/2024-03-15/7560240-01.png)

　ディスプレイの回転は、/boot/config.txtにあるdisplay_lcd_rotateを変更する。設定可能なのは1-3で、それぞれ、90度、180度、270度表示になる。

　デフォルトでは、何も設定されていない。

```text
kinneko@raspberrypi:~ $ cat /boot/config.txt | grep display_lcd_rotate
```

　90度で設定してみる。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/config.txt
display_lcd_rotate=1
```

　再起動して変更を確認する。変わってないんですが...

![](/2024-03-15/7560240-02.png)

　KMS環境では、この設定はダメらしい... もとに戻しておく。

　X11環境のほうで設定を変更しないといけなさそう。

```text
kinneko@raspberrypi:~ $ xrandr --output HDMI-1 --rotate right
Can't open display
```

　DSIでは、何を指定したらいいのだろう。

　これは、xrandrコマンド自身で調べることができるようだ。

```text
kinneko@raspberrypi:~ $ export DISPLAY=:0
kinneko@raspberrypi:~ $ xrandr
Screen 0: minimum 320 x 200, current 800 x 480, maximum 2048 x 2048
HDMI-1 disconnected primary (normal left inverted right x axis y axis)
DSI-1 connected 800x480+0+0 (normal left inverted right x axis y axis) 0mm x 0mm
   800x480       59.93*+
```

　接続されているモニタのリストは以下のオプションで確認できる。

```text
kinneko@raspberrypi:~ $ xrandr --listmonitors
Monitors: 1
 0: +DSI-1 480/127x800/212+0+0  DSI-1
```

　実行する。できたわー。

```text
kinneko@raspberrypi:~ $ xrandr --output DSI-1 --rotate right
```

![](/2024-03-15/7560240-03.png)

　この設定は一時的なものなので、恒久化する必要がある。方法は大きく３種類ある。

　ユーザーのホームディレクトリに置く.xinitrcや.xprofileファイルの中で指定する方法がある。この場合はユーザーごとの設定になる。

　LXDEのレベルで設定するには、/etc/xdg/lxsession/LXDE-pi/autostartか、~/.config/lxsession/LXDE-pi/autostartに追記する。ユーザーごとの設定は好ましくないので、/etc/xdg/lxsession/LXDE-pi/autostartに追記するのがよさそう。

　また、systemdを使って実行する方法もある。たとえば、/etc/systemd/system/xrandr-rotate.serviceを作ってxrandrを実行させる。これはちょっと大袈裟な感じだ。

　LXDEのシステムワイドな設定に追加することにする。

```text
kinneko@raspberrypi:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
@lxpanel --profile LXDE-pi
@pcmanfm --desktop --profile LXDE-pi
@xscreensaver -no-splash
@xrandr --output DSI-1 --rotate right
```

　追記後に再起動してみる。

　当然ながら、スプラッシュは回転しない。display_lcd_rotateが使えないのが恨めしい。

![](/2024-03-15/7560240-04.png)

　みっともないので、スプラッシュを表示しないようにする。起動時のオプションを変更する必要がある。デフォルトではこうなっている。

```text
kinneko@raspberrypi:~ $ cat /boot/cmdline.txt
console=serial0,115200 console=tty1 root=PARTUUID=70968fa8-02 rootfstype=ext4 fsck.repair=yes rootwait quiet splash plymouth.ignore-serial-consoles
```

　ここにsplash設定があるので、これを削除してみる。

　また、plymouthでplymouth.ignore-serial-consolesが設定されているので、plymouthが表示するスプラッシュスクリーンも抑制する必要がある。plymouth.enable=0で、plymouthの機能そのものを抑制してしまおう。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/cmdline.txt
console=serial0,115200 console=tty1 root=PARTUUID=70968fa8-02 rootfstype=ext4 fsck.repair=yes rootwait quiet plymouth.enable=0
```

　再起動すると、カラーマークのあと、隅にカーソルが点滅するのと、一時的に数行のコンソール表示が出るものの、おおむね目的は達成できた。plymouthを停止したので、終了時のスプラッシュも表示されなくなった。

　念の為、logo.nologoも設定しておく。

```text
console=serial0,115200 console=tty1 root=PARTUUID=70968fa8-02 rootfstype=ext4 fsck.repair=yes rootwait quiet logo.nologo plymouth.enable=0
```

　回転だけすると、タッチのキャリブレーションも変わってくるので、タッチした情報とスクリーン上のカーソル位置が合わなくなってしまう。これも設定する必要がある。

　これは、デバイスドライバにパラメータを渡す必要があるので、/boot/config.txtに追記する必要がある。90度回転の場合は以下のようになる。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/config.txt
dtoverlay=rpi-ft5406,touchscreen-swapped-x-y=1,touchscreen-inverted-x=1
```

　再起動すると、タッチも正常にできるようになった。

![](/2024-03-15/7560240-05.png)

　回転角度が違う場合には、タッチスクリーンの設定も変更する必要がある。

　180度のときには、

```text
dtoverlay=rpi-ft5406,touchscreen-inverted-x=1,touchscreen-inverted-y=1
```

　270度のときには、

```text
dtoverlay=rpi-ft5406,touchscreen-swapped-x-y=1,touchscreen-inverted-y=1
```

```text
と設定する必要がある。
```

　これで、DSI接続のLCDについての基本的な設定は終わる。

　Raspi Bシリーズの基板では意味なく大きすぎるので、Zeroなどが使えないかと思ったのだけど、Zeroシリーズは、カメラ用のCSIはついていても、DSIはついてないので動作しないということのようだ。Aシリーズも初代以外は対応していないようだ。全体に小さくするのは断念だ。

　また、Pi5からは、フレキのコネクタサイズが違うので、専用のフレキを用意する必要があるそうだ。
