　デフォルトの解像度が低すぎるので、GUIアプリによっては画面サイズが見切れてしまい、面倒なことになることがわかった。

　Raspiでは、仮想的にディスプレイのフレームバッファサイズを変更することができる。

　デフォルトでコメントアウトされているので有効にして再起動する。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/config.txt
# uncomment to force a console size. By default it will be display's size minus
# overscan.
framebuffer_width=1280
framebuffer_height=720
```

　しかし、再起動しても画面の解像度上がった気配はないな...

　またKMS問題かな。

　しょうがないので、xrandrで縦横２倍の設定を行ってみる。

```text
kinneko@raspberrypi:~ $ export DISPLAY=:0
kinneko@raspberrypi:~ $ xrandr --output DSI-1 --scale 2x2
```

　アイコンは小さく、表示エリアは大きくなった。

![](/2024-03-18/7561346-01.png)

　ところが、再起動したら、X11が起動してこなくなった。

　なんかずっと動いているのだけど、画面はいっこうに表示されない。

　前の解像度設定が残っているのが悪さしているのかな？ コメントアウトしておく。

```text
kinneko@raspberrypi:~ $ sudo vi /boot/config.txt
# uncomment to force a console size. By default it will be display's size minus
# overscan.
#framebuffer_width=1280
#framebuffer_height=720
```

　sshはできたので、そのまま再起動したら普通に戻った。

　さて、xrandrの設定をデフォルトにするには、前と同じ方法でいい。

　LXDEのシステムワイドな設定に追加することにする。

```text
kinneko@raspberrypi:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
@lxpanel --profile LXDE-pi
@pcmanfm --desktop --profile LXDE-pi
@xscreensaver -no-splash
@xrandr --output DSI-1 --rotate right  --scale 2x2
```

　今回使う予定のアプリでは、表示を調整する方法があったので、この設定は有効にしないで済んだ。
