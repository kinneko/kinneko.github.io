　続いて設定をやってゆく。

　画面のスリープはどちらでもいいのだけど、ブラックアウトしていると、目安になるLEDもフロント側からは見えないので、動いているかどうかもよくわからない。少し困るので、抑制する設定を試してみる。

　こちらは、ドキュメント通りの方法でできるようだ。lightdm.confに「xserver-command=X -s 0 -dpms」を追記して再起動する。DPMS(Display Power Management Signaling)とスクリーンセーバー機能を無効にすることで、ディスプレイが常にオンになるようにしている。

```text
kinneko@raspberrypi:~ $ cat /etc/lightdm/lightdm.conf | grep xserver-command
# xserver-command = X server command to run (can also contain arguments e.g. X -special-option)
#xserver-command=X
```

　これ以外にも、LXDE環境のautostartファイルで、ユーザー設定やシステムワイドの設定で指定することもできる。

```text
kinneko@raspberrypi:~ $ cat /etc/xdg/lxsession/LXDE-pi/autostart
@lxpanel --profile LXDE-pi
@pcmanfm --desktop --profile LXDE-pi
@xscreensaver -no-splash
```

　以下を追記する。

```text
@xset s off
@xset -dpms
```

　ユーザー設定で行う場合は、以下のファイルに追記する。

```text
kinneko@raspberrypi:~ $ cat ~/.config/lxsession/LXDE-pi/autostart
cat: /home/kinneko/.config/lxsession/LXDE-pi/autostart: No such file or directory
```

　raspi-configコマンドでも設定できる。

```text
kinneko@raspberrypi:~ $ sudo raspi-config
```

　さらに、GUIのメニューにある「Raspberry Pi設定ツール」でも同様に変更できる。

　変更はどこに反映されたのだろう？ lightdm.confでもautostartでもない。/boot/config.txtにはスクリーンブランキングの設定はなさそう。

```text
kinneko@raspberrypi:~ $ cat /etc/lightdm/lightdm.conf | grep xserver-command
# xserver-command = X server command to run (can also contain arguments e.g. X -special-option)
#xserver-command=X
```

```text
kinneko@raspberrypi:~ $ cat /etc/xdg/lxsession/LXDE-pi/autostart
@lxpanel --profile LXDE-pi
@pcmanfm --desktop --profile LXDE-pi
@xscreensaver -no-splash
kinneko@raspberrypi:~ $ cat ~/.config/lxsession/LXDE-pi/autostart
cat: /home/kinneko/.config/lxsession/LXDE-pi/autostart: No such file or directory
```

　これかな？

```text
kinneko@raspberrypi:~ $ cat /etc/X11/xorg.conf.d/10-blanking.conf
Section "Extensions"
    Option      "DPMS" "Disable"
EndSection
```

```text
Section "ServerLayout"
    Identifier "ServerLayout0"
    Option "StandbyTime" "0"
    Option "SuspendTime" "0"
    Option "OffTime"     "0"
    Option "BlankTime"   "0"
EndSection
```

　設定を戻してみると、このファイルが消えていたので間違いなさそう。再設定すると復活していた。

```text
kinneko@raspberrypi:~ $ cat /etc/X11/xorg.conf.d/10-blanking.conf
cat: /etc/X11/xorg.conf.d/10-blanking.conf: No such file or directory
```

　RaspiOS的には、ドキュメントにあるlightdm.confや、autostartファイルの改変を使わずに、raspi-configという公式の設定でスリープ抑制をするのが良さそうだ。
