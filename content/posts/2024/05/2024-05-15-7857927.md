　VSCode真面目に使うかな... (とか前にも言ってたけど、結局vimとか使っているのだけど)

　というわけで、M3 MBAにVSCodeを入れる。

　インストールはほとんど変わっていない感じだけど、日本語の情報は古いことが多いので、本家の情報を確認しておく。最新版は1.88とバナーに出ている。

> Visual Studio Code - Code Editing. Redefined<br>
> <https://code.visualstudio.com/>

![](/2024-05-15/7857927-01.png)

　ダウンロードは、macOS版はユニバーサルバイナリ版しかないようだ。

![](/2024-05-15/7857927-02.png)

　VSCode-darwin-universal.zipがダウンロードされる。 ダウンロードと同時にGetting Startedに画面遷移する。

> Documentation for Visual Studio Code<br>
> <https://code.visualstudio.com/docs/?dv=osx>

![](/2024-05-15/7857927-03.png)

　zipを展開すると、いきなりアプリが出てくる。これをアプリケーションフォルダにコピーする。

![](/2024-05-15/7857927-04.png)

　起動してみる。AppStoreからのダウンロードでないので起動時に警告が出る。

![](/2024-05-15/7857927-05.png)

　起動した。まぁ、見慣れた画面だ。

![](/2024-05-15/7857927-06.png)

　macOSの言語環境を読み取って、日本語表示にするアオオンをインストールするようにすすめてくる。

![](/2024-05-15/7857927-07.png)

> 表示言語を 日本語 に変更するには言語パックをインストールします。 (Install language pack to change the display language to Japanese.)

　「インストールして再起動」ボタンを押すと、アドオンがインストールされて再起動された。表示が日本語になっている。

![](/2024-05-15/7857927-08.png)

　テーマの選択をする。デフォルトのダークハイコントラストのまま。

　言語拡張は、JS, TS, HTML/CSS, Python, Dart, JSON, Markdownあたりを入れればいいか。HTML/CSS, Python, Dartはオススメに出てくるものを入れたけど、他の環境は無限に出てくるので、どれにしていいかわからない...

![](/2024-05-15/7857927-09.png)

　Markdownはデフォルトでサポートされている機能だけでいいか。エディタの右上にある「プレビュー」アイコンを押すかCmd+K Vでプレビューできるようだ。

　JS/TS, JSONは、ESLintとPrettierくらいでいいかな...

![](/2024-05-15/7857927-10.png)

　Prettierは、エディタでファイルを開いて、右クリックメニューから「ドキュメントのフォーマット」を選択するか、Shift+Option+Fでファイルがフォーマットされる。

　保存時に自動フォーマットするには、~/Library/Application Support/Code/[User]/settings.jsonに以下のように書いておく。VSCodeから編集するにはコマンドパレットに「Open Settings (JSON)」と入力して選択できる。

```json
{
  "editor.formatOnSave": true
}
```

　プロジェクトのローカル設定は、.prettierrcを作ってそこに書いておく。

![](/2024-05-15/7857927-11.png)

　Live Serverは今回は入れない。

　オススメの中にES7+ React/Redux/React-Native snippetsがあるのが気になるけど、今回は入れない。

![](/2024-05-15/7857927-12.png)

　Git/Github関連もすぐにはいらないのでパス。

　全角のスペースを可視化するzenkakuは入れておくかな。

![](/2024-05-15/7857927-13.png)

　「設定の調整」「デバイス間での設定の同期」などあとの設定はパス。

![](/2024-05-15/7857927-14.png)

　公式のmacOSのインストール手順はここにある。

> Running Visual Studio Code on macOS<br>
> <https://code.visualstudio.com/docs/setup/mac>

![](/2024-05-15/7857927-15.png)

　コマンドラインからの起動方法や、タッチバーサポート、Mojave以降ではプライバシー保護のためアクセス許可のダイアログが出るかもよなど、たいしたことは書かれていない。

　最近は、機能拡張を追加してもVSCodeの再起動しろって言われないのね。平和。
