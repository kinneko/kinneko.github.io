　Waylandの画面のスクショをコマンドラインから取得するにはgrimを使うのが便利そう。

　Waylandデフォルト化で、X11でのノウハウがいろいろ通用しないようになっている。コンソールからのスクリーンキャプチャもその１つ。

　grimはWaylandディスプレイサーバー向けに設計されたスクリーンキャプチャツール。

> GitHub - emersion/grim: Grab images from a Wayland compositor<br>
> <https://github.com/emersion/grim>

![](/2024-05-22/7897614-01.png)

　BookwormベースのRaspiOS Desktopでは、grimはデフォルトでインストールされているのだけど、環境変数のWAYLAND_DISPLAYが自動設定されていないのでややこしい。

```console
kinneko@pi4:~ $ grim ./cap.png
failed to create display
```

　WAYLAND_DISPLAYを指定してやるとキャプチャできる。

```console
kinneko@pi4:~ $ WAYLAND_DISPLAY="wayland-1" grim ./cap.png
kinneko@pi4:~ $ file cap.png
cap.png: PNG image data, 480 x 800, 8-bit/color RGB, non-interlaced
```

![](/2024-05-22/7897614-02.png)

　slurpコマンドと組み合わせることで、GUIで選択した領域を切り取ってキャプチャすることもできるようだけど、なんかそれはそれでめんどくさい。矩形領域を直接数値指定できたらいいのに。
