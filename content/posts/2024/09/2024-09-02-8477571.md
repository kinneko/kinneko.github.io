　ハロワをビルドして確認。

```text
% flutter create hellowworld
Creating project hellowworld...
Resolving dependencies in `hellowworld`...
Downloading packages...

Wrote 129 files.

All done!
You can find general documentation for Flutter at: https://docs.flutter.dev/
Detailed API documentation is available at: https://api.flutter.dev/

https://www.youtube.com/c/flutterdev

In order to run your application, type:

% cd hellowworld
```

　あ、createでandroid指定するの忘れたわ。全対応になってしまった。Androidデバイスを指定してビルドしないと。その場合は、「flutter create --platforms=android hellowworld」。ターゲットの追加は「create .」なんだけど、これだと全部追加されてしまうので、iOSだけ追加する場合は、「flutter create --platforms=ios .」。すっかり忘れているな。
