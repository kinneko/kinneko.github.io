　掃除と調整は一通り終わったので、プリントしてみる。

　とりあえず、テストプリントなら定番の3DBenchyかな。

　モデルのスライサーはいつものCuraを使う。Creality純正のスライサーもあったと思うのだけど、慣れたものが一番楽ちんだから。

　しばらくさわっていないので、だいぶバージョンアップしているのかな？ 起動してみても、特にアップデート警告のポップアップはでないな... そのままでいいかw

![](/2024-04-08/7709203-01.png)

　プリンタ設定を追加する。

![](/2024-04-08/7709203-02.png)

　メジャーなプリンタはデフォルトで設定があって楽だw マイナーなプリンタでは、設定を自分で作らねばならないことも多い。

![](/2024-04-08/7709203-03.png)

　デフォルト値の設定はこんな感じ。

![](/2024-04-08/7709203-04.png)

Start G-code

```gcode

; Ender 3 Custom Start G-code

G92 E0 ; Reset Extruder

G28 ; Home all axes

M104 S{material_standby_temperature} ; Start heating up the nozzle most of the way

M190 S{material_bed_temperature_layer_0} ; Start heating the bed, wait until target temperature reached

M109 S{material_print_temperature_layer_0} ; Finish heating the nozzle

G1 Z2.0 F3000 ; Move Z Axis up little to prevent scratching of Heat Bed

G1 X0.1 Y20 Z0.3 F5000.0 ; Move to start position

G1 X0.1 Y200.0 Z0.3 F1500.0 E15 ; Draw the first line

G1 X0.4 Y200.0 Z0.3 F5000.0 ; Move to side a little

G1 X0.4 Y20 Z0.3 F1500.0 E30 ; Draw the second line

G92 E0 ; Reset Extruder

G1 Z2.0 F3000 ; Move Z Axis up little to prevent scratching of Heat Bed

G1 X5 Y20 Z0.3 F5000.0 ; Move over to prevent blob squish

```

End G-code

```gcode

G91 ;Relative positioning

G1 E-2 F2700 ;Retract a bit

G1 E-2 Z0.2 F2400 ;Retract and raise Z

G1 X5 Y5 F3000 ;Wipe out

G1 Z10 ;Raise Z more

G90 ;Absolute positioning

G1 X0 Y{machine_depth} ;Present print

M106 S0 ;Turn-off fan

M104 S0 ;Turn-off hotend

M140 S0 ;Turn-off bed

M84 X Y E ;Disable all steppers but Z

```

　設定すると、ステージがEnderロゴに変わった。

![](/2024-04-08/7709203-05.png)

　3DBenchyのstlファイルをロードする。

> #3DBenchy – The jolly 3D printing torture-test<br>
> <https://www.3dbenchy.com/>

![](/2024-04-08/7709203-06.png)

　スライスする。

![](/2024-04-08/7709203-07.png)

　うへ、１時間51分かかると出てきたよ。だいぶ遅いじゃないの...

　SDカードにGcodeデータをコピーしてプリントする。

　セットしておいたフィラメントが折れていた。相当に湿気っている感じ。最初からこれだと、やる気なくすね。

![](/2024-04-08/7709203-08.png)

　途中で折れているわけではなさそうなので、少しだけノズルの温度を上げて、セミコールドプルしておく。少し毛羽立っている感じはあるけど、カーボンなどはついていない感じ。黒フィラメントだから、よくわからないけどw

![](/2024-04-08/7709203-09.png)

　フィラメントが折れないように気をつけつつ、フィラメントをロードして、プリントを開始。

　PLAなのでノズルは200度だと思うのだけど、175度で止まっている。

![](/2024-04-08/7709203-10.png)

　どうやら、Curaのデフォルトでは、ベッドが指定の60度になるまでノズル温度は上げすぎないようになっているようだ。うーん、ノズルの温度はすぐに上がる感じなので、ベッドだけ先にやって、ノズルは後でもいいような...

![](/2024-04-08/7709203-11.png)

　あぁ、やっぱ定着が悪い。もっとノズルとベッドのスペースをシビアにするべきだったか。

![](/2024-04-08/7709203-12.png)

　途中で剥がれたので手動で停止する。

![](/2024-04-08/7709203-13.png)

　あーあ...
