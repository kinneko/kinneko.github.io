　ローカルLLMのフレームワーク、Ollamaを使ってみる。

　ローカルLLMのフレームワークは、少し前にJanを動かしてみた。

> MBPでJanを使ってみる -1-<br>

　同様のツールであるOllamaを動かしてみる。こっちのが古参だ。

> Ollama<br>
> <https://ollama.com/>

![](/2024-04-24/7806031-12.png)

　2024/3/14にAMD製グラフィックボードにも対応したそうだけど、macOSだと関係ないな。

　コマンドラインでバージョン確認。

```text
% ollama --version
ollama version is 0.1.32
```

　pullコマンドでモデルのでダウンロード。

```text
% ollama pull [モデル名]
```

　runコマンドでモデル実行。いきなりrunしても、モデルがダウンロードされていなければ、ダウンロードしてくれる。

```text
% ollama run [モデル名]
```

　1.4GBとサイズ的に手頃なgemma:2bを実行。ダウンロードがはじまる。

```text
% ollama run gemma:2b
pulling manifest

```

　モデルの削除。

　デカいモデルをディスクの肥やしにするのは嫌なので、モデルの削除方法を調べる。rmオプションが使える感じ。

  pull        Pull a model from a registry

```text

　削除は結構そっけない。一瞬で終わる。

```
