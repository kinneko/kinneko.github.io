　Curaのスライスパスがなんかイマイチ気に入らないので、PrusaSlicerを導入してみる。

　実行バイナリのダウンロードは、Githubのリリースページから取得できる。

> Releases · prusa3d/PrusaSlicer<br>
> <https://github.com/prusa3d/PrusaSlicer/releases>

![](/2024-06-21/8033494-01.png)

　最新のPrusaSlicer-2.7.4+macOS-universal-202404050934.dmgをダウンロードして開く。

![](/2024-06-21/8033494-02.png)

![](/2024-06-21/8033494-03.png)

![](/2024-06-21/8033494-04.png)

![](/2024-06-21/8033494-05.png)

　Kingroonとかないのねw

![](/2024-06-21/8033494-06.png)

　一旦、中止して終了する。

　プロファイルデータは公開してくれている人がいるので、それを使う。PROはS1しかないけど、ほぼ同じなのでそのまま。

> GitHub - RyanT95/KP3S-Prusa: PrusaSlicer profiles for Kingroon KP3S 3.0 (Titan Extruder) & KP3S Pro S1.<br>
> <https://github.com/RyanT95/KP3S-Prusa>

![](/2024-06-21/8033494-07.png)

　PrusaSlicerの設定のある/Applications/Original Prusa Drivers/PrusaSlicer.app/Contents/Resources/profilesに、Kingroonディレクトリを掘り、Kingroon.idxとKingroon.iniをコピーする。

```
% cd /Applications/Original Prusa Drivers/PrusaSlicer.app/Contents/Resources/profiles
% git clone https://github.com/RyanT95/KP3S-Prusa.git
Cloning into 'KP3S-Prusa'...

Receiving objects: 100% (128/128), 3.52 MiB | 9.07 MiB/s, done.
Resolving deltas: 100% (57/57), done.
% mv KP3S-Prusa/Kingroon.* ./
% mv KP3S-Prusa/Kingroon ./
% ls Kingroon*

```

　PrusaSlicerを再起動すると、「その他」のメニューに出てくる。

![](/2024-06-21/8033494-08.png)

　あれ？ 画像のパスがダメっぽい。まぁいいか。

![](/2024-06-21/8033494-09.png)

　起動した。

![](/2024-06-21/8033494-10.png)

　あんま設定するとこないのね。

![](/2024-06-21/8033494-11.png)

　スライス実行ボタンを押す。なんか、センターと違うところにレイアウトされた。

![](/2024-06-21/8033494-12.png)

　ベッド60度、ヘッド200度でプリントしている。

　詳細設定はプリンタとフィラメントで別ウインドウでやるようだ。基本的なものはCuraと同じ設定が揃っている。

![](/2024-06-21/8033494-13.png)

　プリント終わったら、Z軸を上まで上げるのは面白いね、

　温度が高いのと、フィラメントが湿気っているせいか、出力は安定していない。トップ以外はCuraに負けている気がする。使い慣れたCuraでいいかな。
