　最初はいろいろトラブルが発生する可能性があるので、Raspi Imagerで書き込むsshのデフォルトはパスワード認証にしている。Imagerの中に公開鍵を置いておきたくないというのもある。

　Raspiを起動して、運用が安定するとセッションのたびにパスワード入れるのが面倒になるので、公開鍵認証に変更したい。

　仕組み的には、Raspi側の~/.ssh/authorized_keysに、macOS側のユーザーの公開鍵をエディタで登録してやればいいのだけど、これまで手動で登録しかやったことがなかった。

　普通はssh-copy-idコマンドを使うのだそうだ。使ったことないよw 昔からあったっけ？

　調べてみると、最初のcontribは1999年頃からあるらしい...

　中身はシェルスクリプトだ。

```
% file /usr/bin/ssh-copy-id
/usr/bin/ssh-copy-id: POSIX shell script text executable, Unicode text, UTF-8 text
```

　Raspi側のユーザーディレクトリには、デフォルトでは.sshディレクトリは作成されていない(Imagerで鍵を書き込む設定にしている場合を除く)。手動でやる場合は、自分で作成する必要がある。しかし、ssh-copy-idコマンドは自動で作ってくれるようで、事前に作っておく必要はない。

```
kinneko@pi4:~ $ mkdir -m 700 .ssh
```

　macOSからRaspiにssh接続した状態で、別のmacOSの端末からssh-copy-idコマンドを実行する。オプションでは登録する公開鍵を指定する必要がある。途中、パスワードを求められるので入力する。

```
% ssh-copy-id -i ~/.ssh/id_ed25519.pub kinneko@192.168.0.12
/usr/bin/ssh-copy-id: INFO: Source of key(s) to be installed: "/Users/macinneko/.ssh/id_ed25519.pub"
/usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s), to filter out any that are already installed
/usr/bin/ssh-copy-id: INFO: 1 key(s) remain to be installed -- if you are prompted now it is to install the new keys
kinneko@192.168.0.12's password:

Number of key(s) added:        1

Now try logging into the machine, with:   "ssh 'kinneko@192.168.0.12'"
and check to make sure that only the key(s) you wanted were added.
```

　使用している公開鍵が１つしかない場合は、鍵を指定する必要もない。

```
% ssh-copy-id  kinneko@192.168.0.12
/usr/bin/ssh-copy-id: INFO: Source of key(s) to be installed: "/Users/macinneko/.ssh/id_ed25519.pub"
/usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s), to filter out any that are already installed
/usr/bin/ssh-copy-id: INFO: 1 key(s) remain to be installed -- if you are prompted now it is to install the new keys
kinneko@192.168.0.12's password:

Number of key(s) added:        1

Now try logging into the machine, with:   "ssh 'kinneko@192.168.0.12'"
and check to make sure that only the key(s) you wanted were added.
```
