　マルツにmicroSDを買いにいったら、お店に2個ぶらさがっていた。千円ちょいなので買ってみた。6/19

　このくらいの金額だと、ちょっと買ってみるかという感じにはなるよね。

　たぶん、海外の人だと500円くらいの感覚で買えているのではないかな。いいなー。

　普通のESP32かと思っていたら、ESP32-C6を積んでいるRISC-Vマシンなのね。でも開発環境はArduinoIDEか。アーキテクチャ違いでライブラリ関係が動かなのが多そうね。

　本家のドキュメント。やだなぁ、UIFlow2に対応していないのに、このページにリンク置くのはナシだろうに。日本語ページでは、UIFlowは表示されていなかった。面白いね。

> m5-docs<br>
> <https://docs.m5stack.com/ja/core/M5NanoC6>

![](/2024-08-08/8109291-01.png)

　ソース類はこちら。

> GitHub - m5stack/M5NanoC6<br>
> <https://github.com/m5stack/M5NanoC6>

> Actions · m5stack/M5NanoC6 · GitHub<br>
> <https://github.com/m5stack/M5NanoC6/actions>

　開発環境がいろいろ対応できていない感じ。MicroPythonの対応もまだできていないので、UIFlow2でも対応できていない。先日のハンズオンで、使ってみたので、ちょっと記事ネタにしようと思ったのだけど困ったな。

　対応状況を少し調査。

　CircuitPythonでの動作機種には入ってないけど、C6のリファレンス開発機で動くので、入れて動かすことはできるようだ。ということは、MicroPythonでの対応も近いかな？

> M5NanoC6 をCircuitPythonで動かす #IR - Qiita<br>
> <https://qiita.com/komde/items/e7755b11ab79e8713431>

　ここに「1.24 リリースに含まれる予定ですが、まだ日付は決まっていません。」とある。6/27の投稿。

> ESP32-C6 Support? · micropython · Discussion #11356 · GitHub<br>
> <https://github.com/orgs/micropython/discussions/11356>

　MIcroPythonのリリースをみると、まだ1.23だな。これは5/31リリース。

> Releases · micropython/micropython · GitHub<br>
> <https://github.com/micropython/micropython/releases>

　C6への対応はできているそう。

> esp32c6 support (IDF v5.2) by andrewleech · Pull Request #11869 · micropython/micropython · GitHub<br>
> <https://github.com/micropython/micropython/pull/11869>

　GENERIC_C6の対応はこれか。

> GitHub - tytgatlieven/micropython-esp32c6: MicroPython - a lean and efficient Python implementation for microcontrollers and constrained systems<br>
> <https://github.com/tytgatlieven/micropython-esp32c6>

　まぁ、UIFlow2への対応は、気長に待つしかないね。

　とりあえず、開発はArduinoIDEでやるしかないみたい。ESP32ライブラリをベータにあげないといけないのかな？ 開発環境が汚染されるのはイヤだな。

　と、思っていたら買ってからパッケージも開けないまま、二ヶ月も放置してしまったよ。MIcroPythonの1.24はまだリリースされていない。 micropython-esp32c6のほうも動きはない感じ。

　ここの記事ネタがないので、Lチカくらいやってみることにする。今までの環境をβにするのは、ちょっとイヤなので、M3MBAのほうに環境を作ることにしよう。

　小さいものなので、あまりハード的な特徴はない。SoCはESP32-C6FH4 240MHz、4M Flash。2.4Ghz Wi-Fi6、Zigbee、Thread、Matterに対応していて、GROVEポートが１つあって、赤外線LEDとRGB LED(WS2812)が内蔵されている。センサ類はない。バッテリもないので、通電はUSB必須という感じ。単体では、正直なところ何に使ったらいいのかよくわからない。
