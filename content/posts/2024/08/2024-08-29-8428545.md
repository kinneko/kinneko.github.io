　５インチパネルとPi4の組み合わせとくらべると、だいぶ小さく薄くなった。厚みで６割。容積で半分以下という感じ。

![](/2024-08-29/8428545-02.png)

　さて、ここまでの作業でいろいろゴミも残ってしまったので、SDカードの焼き直し。

　Wayland強制はできなかったし、メモリがタイトな感じなので32bit Desktopでインストールする。メモリ要求はだいぶ落ちたようだ。しかし、BとくらべてAはメモリの搭載が少ないな... なんか、そのぶん動作ももっさりしている感じがする。

```text
kinneko@pi3a:~ $ sudo apt-get update && sudo apt-get upgrade -y
kinneko@pi3a:~ $ free -h
               total        used        free      shared  buff/cache   available
Mem:           425Mi       116Mi       151Mi        12Ki       211Mi       309Mi
Swap:          199Mi       111Mi        88Mi
```

　パネルが変わったので、モニタの認識を確認する。変わらず。

```text
kinneko@pi3a:~ $ DISPLAY=:0 xrandr --listmonitors
Monitors: 1
 0: +DSI-1 800/212x480/127+0+0  DSI-1
```

　輝度は、ハードウエアボタンでバックライトを制御しているので、ソフトウエア制御はいらなさそう。しかし、ソフトウエアの制御も有効のようで、コマンドを投入すると、普通に画面が暗くなった。

```text
kinneko@pi3a:~ $ sudo su -c "echo 50 > /sys/class/backlight/10-0045/brightness"
```

　ディスプレイ回転の永続化。ユーザーレベルの設定ではなく、LXDEのレベルで設定を強制する。ついでにパネルとデスクトップも停止しておく。さらに、スクリーンセーバーとDPMS(ディスプレイパワーマネジメントシグナル)を無効にする。

```text
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
#@lxpanel --profile LXDE-pi
#@pcmanfm --desktop --profile LXDE-pi
@xscreensaver -no-splash
@xrandr --output DSI-1 --rotate right
@xset s off -dpms
```

　タッチの座標調整。まず、タッチスクリーンのデバイス名を調べる。なんか微妙に変わっているじゃないの。

```text
kinneko@pi3a:~ $ DISPLAY=:0 xinput -list
⎡ Virtual core pointer                    	id=2	[master pointer  (3)]
⎜   ↳ Virtual core XTEST pointer              	id=4	[slave  pointer  (2)]
⎜   ↳ 10-0038 generic ft5x06 (79)             	id=6	[slave  pointer  (2)]
⎜   ↳ vc4-hdmi                                	id=7	[slave  pointer  (2)]
⎣ Virtual core keyboard                   	id=3	[master keyboard (2)]
    ↳ Virtual core XTEST keyboard             	id=5	[slave  keyboard (3)]
    ↳ vc4-hdmi                                	id=8	[slave  keyboard (3)]

kinneko@pi3:~ $ sudo vi /etc/X11/xorg.conf.d/99-calibration.conf
Section "InputClass"
    Identifier      "calibration"
    MatchProduct    "10-0038 generic ft5x06 (79)"
    Option          "TransformationMatrix" "0 1 0 -1 0 1 0 0 1"

```

　再起動してパラメータの変更を確認。スクリーンセーバーとDPMSは問題なし。デスクトップやパネルまわりも出なくなっている。黒い画面にマウスカーソルがあるだけ。

```text
kinneko@pi3a:~ $ DISPLAY=:0 xset q | grep "timeout"
  timeout:  0    cycle:  600
kinneko@pi3a:~ $ DISPLAY=:0 xset q | grep "DPMS is"
  DPMS is Disabled
```

```text
kinneko@pi3a:~ $ DISPLAY=:0 xinput -list

⎜   ↳ Virtual core XTEST pointer              	id=4	[slave  pointer  (2)]

kinneko@pi3a:~ $ sudo vi /etc/X11/xorg.conf.d/99-calibration.conf
```

　前の経験から、もっかい再起動してみる。うまくいった... なんだよそれ... デバイス名がフラフラするのはいただけないな。xinputが自動的に割り当てる機能自体ではIDを固定する方法はなさそう。強制できる方法はありそうだけど、とりあえず保留かな。

　adbのインストール。

```text
kinneko@pi3a:~ $ sudo apt install adb -y
```

　scrcpyをビルド。まずツールを入れる。

```text
kinneko@pi3:~ $ sudo apt install libavformat-dev libsdl2-dev libavdevice-dev libusb-1.0-0-dev -y
```

　scrcpyソースコードをcloneしてビルド。確認してビルド環境を削除。

```text
kinneko@pi3:~ $ git clone https://github.com/Genymobile/scrcpy
kinneko@pi3a:~ $ cd scrcpy
kinneko@pi3:~/scrcpy $ ./install_release.sh
kinneko@pi3a:~/scrcpy $ which scrcpy
/usr/local/bin/scrcpy
kinneko@pi3a:~/scrcpy $ scrcpy --version
scrcpy 2.6.1 <https://github.com/Genymobile/scrcpy>

Dependencies (compiled / linked):
 - SDL: 2.26.5 / 2.26.5
 - libavcodec: 59.37.100 / 59.37.100
 - libavformat: 59.27.100 / 59.27.100
 - libavutil: 57.28.100 / 57.28.100
 - libavdevice: 59.7.100 / 59.7.100
 - libusb: - / 1.0.26
kinneko@pi3a:~/scrcpy $ cd ..
kinneko@pi3a:~ $ rm -rf scrcpy/
```

　THINKLETを接続して動作確認。マウスカーソルが滑る感じがするな。まだ調整の余地がある。

```text
kinneko@pi3:~ $ DISPLAY=:0 scrcpy --fullscreen --max-size 512 --no-audio --display-buffer=0
```

　デスクトップに画像を貼る。ツールはfehを使ってみる。

　kinneko@pi3a:~ sudo apt-get install feh -y

　画像を指定して起動する。表示はされた。起動直後はカーソルが消えているけど、タッチすると表示される。起動は一回でいいのかな？

```text
kinneko@pi3a:~ $ DISPLAY=:0 feh --bg-fill /home/kinneko/desktop_480x800.png
```

　プロセスが生きていて画像を持っている感じではない。

```text
kinneko@pi3a:~ $ ps -ax | grep feh
 3190 pts/0    S+     0:00 grep --color=auto feh
```

　scrcpyを起動して、終了しても画像は表示される。なかなかいいかも。

　一回起動したらいいようなので、fehを起動時に動かす設定を入れる。LXDEの起動で入れればいいかな。再起動して、画像が表示されるのを確認した。

```text
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
@feh --bg-fill /home/kinneko/desktop_480x800.png
```

　scrcpyの自動起動。

```text
kinneko@pi4:~ $ sudo vi /etc/systemd/system/scrcpy.service
[Unit]
Description=Start scrcpy for USB devic
After=graphical.target

[Service]
Type=simple
User=kinneko
Environment="DISPLAY=:0"
ExecStart=/usr/local/bin/scrcpy --fullscreen --max-size 512 --no-audio --display-buffer=0
Restart=on-failure
RestartSec=3

kinneko@pi3a:~ $ sudo systemctl daemon-reload

kinneko@pi3a:~ $ sudo vi /etc/udev/rules.d/99-THINKLET.rules
ACTION=="add", SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="90b8", RUN+="/bin/systemctl start scrcpy.service"
ACTION=="remove", SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="90b8", RUN+="/bin/systemctl stop scrcpy.service"

kinneko@pi3a:~ $ sudo udevadm control --reload-rules
kinneko@pi3a:~ $ sudo udevadm trigger
```

　USBにTHINKLETを差し込むと、自動起動してくるようになった。
