　記事ネタにするのに、M5StickC Plus2を買ってくる。

　CとC Plusは持っているのだけど、今は買えないものを記事のネタにするのもどーかなと思って。

　薄いオレンジ色があんまり好きじゃないので買ってなかったのだった。記事でNanoC6にOLEDユニットとIRリモコンユニットを接続して、簡易送受信リモコンしようかと思ったのだけど、GroveコネクタがI2Cしか対応していないので、共存は無理そうということで、こちらにした。

　購入はマルツの店頭で。価格面でATOMとDialと迷ったのだけど、C派としてはこれにしておいた。前回行ったときには前モデルのPlusの在庫も時計バンド付きがあったのだけど、今はすっかりなくなっていた。7/27

> M5StickC Plus2 M5STACK-K016-P2 M5Stack製｜電子部品・半導体通販のマルツ<br>
> <https://www.marutsu.co.jp/pc/i/2777172/>

![](/2024-08-01/8295998-01.png)

　パッケージには、Type-Cの電源ケーブルが付属しない。コストダウンかな。

　ケースの色は、濃いオレンジのPlusだったのが、薄いオレンジのみかん色的なPlus2に変わっている。ディスプレイのサイズは1.14インチ(解像度135×240)と、Plusと同じ。

　中身としては、SoCがESP32-PICO-D4からESP32-PICO-V3-02に変更されている。それに伴って、PlusがFlash 4MB/SRAM 520KBだったのが、Plus2ではFlash 8MB/SRAM 2MBとだいぶ増えている。

　搭載バッテリーは、120mAhから200mAhに増量。UART変換デバイスがPlusのCH522から、Plus2ではCH9102に変更されてる。

　ハード的に大きな変更と言えるのは、あまり評判がよくなかった電源制御用のAXP192が削除されてるあたり。LED(G10)と赤外LED(G9)も、Plusでは別々に配線されていたけれど、Plus2ではどちらのLEDも配線は同じG19だけになっている。個別に制御はできないということだ。さらに論理も反転してHighで点灯になっている。PMICが廃止されたので、電源ボタン(ボタンC)の制御がG35でできる。

　ペリフェラル類は、赤LED、IR送信、マイク SPM1423、６軸IMU(MPU6886)、ボタン３つ、ブザーというのは変わらない。

　製品を改良しようという気持ちもわからないでもないけど、スペックがコロコロ変わってしまうのもホビー用途以外には使いにくいというか使えない感じがあるね。

　パッケージはこんな感じ。ブリスターだけど、だいぶコンパクトになっている。

　サンプルスケッチはこんな感じ。Basicしかないのが面白い。Unifiedでいろいろ吸収隠蔽してゆく方向なのでかな。

![](/2024-08-01/8295998-09.png)

　LEDのサンプルスケッチはこんな感じ。setup()は画面に「Power LED」と緑文字を表示しているだけなので、Lチカとは関係がない。loop()のほうでLチカをしている。M5StickCPlus2ですっかり隠蔽されて、GPIOの指定も特にない。StickCP2.Power.setLed()するだけ。0/1で指定するのだけど、もうStickCP2.Power.setLed.on/offくらいにしたらいいのに...

　シリアルも、以前のモデルは、cu.MyM5StickC-ESP32SPPやcu.MyM5StickCPLUS-ESP32SPPと認識していたのだけど、

```
#include "M5StickCPlus2.h"

void setup() {
    auto cfg = M5.config();
    StickCP2.begin(cfg);
    StickCP2.Display.setRotation(1);
    StickCP2.Display.setTextColor(GREEN);
    StickCP2.Display.setTextDatum(middle_center);
    StickCP2.Display.setTextFont(&fonts::Orbitron_Light_24);
    StickCP2.Display.setTextSize(1);
    StickCP2.Display.drawString("Power LED", StickCP2.Display.width() / 2,
                                StickCP2.Display.height() / 2);
}

void loop() {
    // inside power red led control
    StickCP2.Power.setLed(1);
    delay(1000);
    StickCP2.Power.setLed(0);
    delay(1000);
}
```
