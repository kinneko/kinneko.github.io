　マウスカーソルが残る問題はとりあえず棚上げにする。

　adbコマンドのインストール。

```text
kinneko@pi3a:~ $ sudo apt install adb
```

　scrcpyをビルドするツールを入れる。

```text
kinneko@pi3a:~ $ sudo apt install libavformat-dev libsdl2-dev libavdevice-dev libusb-1.0-0-dev
```

　scrcpyソースコードをcloneする。

```text
kinneko@pi3a:~ $ git clone https://github.com/Genymobile/scrcpy
```

　scrcpyをビルド。

```text
kinneko@pi3a:~ $ cd scrcpy/
kinneko@pi3a:~/scrcpy $  ./install_release.sh
```

　scrcpyのビルド結果の確認。

```text
kinneko@pi3a:~/scrcpy $ which scrcpy
/usr/local/bin/scrcpy
kinneko@pi3a:~/scrcpy $ scrcpy --version
scrcpy 2.6.1 <https://github.com/Genymobile/scrcpy>
(snip)
```

　scrcpyのビルド環境の削除。

```text
kinneko@pi3a:~/scrcpy $ cd ..
kinneko@pi3a:~ $ rm -rf scrcpy/
```
