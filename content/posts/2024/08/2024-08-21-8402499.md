　せっかくケースのプリントしたのに、パネルが変わってしまったので、違う設計のものにしないといけない。うーん。

　こちらは、四隅にネジ穴のないタイプ。サイズはタイトにできるけど、固定方法が課題になるやつ。

　とりあえず、手元にある５インチのパネルで作業を継続する。

　前の分厚い筐体に入れてみる。だいぶ小さくはなるね。厚さは６割くらいの感じ。薄くするのであれば、背面ケースの固定方法が悩ましい感じになるかな...

![](/2024-08-21/8402499-002.png)

　パネルの四隅にある穴は、ネジになっているのかと思ったけど、そうでもないみたいだ。

![](/2024-08-21/8402499-003.png)

　SDカードは焼き直してしまったので、ここまでやったことを再度実行する。

　ディスプレイの輝度を下げる。５インチのほうは、輝度を下げても視認性が高い。

```
kinneko@pi3a:~ $ sudo su -c "echo 50 > /sys/class/backlight/10-0045/brightness"
```

　LXDEのレベルでディスプレイ回転の永続化。

```
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
(追記)
@xrandr --output DSI-1 --rotate right
```

　タッチのキャリブレーション。

```
kinneko@pi3a:~ $ sudo vi /etc/X11/xorg.conf.d/99-calibration.conf
Section "InputClass"
    Identifier      "calibration"
    MatchProduct    "10-0038 generic ft5x06 (00)"
    Option          "TransformationMatrix" "0 1 0 -1 0 1 0 0 1"
EndSection
```

　LXDEのレベルで画面の自動スリープを抑制する。

　xset s off でスクリーンセーバーを無効に、xset -dpms でDPMS(ディスプレイパワーマネジメントシグナル)を無効にする。

```
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
(以下追記)
@xset s off
@xset -dpms
```

　LXDEのパネルとpcmanfmとxscreensaverを停止する。

```
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
#@lxpanel --profile LXDE-pi
#@pcmanfm --desktop --profile LXDE-pi
#@xscreensaver -no-splash
```

　マウスカーソルを表示用の画像を消す方法で削除したのだけど、これはWaylandでは有効だったけど、xorgではダメっぽい。消えなかった。

　これもLXDEの設定で設定しておく。

```
kinneko@pi3a:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
@xsetroot -cursor_name none
```

　ここで一旦再起動。

```
kinneko@pi3a:~ $ sudo reboot
```

　しばらく放置すると画面が黒くなるので、スリープ抑制も効いてないか。

　確認しても効いてないわ。

```
kinneko@pi3a:~ $ DISPLAY=:0 xset q | grep "timeout"
  timeout:  600    cycle:  600
kinneko@pi3a:~ $ DISPLAY=:0 xset q | grep "DPMS is"
  DPMS is Disabled
```

　前のときの設定はこのへんか。これでうまくいっていたのだけどな。

　マウスカーソルは消えてないな... Pi2のときはどうやって消したのだっけか...

　まず、xorgがどうやって起動されているか調べてみる。display-manager.serviceで動いている。ファイルの実態はlightdm.serviceだった。その中で起動されているのは、lightdmだ。

```
kinneko@pi3a:~ $ ls -l /etc/systemd/system/display-manager.service
lrwxrwxrwx 1 root root 35 Jul  4 09:09 /etc/systemd/system/display-manager.service -> /lib/systemd/system/lightdm.service
```

```
kinneko@pi3a:~ $ cat /lib/systemd/system/lightdm.service
[Unit]
Description=Light Display Manager
Documentation=man:lightdm(1)
After=systemd-user-sessions.service
```

```
# replaces plymouth-quit since lightdm quits plymouth on its own
Conflicts=plymouth-quit.service
After=plymouth-quit.service
```

```
# lightdm takes responsibility for stopping plymouth, so if it fails
# for any reason, make sure plymouth still stops
OnFailure=plymouth-quit.service
```

```
[Service]
ExecStart=/usr/sbin/lightdm
Restart=always
BusName=org.freedesktop.DisplayManager
```

```
[Install]
Alias=display-manager.service
```

　startxやxinitに-nocursorパラメーターを指定して、カーソルを消そうと思ったけど、lightdm経由で動作しているということであれば、そういう設定もできないな。

　lightdmの設定ファイルを見てみる。このへんが使えるかな？

```
kinneko@pi3a:~ $ cat /etc/lightdm/lightdm.conf
# xserver-config = Config file to pass to X server
#xserver-config=
```
