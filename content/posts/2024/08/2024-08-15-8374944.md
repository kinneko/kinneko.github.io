　CM4はAliexpressで買えるのだけど、入手性ははっきり言ってよくない。SKYに問い合わせて相談によっては売ってもらえるという感じ。Aliexpressで買うこともできるし、遊びの分はすでに買ってあるけど、仕事で使うことになったら消費税やら関税やらでめんどくさそう。

　CM4にドーターボードをつけると、どうしてもその分分厚くなってしまうので、コンパクトに仕上がらない問題もある。

　その点、Pi 3 Model A+ならば、NICがない分、高さが低くなるしDSIポートも付いている。

　パフォーマンスに問題がなければ、これでもいいかな。

　Pi3になるので、Pi4と比べて、CPUパワーとRAMがちょっと足りない。CPUのほうは、Broadcom BCM2837B0 Cortex-A53 (ARMv8) 64-bit 1.4GHzなので、まったく足りないということはないのだけど、RAMが512MB LPDDR2 SDRAMなのがだいぶつらいけど。

　Pi3だと、RaspiOSではWaylandは動かない。X11での動作になる。最初のPi2の時のノウハウをロールバックする必要がある感じ。んで、電源がmicro Bなのはちょっとイマイチ。

　残念なのは、すでにEoLが出ていて、在庫限りなところ。しかし、市場にはまだ潤沢にある感じ。最初は、2018年に$25で出ているのか。円が高い頃はもっと安かったのだろうな...

　scrcpyをPi2で動かしたときには、システムパワーが足りなくて、タッチ操作がスムースではなかった。Pi3では試していないな。そのまま手元のPi4にしてしまったし。やってみる価値はあるか。今日はマルツは休みだけど、幸い、Pi3 Model Bなら手元にある。

　というわけで、マルツで5k円散財する前に、手持ちのPI3Bで動作テストする。

　X11が動いているのがわかる。

```
kinneko@pi3:~ $ ps ax | grep xorg
    893 tty7     Ssl+   0:00 /usr/lib/xorg/Xorg :0 -seat seat0 -auth /var/run/lightdm/root/:0 -nolisten tcp vt7 -novtswitch
```

　レインボースプラッシュから、X11が起動するまでの時間は36秒くらいかかっている。だいぶ違いがあるな。つらい。

```
kinneko@pi3:~ $ sudo apt-get update && sudo apt-get upgrade -y
```

　メモリはやっぱり厳しい。

```
kinneko@pi3:~ $ free -h
               total        used        free      shared  buff/cache   available
Mem:           907Mi       172Mi       248Mi       300Ki       551Mi       735Mi
Swap:          199Mi       135Mi        64Mi
```

　モニターの解像度などを確認。

```
kinneko@pi3:~ $ DISPLAY=:0 xrandr --listmonitors
Monitors: 1
 0: +DSI-1 800/212x480/127+0+0  DSI-1
```

　まぶしいので輝度を下げる。なんか画面の色が薄いような気もする。

```
kinneko@pi3:~ $ sudo su -c "echo 50 > /sys/class/backlight/10-0045/brightness"
```

　ディスプレイの回転。

```
kinneko@pi3:~ $ DISPLAY=:0 xrandr --output DSI-1 --rotate right
```

　ディスプレイ回転の永続化。ユーザーレベルの設定ではなく、LXDEのレベルで設定を強制する。

```
kinneko@raspberrypi:~ $ sudo vi /etc/xdg/lxsession/LXDE-pi/autostart
(追記)
@xrandr --output DSI-1 --rotate right
```

　再起動して反映を確認する。

```
kinneko@pi3:~ $ sudo reboot
```

　タッチキャリブレーション。

　Waylandではそういうことがなかったのだけど、X11では画面の回転だけすると、タッチのキャリブレーションも変わってしまっている。画面は縦表示レイアウトになったのだけど、タッチは横表示のままになっていて、タッチした情報とスクリーン上のカーソル位置が合わなくなってしまう。これも設定する必要がある。

　とりあえず、xinput-calibratorを入れて、値をとってみる。

```
kinneko@pi3:~ $ sudo apt-get install xinput-calibrator
Reading package lists... Done
```

　起動して情報を取る。

```
kinneko@pi3:~ $ DISPLAY=:0 xinput_calibrator
Calibrating standard Xorg driver "10-0038 generic ft5x06 (00)"
	current calibration values: min_x=0, max_x=65535 and min_y=0, max_y=65535
	If these values are estimated wrong, either supply it manually with the --precalib option, or run the 'get_precalib.sh' script to automatically get it (through HAL).
	--> Making the calibration permanent <--
  copy the snippet below into '/etc/X11/xorg.conf.d/99-calibration.conf' (/usr/share/X11/xorg.conf.d/ in some distro's)
Section "InputClass"
	Identifier	"calibration"
	MatchProduct	"10-0038 generic ft5x06 (00)"
	Option	"MinX"	"53987"
	Option	"MaxX"	"53532"
	Option	"MinY"	"19394"
	Option	"MaxY"	"19230"
	Option	"SwapXY"	"1" # unless it was already set to 1
	Option	"InvertX"	"0"  # unless it was already set
	Option	"InvertY"	"0"  # unless it was already set
EndSection
```

　/etc/X11/xorg.conf.d/99-calibration.confを作成して、上記の設定をもとに270度回転したデータを作成して記入する。

　ダメ。

```
kinneko@pi3:~ $ sudo rm /etc/X11/xorg.conf.d/99-calibration.conf
```

　むーりー。Pi2の時にやっていたやり方でもbookwormではうまくいかないわ。もうWaylandにしておこう。

```
kinneko@pi3:~ $ sudo raspi-config
```
