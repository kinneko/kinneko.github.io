　チビチビとブログの移行を進めてはいるけど、すでになんかcontent/postsがmdで溢れかえっている。なんか先を考えるとヤバい。

![](/2025-12-17/xWXbil4E81hPq6yhe0NB7SHg.png)

　まだそれほど移行していないのに、ビルドに時間がかかるようになってきているのも気になる。一部は固定化しないといけないかもしれない。いまのところ、こんな感じ。

![](/2025-12-17/U6SRJkhkpIdyIwQhHbbbWPAA.png)

　とりあえず前者の対応をしたい。

　Zolaはcontent/ 配下のディレクトリ階層をそのまま「セクション（section）」として扱えるので、content/posts/2025/12/のように年・月でフォルダ分けして管理することができる。

　年間200投稿以上あるので、年と月で分けたいところ。

　作成したそれぞれのディレクトリに_index.mdを置く必要がある。これがあると、そのディレクトリはsectionとして扱われる。

```
年/月でsectionが分かれると、テーマ側が section.pages だけを見ている場合に「親（posts）に記事がいない」状態になってしまう。これを避けるためには、年/月の_index.mdを transparent = true に設定する。すると、子のページを親セクションに渡すことができる。
```

　content/posts/2025/_index.mdとcontent/posts/2025/12/_index.mdを以下の内容で作成しておく。

　+++

```
transparent = true
render = false
```

　+++

```
transparent = trueは、子セクション配下の記事を親に“渡す”設定。これを設定しておくと、posts の一覧・ページネーションが崩れにくい。
render = falseは、年/月のセクション自体のページ（/posts/2025/ 等）を生成しない設定。
```

```
% pwd
```

　~/Documents/fanbox-zola/content/posts

```
% mkdir -p 2025/12
% vi 2025/_index.md
% cp 2025/_index.md 2025/12
```

　コンテンツを移動する。

```
% mv 2025*.md 2025/12/
```

　見た目はまったく変化がない。

![](/2025-12-17/Ni3670Gf6WA0Gojl0phU6U0A.png)

　コンテンツのパスは、posts/2025-11-28/から、posts/2025/11/2025-11-28/みたいに変わる。

　他の月もやっておく。

```
% mkdir -p 2019/10
% mkdir -p 2019/11
% cp 2025/_index.md 2019
% cp 2025/_index.md 2019/10
% cp 2025/_index.md 2019/11
% mv 2019-10-*.md 2019/10/
% mv 2019-11-*.md 2019/11/
```

　だいぶすっきりした。

```
% ls
```

　2019		2025		_index.md
