　ログインしただけで、毎回これが出るようになってしまった。めんどくさい。


```
(base) root@m5stack-LLM:~#
```


　ログインするたびにconda deactivateを毎回やるのはめんどくさい。だいたい、condaをおぼえていないし、deactivateのスペルも怪しい。

　ログインシェルが起動してくるまでにも、少し時間がかかるようになってしまった。よくない。


　condaの設定でベース環境の自動アクティベーションを無効にする方法でも抑制できるらしいけど、condaとかもう使わないもんな...


　　conda config --set auto_activate_base false


　シェルの設定を見ると、こんなのが差し込まれている。


```
root@m5stack-LLM:~# vi .bashrc
(snip)
# >>> conda initialize >>>
# !! Contents within this block are managed by 'conda init' !!
__conda_setup="$('/root/miniconda3/bin/conda' 'shell.bash' 'hook' 2> /dev/null)"
if [ $? -eq 0 ]; then
    eval "$__conda_setup"
else
    if [ -f "/root/miniconda3/etc/profile.d/conda.sh" ]; then
        . "/root/miniconda3/etc/profile.d/conda.sh"
    else
        export PATH="/root/miniconda3/bin:$PATH"
    fi
fi
unset __conda_setup
# <<< conda initialize <<<
(snip)
```


　コメントアウトして終了。
