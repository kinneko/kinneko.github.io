　座談会で、@cinimlさんが、自前ビルドにはツールが入ってない的なことを言ってたので調べた。

![](/2025-02/9344180-02.png)

　　Module LLM ファームウェアアップグレードガイド

　　https://docs.m5stack.com/ja/guide/llm/llm/image

　ubuntu_rootfs_sparse.ext4が3.2Gもあるのがデカさの原因のようだ。スパース展開すると30GBくらいになるのかな。


　スパースファイルをext4イメージに変換する。結構時間かかる。デカいものな。


```
kinneko@llmbuild:~/imgtest$ simg2img ubuntu_rootfs_sparse.ext4 ubuntu_rootfs.ext4
```


　まぁ、こんなサイズになるよね。eMMCが32Gなので、それ以上ではないけど。


```
kinneko@llmbuild:~/imgtest$ ls -alh ubuntu_rootfs*
-rw-rw-r-- 1 kinneko kinneko  29G Feb  7 04:35 ubuntu_rootfs.ext4
-rw-r--r-- 1 kinneko kinneko 3.2G Dec  5 09:04 ubuntu_rootfs_sparse.ext4
```


　ちゃんとext4イメージとして認識している。


```
kinneko@llmbuild:~/imgtest$ file ubuntu_rootfs.ext4
ubuntu_rootfs.ext4: Linux rev 1.0 ext4 filesystem data, UUID=57f8f4bc-abf4-655f-bf67-946fc0f9f25b (extents) (large files)
```


　マウントしてみる。


```
kinneko@llmbuild:~/imgtest$ sudo mkdir /mnt/2nd
kinneko@llmbuild:~/imgtest$ sudo mount -o loop ./ubuntu_rootfs.ext4 /mnt/2nd
```


　まぁ、普通だね。


```

kinneko@llmbuild:~/imgtest$ mkdir self
```

　スパースファイルのファイル名が違っている。サイズもだいぶ小さい。


```
kinneko@llmbuild:~/imgtest/self$ ls -alh rootfs_sparse.ext4
-rw-r--r-- 1 kinneko kinneko 579M Feb  4 06:09 rootfs_sparse.ext4
```


　スパースファイルを展開してみる。


```
kinneko@llmbuild:~/imgtest/self$ simg2img rootfs_sparse.ext4 rootfs.ext4
kinneko@llmbuild:~/imgtest/self$ ls -alh rootfs*
-rw-rw-r-- 1 kinneko kinneko  29G Feb  7 04:53 rootfs.ext4
-rw-r--r-- 1 kinneko kinneko 579M Feb  4 06:09 rootfs_sparse.ext4
```


　マウントするか。


```
kinneko@llmbuild:~/imgtest/self$ sudo mkdir /mnt/self
kinneko@llmbuild:~/imgtest/self$ sudo mount -o loop ./rootfs.ext4 /mnt/self
```


　ファイルリストを取る。


```
kinneko@llmbuild:~/imgtest/self$ sudo mkdir /mnt/self
kinneko@llmbuild:~/imgtest/self$ sudo mount -o loop ./rootfs.ext4 /mnt/self
kinneko@llmbuild:~/imgtest/self$ cd /mnt/self/
kinneko@llmbuild:/mnt/self$ sudo find ./ > ~/self.list
kinneko@llmbuild:/mnt/self$ head ~/self.list
./
./lost+found
./bin
./boot
./dev
./dev/null
./etc
./etc/.pwd.lock
./etc/ModemManager
./etc/ModemManager/connection.d
```


　２つのファイルリストができたので、差分を取る。


```
kinneko@llmbuild:~$ diff 2nd.list self.list
```


　ここに貼るのはデカいので、gistに置く。


　　M5LLMの2nd FWとbuildrootで作成したFWの違い

　　https://gist.github.com/kinneko/0d22813a3088c4df93e245bf68f65dd6


　多くはパッケージ構成の違いと、pipかなにかで入っているpythonライブラリの違いなんだけど、optとかに入っているllm-*とかはごっそりないね。
