　LLMモジュールに一度に複数のUSBデバイスを接続するには、導入したUSB OTGアダプタにはUSBポートが１口しかないので難しい。

　そこでUSB HUBを使ってみることにした。手持ちのUSB HUBが、ホスト側がType-Cだったり、サイズが大きめだったりするので、新しく調達する。

　どこででも同じものが安く入手できるという理由で、ダイソーで550円のスリムなUSB HUBを買ってきた。

![](/2025-01-21/9194255-01.png)

![](/2025-01-21/9194255-02.png)

　普通に認識した。その先にUSB NICを差し込んだら、こちらも普通に使えている。当たり前かw

　root@m5stack-LLM:~# lsusb

　Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub

　Bus 001 Device 004: ID 05ac:1402 Apple, Inc. Ethernet Adapter [A1277]

　Bus 001 Device 003: ID 1a40:0101 Terminus Technology Inc. Hub

　Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
