　さて、自由に日本語を表示するためには、いちいちグリフを作っていられない。

![](/2025-07-30/10283070-01.png)

　美咲フォントのデータをArduinoで使えるようにライブラリ化している方がいるので、それを使わせてもらう。

　GitHub - Tamakichi/Arduino-misakiUTF16: Arduino用 美咲フォントライブラリ 教育漢字・内部フラッシュメモリ乗せ版

https://github.com/Tamakichi/Arduino-misakiUTF16

　使えるのは、教育漢字1,006字＋ひらがな・カタカナ・記号・半角等の1,710字だそうだ。メモリ消費は約16kバイト。最近のESP32とかでは問題ないね。

　残念ながら、ArduinoIDEのライブラリには登録されていない。手動でzipを取り込む。

　ダウンロードはこちらからzipをもらう。

　Release Arduino用 美咲フォントライブラリ 教育漢字・内部フラッシュメモリ乗せ版 1.03 · Tamakichi/Arduino-misakiUTF16 · GitHub

https://github.com/Tamakichi/Arduino-misakiUTF16/releases/tag/1.03

　Arduino IDEを開いて、[スケッチ] -> [ライブラリをインクルード] -> [.ZIP形式のライブラリをインストール...]でzipを選択してインストールする。

　「指定されたフォルダ／zipファイルには有効なライブラリがありません」とエラーになった。展開してみると、そのまま使えないリポジトリのアーカイブになっている。つらい。

　misakiUTF16フォルダだけをzipアーカイブして、Arduino IDEで指定したら読み込めた。

　% ls ~/Documents/Arduino/libraries/misakiUTF16

　examples		misakiUTF16.cpp		misakiUTF16FontData.inc

　keywords.txt		misakiUTF16.h

　スケッチをビルドするとエラーになった。

　どうやら、misakiUTF16.h は <avr/pgmspace.h> を参照しているようだ。AVR系マイコン用のヘッダなのでESP32では使えない。

　AIを駆使して、pgmspaceの対応コード潰しているけど、なんかキリがない感じでエラーになるわ...

　Xでボヤいていたら、アドバイスもらった。

　朝日薫/multix.jp on X: "@kinneko pgmspaceは別段難しいことはやってないので、手でラッパー書いた方が早いんじゃないかな。単にコードアドレス空間のバイト群を、レジスタや、データアドレス空間に転写したりするだけなので。" / X

https://x.com/askn37/status/1949014405624320332

　なるほど。

　AIに書いてもらう。

```text
#define _PGMSPACE_H_
```

```text
// PROGMEM は無効化（無視される）

```

```text
// pgm_read_byte などを単なるポインタ読み込みで置き換え
#define pgm_read_byte(addr) (*(const uint8_t *)(addr))
#define pgm_read_word(addr) (*(const uint16_t *)(addr))
#define pgm_read_dword(addr) (*(const uint32_t *)(addr))
#define pgm_read_float(addr) (*(const float *)(addr))
```

```text
// memcpy_P は通常の memcpy と同義
#define memcpy_P(dest, src, num) memcpy((dest), (src), (num))
```

```text
// strcpy_P も同様に置き換え
#define strcpy_P(dest, src) strcpy((dest), (src))
```

```text
// PSTR マクロ：単なる文字列として返す（フラッシュ展開なし）
#define PSTR(s) (s)
```

#endif // _PGMSPACE_H_
