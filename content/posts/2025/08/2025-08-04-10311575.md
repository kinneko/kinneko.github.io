u8g2_font_unifont_t_japanese1を指定すると、日本語も表示できるそう。

![](/2025-08-04/10311575-qInsQMyg.png)

　やってみる。

```
#include <Arduino.h>
#include <U8g2lib.h>
#include <Wire.h>
#define SDA_PIN (26)
#define SCL_PIN (32)
// 日本語対応フォントを使用（例: unifont、フルバッファ使用）
```

　U8G2_SSD1306_72X40_ER_F_HW_I2C u8g2(U8G2_R0, /* reset=*/U8X8_PIN_NONE);

```
void setup(void){
Wire.begin(SDA_PIN, SCL_PIN);
u8g2.begin();
u8g2.enableUTF8Print();  // UTF-8を扱うために必要
}
```

```
void loop(void){
u8g2.clearBuffer();
// 日本語対応フォント（漢字も対応）
u8g2.setFont(u8g2_font_unifont_t_japanese1);
// UTF-8で直接出力（drawStrではなくprintで描画）
u8g2.setCursor(0, 24);
u8g2.print("寿司食いてー！");
u8g2.sendBuffer();
delay(1000);
}
```

　表示がハミ出てセンタリングされて、「司食いてー」と表示されている。フォントサイズ的には２行半くらいは表示できそうな感じ。日本語表示そのものは簡単ね。

　表示が切れるのは、u8g2内部の描画バッファは初期化時に72x40に指定されているので、センタリングされて、そこからはみ出るものは切れてしまっているのかな？

　ん？ そっか、「寿」と「！」がデフォルトのフォントセットに含まれていないようだ。

　寿と！を別のフォントに変更すると、ちゃんと「す司食いて」の「て」の前半くらいまで表示された。

```
u8g2.print("す司食いてーよ");
```

![](/2025-08-04/10311575-qMk1nMKA.png)

　スケッチはこんな感じ。

```
#include <Arduino.h>
#include <U8g2lib.h>
#include <Wire.h>
#include "u8g2_font_unifont_myfonts.h"
```

```
#define SDA_PIN 26
#define SCL_PIN 32
```

　U8G2_SSD1306_72X40_ER_F_HW_I2C u8g2(U8G2_R0, /* reset=*/U8X8_PIN_NONE); // EastRising 0.42\" OLED

```
const char* japaneseText = "寿司食いてー！";
int textWidth;
int xPos;
```

```
void setup(void)
{
Wire.begin(SDA_PIN, SCL_PIN);
u8g2.begin();
u8g2.enableUTF8Print(); // Enable UTF-8 support for Japanese characters
u8g2.setFont(u8g2_font_unifont_myfonts); // Use custom Japanese font
textWidth = u8g2.getUTF8Width(japaneseText);
xPos = u8g2.getDisplayWidth(); // Start text from right edge of the display
}
```

```
void loop(void)
{
u8g2.clearBuffer();
u8g2.drawUTF8(xPos, 15, japaneseText);
u8g2.sendBuffer();
```

　xPos--; // Move text to the left by 1 pixel

```
// If text has scrolled completely off the left, reset its position to the right
if (xPos < -textWidth) {
xPos = u8g2.getDisplayWidth();
}
delay(20); // Adjust this value to change scrolling speed
}
```
