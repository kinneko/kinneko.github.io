　Puzzle Unitがイマイチだったので、買ってあったけど使ってなかったOLED UNITを使ってみることにする。ターゲットマイコンは、ATOM Liteをそのまま使用する。

　OLED UNITは、税込704円なので、表示装置としては比較的安価。でも、えらく小さい。72x40なので、8x8のフォントだと複数行表示もできそうだな。しかし、このくらいのOLEDモジュールだと、ここまで小さくなくてもいいのであれば100円台でありそう。

> M5Stack用 0.42インチ Mini OLEDユニット — スイッチサイエンス<br>
> <https://www.switch-science.com/products/9196>

　とりあえず、公式のサンプルスケッチを見る。

> M5Stack/examples/Unit/MiniOLED/MiniOLED.ino at master · m5stack/M5Stack · GitHub<br>
> <https://github.com/m5stack/M5Stack/blob/master/examples/Unit/MiniOLED/MiniOLED.ino>

```cpp
/*
 * SPDX-FileCopyrightText: 2025 M5Stack Technology CO LTD
 *
 * SPDX-License-Identifier: MIT
 */
/*
 * @Hardwares: M5Core + Mini Unit OLED
 * @Platform Version: Arduino M5Stack Board Manager v2.1.3
 * @Dependent Library:
 * M5Stack@^0.4.6: https://github.com/m5stack/M5Stack
 * U8g2_Arduino: https://github.com/olikraus/U8g2_Arduino
 */

#include <Arduino.h>
#include <U8g2lib.h>
#include <Wire.h>

#define SDA_PIN (21)
#define SCL_PIN (22)

U8G2_SSD1306_72X40_ER_F_HW_I2C u8g2(U8G2_R0, /* reset=*/U8X8_PIN_NONE);  // EastRising 0.42" OLED

void setup(void)
{
    Wire.begin(SDA_PIN, SCL_PIN);
    u8g2.begin();
}

void loop(void)
{
    u8g2.clearBuffer();                  // clear the internal memory
    u8g2.setFont(u8g2_font_ncenB08_tr);  // choose a suitable font
    u8g2.drawStr(10, 20, "Hello");       // write something to the internal memory
    u8g2.drawStr(10, 30, "M5Stack!");
    u8g2.sendBuffer();  // transfer internal memory to the display
    delay(1000);
}
```

　ターゲットがATOM Liteなので、ピンが26,32なので違っている。

　モノクロOLED/液晶ディスプレイ用グラフィックライブラリU8g2を使っている。フォントも含まれている。

　アウトプットはこんな風。

![](/2025-08-01/10305909-05.png)

　Puzzle Unitと比べて、文字数が多く表示できそう。表示面積は小さいけど。

　なんかのステイタスを表示するのには使えそうだけど、小さ過ぎて日常的に何かするには向かない感じ。LEDテープを先に接続するのに、ステイトを表示したほうがいいかなという目的くらいかな。

　表示できるピクセル数は増えたので、日本語表示までやってみるか。
