　サービス化して、自動起動するようにしておく

　手放しで起動しただけで使えるようにサービス化しておく。

```

root@m5stack-LLM:~# vi /etc/systemd/system/llmwake.service
root@m5stack-LLM:~# cat /etc/systemd/system/llmwake.service
[Unit]

```

Description=Telnet JSON Communication Service for LLM

After=multi-user.target

```

[Service]

```

Type=simple

ExecStart=/usr/bin/python3 /root/llm.py

Restart=always

RestartSec=5

User=root

WorkingDirectory=/root

```

[Install]

```

WantedBy=multi-user.target

```

root@m5stack-LLM:~# systemctl enable llmwake.service

```

Created symlink /etc/systemd/system/multi-user.target.wants/llmwake.service → /etc/systemd/system/llmwake.service.

```

root@m5stack-LLM:~# systemctl start llmwake.service

```

root@m5stack-LLM:~# systemctl status llmwake.service

　応答の音量を大きくする

　デフォルトの音量だと、TTSのアウトプット音が小さい。

　設定は、Audioの中でやる。パラメータは"playVolume": 0.5のところ。騒々しい展示場所でのデモに使う予定なので、最大は10なので10にしておくかな。

　10にしても、そこまでデカくはないのはスピーカーがこんなチャチなやつなので仕方がないか。

　応答準備ができたらわかるようにする

　システムの起動は、音とLEDでわかるのだけど、llmサービスの準備ができたのがわからないのは不便だ。音は別に作るのが面倒なので、LEDも色を変えるかな。

　起動中は赤で、起動後は緑なので、安直に使っていない青にしとく。

　subprocessとかめんどい。返り値は取れなくていいので、osモジュールでos.systemで起動したらいいかな。

```

import os
os.system("echo 0 > /sys/class/leds/R/brightness; echo 0 > /sys/class/leds/G/brightness; echo 255 > /sys/class/leds/B/brightness")

```
