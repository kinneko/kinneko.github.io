　TouchDisplay2でタッチが効かなくなる問題は、どうも、起動後にrebootした後はダメになる感じ。

![](/2025-11-05/Ggj26S4k3BNuj3wbBJsPo9O2.png)

　ドライバのロードメッセージを見てみる。

　正常なときはこう。

```
fd@pi3b:~ $ dmesg | grep Goodix
[   10.358666] Goodix-TS 10-005d: supply VDDIO not found, using dummy regulator
[   10.447665] Goodix-TS 10-005d: ID 911, version: 1060
[   10.465138] input: 10-005d Goodix Capacitive TouchScreen as /devices/platform/soc/3f205000.i2c/i2c-11/i2c-10/10-005d/input/input0
```

　rebootしたときはこれ。

```
fd@pi3b:~ $ dmesg | grep Goodix
[    7.563941] Goodix-TS 10-005d: supply VDDIO not found, using dummy regulator
[    7.627625] Goodix-TS 10-005d: Error reading 1 bytes from 0x8140: -5
[    7.651622] Goodix-TS 10-005d: Error reading 1 bytes from 0x8140: -5
[    7.675364] Goodix-TS 10-005d: I2C communication failure: -5
[    7.676273] Goodix-TS 10-005d: probe with driver Goodix-TS failed with error -5
```

　ドライバが、I2Cの先にあるタッチデバイスを探したのだけど、失敗してエラーを出している。

　これは、毎回完全に電源抜いて入れ直す(コールドブートする)必要があるようだ。

　この動きの違いはこれだろうな...

> Touch Display 2買ってみた -1-｜kinneko｜pixivFANBOX<br>
> <https://kinneko.fanbox.cc/posts/10708996>

![](/2025-11-05/P8OfhSHvlxstn1BaQfabpo7P.png)

　ウォームブートのときには、この電源が通電しっぱなしなので、DSIのマイコンがリセットされない。Goodix-TSはDSIコントローラー配下にあるので、こちらも当然リセットされない。

　つまり、再起動前のI2Cの設定が残ってしまっていて、マイコン側は新規の接続を受け付けなくなっている。

　Touch Display 2のタッチ部はGoodix GT911互換コントローラ（I2C接続、通常 bus 10 / address 0x5d）を使っていて、このチップは電源投入直後のリセットシーケンス（RST + INT ピン制御）を要求するそうだ。再起動時はRaspi側のGPIO/I2Cがリセットされず、Goodix側が古い状態のまま応答しなくなる。goodix_tsドライバは起動時にI2Cに応答がないと「probe failed -5」で諦めるので、その後ロードされても復帰できない。

　本来は、ハード的にはDSIマイコンのコントローラーのファームでデバイスが接続したときにはリセットすべき感じかな。もしくは、dtbでリセットするか。それとも、デバイスドライバ側でリセット処理を入れるか。

　もっとも、GoodixのリセットピンがRaspi側から見えるように外に出ているわけではないので、Raspi側からの制御は難しいかも。少なくともdtsを書き換えたくらいだと無理そう。

　純正プロダクトなのに、なんてお粗末な設計なんだろうなぁ... しかも、採用されているGoodixはAPI互換のクローン品らしい。

　調べてみると、タッチが効かなくなるという事例は純正７インチTouch Display 2の時からたくさんある感じ。対処したというメッセージもあるけど、その後もあいかわらずダメという反応も多い。

> Touch-functionality of Touch Display 2 stops working after reboot - Raspberry Pi Forums<br>
> <https://forums.raspberrypi.com/viewtopic.php?t=389937>

　waveshare品でも同じ問題がある感じ。こちらはなんでかわからないけど、解決されないままCloseしている。
