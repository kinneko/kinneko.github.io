　しょうがないので、再度SDを焼いて、アップグレード前のデフォルトを見てみる。

![](/2025-10-08/10682462-huwt1Z9mO8HryBDv1dcZCvRg.png)

　デフォルトのを焼くと、普通にDesktopが起動してくる。当たり前。

![](/2025-10-08/10682462-DAhRn0QEPSaFuQoVXZgDGxm8.png)

　ディスプレイマネージャはlightdmで変更されていない。

fd@pi5:~ $ systemctl status display-manager | cat

● lightdm.service - Light Display Manager

(snip)

　lightdmの設定も同じ。

fd@pi5:~ $ grep autologin-user /etc/lightdm/lightdm.conf

```
# autologin-user = User to log in with by default (overrides autologin-guest)
# autologin-user-timeout = Number of seconds to wait before loading default user
```

autologin-user=fd

#autologin-user-timeout=0

　lightdmのセッションはrpd-labwc。

fd@pi5:~ $ sudo lightdm --show-config

```
[Seat:*]
```

B  greeter-session=pi-greeter-labwc

B  greeter-hide-users=false

A  session-wrapper=/etc/X11/Xsession

B  user-session=rpd-labwc

B  display-setup-script=/usr/share/dispsetup.sh

B  autologin-user=fd

B  autologin-session=rpd-labwc

Sources:

A  /usr/share/lightdm/lightdm.conf.d/01_debian.conf

B  /etc/lightdm/lightdm.conf

　セッション名に該当するファイルはあるか調べる。

　あるじゃん。アップデートでこれが消えるのかな？

fd@pi5:~ $ ls /usr/share/wayland-sessions/

labwc.desktop  rpd-labwc.desktop

fd@pi5:~ $ cat /usr/share/wayland-sessions/rpd-labwc.desktop

```
[Desktop Entry]
Type=Application
Name=Raspberry Pi Desktop on Wayland
Exec=/usr/bin/labwc-pi
```

　rpd-wayland-coreパケージに含まれているらしい。

fd@pi5:~ $ dpkg -S /usr/share/wayland-sessions/rpd-labwc.desktop

rpd-wayland-core: /usr/share/wayland-sessions/rpd-labwc.desktop

　アップグレードしてみる。なんか、それっぽい感じのパッケージはないな。

fd@pi5:~ $ sudo apt update

fd@pi5:~ $ sudo apt upgrade

Upgrading:

chromium          openssl                  raspi-utils-otp

chromium-common   openssl-provider-legacy  raspinfo

chromium-l10n     pipanel                  rasputin

chromium-sandbox  raindrop                 rp-prefapps

libdtovl0         raspi-utils              rpcc

libgpiolib0       raspi-utils-core         wf-panel-pi

libssl3t64        raspi-utils-dt           wfplug-connect

lpplug-menu       raspi-utils-eeprom       wfplug-menu

Summary:

Upgrading: 24, Installing: 0, Removing: 0, Not Upgrading: 0

Download size: 166 MB

Space needed: 20.5 kB / 21.5 GB available

Continue? [Y/n] y

(snip)

　rpd-wayland-coreパケージは更新されていないな。

　再起動しても消えてないし... 当然ながらDesktopが起動してくる。

fd@pi5:~ $ cat /usr/share/wayland-sessions/rpd-labwc.desktop

```
[Desktop Entry]
Type=Application
Name=Raspberry Pi Desktop on Wayland
Exec=/usr/bin/labwc-pi
```

　なんでだよ...

　パッケージが移ったわけでもないようだ。

fd@pi5:~ $ dpkg -S /usr/share/wayland-sessions/rpd-labwc.desktop

rpd-wayland-core: /usr/share/wayland-sessions/rpd-labwc.desktop

　再現できないのなら、原因不明だな...

　ネタとして最悪のケースだわ...

　別の環境でも同じようなことが起こったので、ダメかも。安定するまで、Bookwormに戻します。
