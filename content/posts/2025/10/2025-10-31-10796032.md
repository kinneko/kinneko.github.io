　ついでに、デフォルトユーザーでの自動ログインを有効にしておく。

![](/2025-10-31/10796032-MUbmhV0xIY4bos2jWOcqoYQT.png)

```
GDM(GNOME Display Manager)の設定を変更する。
```

kinneko@pi4:~$ grep Automatic /etc/gdm3/custom.conf

```
#  AutomaticLoginEnable = true
#  AutomaticLogin = user1
```

kinneko@pi4:~$ sudo vi /etc/gdm3/custom.conf

```
AutomaticLoginEnable = true
AutomaticLogin = kinneko
```

　GDMを再起動する。

kinneko@pi4:~$ sudo systemctl restart gdm3

　TouchDisplay2は画面が縦がデフォルトなので、画面も横方向にしておく。

kinneko@pi4:~$ sudo vi /boot/firmware/config.txt

```
[pi4]
dtoverlay=vc4-kms-dsi-ili9881-5inch,rotation=90
```

　正常のときには見えるのだけど。

kinneko@fb4:~$ sudo dmesg | grep Touch

```
[   17.226655] input: 10-005d Goodix Capacitive TouchScreen as /devices/platform/soc/fe205000.i2c/i2c-22/i2c-10/10-005d/input/input13
```

　異常になると見えていない。

kinneko@fb4:~$ sudo dmesg | grep Touch

　なんとなく心当たりはあるけど、それは別のネタで。

　とりあえずの対応としては、rebootではタッチドライバが死ぬので、かならずコールドブートすること。

　手順整理：

　1.25.04(2025-04-17)をインストール。 25.10はダメ。24.04はタッチが効かない。

　2. HDMI, キーボード, マウスを接続して、インストールを完了する

　3. コンソールでopenssh-serverをインストール

　4. /boot/firmware/config.txtに"dtoverlay=vc4-kms-dsi-ili9881-5inch"を設定する

　5. AC電源供給時の自動サスペンドの設定を無効化

```
$ gsettings set org.gnome.settings-daemon.plugins.power sleep-inactive-ac-type 'nothing'
```

　6. 画面ブランク直前のディマー（画面減光）を無効化

```
$ gsettings set org.gnome.settings-daemon.plugins.power idle-dim false
```

　7. スリープを制御しているサービスを停止

```
$ sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

　8. GNOME の「アイドル時間（秒）」をゼロにする

```
$ gsettings set org.gnome.desktop.session idle-delay 0
```

　9. デフォルトユーザーでの自動ログインを有効化

```
$ sudo vi /etc/gdm3/custom.conf
AutomaticLoginEnable = true
AutomaticLogin = [ユーザー名]
```

　10. 画面を回転(電源を上)

```
$ vi ~/.config/monitors.xml
```

<monitors version="2">

<configuration>

<layoutmode>physical</layoutmode>

<logicalmonitor>
