　Raspberry Pi Touch Display 2を買ってあるのだけど、RaspiOSでしか使ったことがない。

![](/2025-10-27/10785973-QtGbYVRnSSRNA67uEngwOc32.png)

　そもそもこれってUbuntuでも動くのだろうか？ 試す価値はあるか。

![](/2025-10-27/10785973-DWJsifFwuwn2KWdZqRoI7e14.png)

![](/2025-10-27/10785973-VAGz6kICKHoXglYMUSPrzFbG.png)

　とりあえず、LTSで試す。リリースは2025-08-07なので、TouchDisplay2のリリース日である2025年8月18日より数日前のイメージになる。微妙だけど、対応が含まれていてもおかしくないか。

![](/2025-10-27/10785973-PS3e1v0nhyf4ztWO6pahpAVW.png)

　イメージを焼いている間に、下調べする。結構厳しいかも...

　・表示は出るがタッチが効かない（再起動後に無反応）

　・25.04 + Pi 5 でスクロール時に画面ちらつき

　・24.04 LTS Server + Pi 5 で DSI に出力されない

　・Ubuntuが起動しない（TD2接続時）

　あー、やっぱなんにも出ないわ... バックライトも点いてない感じ。うーむ。

![](/2025-10-27/10785973-L9g4d7gsGeWcrz8gdgK3BYie.png)

　有線LANを接続しているのでリンクアップはしてきているから、Ubuntuそのものは起動している感じがする。しかし、sshは接続できないっぽい。UbuntuってmDNSがデフォルトで動作していたと思うのだけど、それも応答がない。プロダクトにMACアドレスシールは貼ってほしいよな...

　しょうがないので、HDMIを接続する。

　なるほど、インストーラーが起動していたよ... Ubuntu Serverしか入れたことなかったかも。Desktopって、こんなのなのね。

![](/2025-10-27/10785973-2UgZiuTIPg7gHcXKtIe59VWt.png)

　必要な設定を順次行う。ホスト名を指定して、ユーザーも作成すると、インストーラーがインストールを開始した。めんどくさ... アップデートもやっているよ。

　マウスとキーボードをつないで、ターミナルを起動してアドレスを調べる。

```
$ ip addr
```

　192.168.0.9が破り当たっていた。

% ping 192.168.0.9 -c 1

PING 192.168.0.9 (192.168.0.9): 56 data bytes

64 bytes from 192.168.0.9: icmp_seq=0 ttl=64 time=3.380 ms

--- 192.168.0.9 ping statistics ---

1 packets transmitted, 1 packets received, 0.0% packet loss

round-trip min/avg/max/stddev = 3.380/3.380/3.380/0.000 ms

　んで、デフォルトではsshdは起動していないようだ。

% ssh kinneko@192.168.0.9

ssh: connect to host 192.168.0.9 port 22: Connection refused

　うーん、不便だ。ターミナルから入れる。

```
$ sudo apt update
$ sudo apt install openssh-server -y
```

　grimもいないのね。

kinneko@pi4:~$ sudo apt install grim

kinneko@pi4:~$ grim desk1.png

compositor doesn't support wlr-screencopy-unstable-v1

　gnome-screenshotもないな...

kinneko@pi4:~$ gnome-screenshot -f desk1.png

Command 'gnome-screenshot' not found, but can be installed with:

```
sudo apt install gnome-screenshot
```

kinneko@pi4:~$ sudo apt install gnome-screenshot

kinneko@pi4:~$ gnome-screenshot -f desk1.png

kinneko@pi4:~$ file desk1.png

desk1.png: PNG image data, 1024 x 768, 8-bit/color RGBA, non-interlaced

　というわけで、インストール後の画面はこれ。なんかキャプチャの縦横比がおかしいな。

![](/2025-10-27/10785973-v9NHowVJkaF0xUyJ1xBNnvRO.png)

　Ubuntu Proの有効化を聞かれる。もちろんNO。

![](/2025-10-27/10785973-GFAWmAVMFIRdbpt6e1xGMHnr.png)

　システム情報を送ったりもしない。

![](/2025-10-27/10785973-tlC01NWG1igrboUYRZnoHnFp.png)

![](/2025-10-27/10785973-aTOwvc8svfth45OmYv0wsYfO.png)

　やっとセットアップ終了。

![](/2025-10-27/10785973-Xc2B2xw2unSLRhPHBQAkVEyy.png)
