　ここまでするなら+1000円くらいにして、裏ケース付けたらいいのに。裏ケースは別に売るというのがちょっとイヤ。とはいえ、前みたいに純正のケースはないみたいで、waveshareとかで出ている。

![](/2025-10-16/10735997-5XmzulxSG91fVFVKWiLu0GDM.png)

　PI5-CASE-TD2 WaveShare製 Raspberry Pi 5/Touch Display 2用ケース

https://www.switch-science.com/products/10464

　これなら、解像度以外は、OSOYOのが少し安くていいかなという感じ。OSOYOもパネル変更して解像度上げてこないかしらん。あと、額縁部分が等幅になっているのは調整がいらなくていいかな。

　実際に動かしてみる。trixie版がもう出ているのだけど、いろいろ問題もあるので、bookwormで試す。

![](/2025-10-16/10735997-q8FPcdyUJCHX8KdOVIDsK552.png)

　画面回転の設定がどこに書かれているか確認してみる。

　これじゃないな...

fd@pi4b:~ $ cat ~/.config/labwc/rc.xml

<?xml version="1.0"?>

<openbox_config xmlns="http://openbox.org/3.4/rc">

<touch deviceName="10-0038 generic ft5x06 (00)" mapToOutput="DSI-1" mouseEmulation="yes"/>

<touch deviceName="10-005d Goodix Capacitive TouchScreen" mapToOutput="DSI-1" mouseEmulation="yes"/></openbox_config>

　これでもないな。

fd@pi4b:~ $ cat ~/.config/wf-panel-pi.ini

```
[panel]
launcher_000001=lxde-x-www-browser.desktop
launcher_000002=pcmanfm.desktop
launcher_000003=lxterminal.desktop
```

　あったあった。そっか、kanshiだった。前にもやったな...

fd@pi4b:~ $ cat ~/.config/kanshi/config

profile {

output DSI-1 enable mode 720x1280@60.011 position 0,0 transform 270

```
}
```

　CLIの場合はこんなに簡単にはいかない。cmdline.txtに以下を追記する、rotation-valueには、0,90,180,270が入れられる。

```
video=DSI-1:720x1280@60,rotate=<rotation-value>
```

　ちなみに、bookwormのデフォルトはこうなっていた。

fd@pi4b:~ $ cat /boot/firmware/cmdline.txt

```
console=serial0,115200 console=tty1 root=PARTUUID=b45bfd34-02 rootfstype=ext4 fsck.repair=yes rootwait modules-load=dwc2,g_ether quiet splash plymouth.ignore-serial-consoles
```

fd@pi4b:~ $ sudo vi /boot/firmware/cmdline.txt

fd@pi4b:~ $ sudo reboot

　しかし、これをやってもplymouthの起動スプラッシュは回転しないな... これは、CLI画面だけの設定らしい。

```
config.txtにdisplay_hdmi_rotate=<回転値>を追加するのもアリだったような。これは、HDMIじゃないからDSIだと回転しないんだっけ？ その場合は、display_lcd_rotate=2とかかな。どうも、最近はこれは使えないらしい。
```

　正解はこれっぽい。

```
dtoverlay=vc4-kms-dsi-ili9881-7inch,rotation=90
```

Rpi5 + Touch Display 2 + OS Lite, how to rotate? - Raspberry Pi Forums

https://forums.raspberrypi.com/viewtopic.php?t=379738

　plymouthも回転した。

　バックライトの輝度調整はコマンドからできないナ。デフォルトは眩しくないからいいんだけど。範囲外だと言っている。

fd@pi4b:~ $ echo "100" > /sys/class/backlight/10-0045/brightness

-bash: echo: write error: Invalid argument

　値は読める。

fd@pi4b:~ $ cat /sys/class/backlight/10-0045/brightness

31

　なるほど、これが最大値なのね。

fd@pi4b:~/android-photo-picker $ cat /sys/class/backlight/10-0045/max_brightness

31

　少し暗くすることはできた。

fd@pi4b:~/android-photo-picker $ echo "20" > /sys/class/backlight/10-0045/brightness
