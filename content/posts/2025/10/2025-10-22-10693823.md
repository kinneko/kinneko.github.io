　RaspiOSのDesktopで、USBを差し込むとfatとかなら自動認識されてどのアプリを起動するか聞かれるダイアログが出る。

![](/2025-10-22/10693823-YMxArDLpQQsWnQyAWOvzkA0V.png)

　デフォルトはアプリはFile Manager(pcmanfm)が設定されている。

![](/2025-10-22/10693823-wgFERJT1YCsEnTh69aBJ6YKq.png)

　都合により、これを止めて、アプリ側からマウント/アンマウントを制御したい。

　trixieから、いっぱい分散していた設定関係は、Control Centreに集約されたようだ。

![](/2025-10-22/10693823-NmMqeL2yVX7NVQFWNSv3bUTO.png)

　起動する。Centreは英語表記なのね。そういう妙な自己主張が面白いw

![](/2025-10-22/10693823-dpwxiZCQllTUTyAsvysCC5ZZ.png)

　しかし、この中には設定はないのであった。

　どこにあるかというと「File Managerの設定」になる。フォルダアイコンのFile Mangerを開いて、Edit->Preferencesを開く。

![](/2025-10-22/10693823-w32OoQqxTTmDD82cDpdzp2EY.png)

　このチェックをぜんぶ外しておく。

![](/2025-10-22/10693823-Tu6dXnmOgHTa9e4A00DsYAal.png)

　ぜんぶチェックを外すと、プログラムがキックされることもなくなった。

　LXDE-piはもう使っていないようだ。

fd@pi4:~ $ ~/.config/pcmanfm/LXDE-pi/pcmanfm.conf

　なので、これを停止してしまうという方法もある。

```
sudo systemctl stop udisks2.service
sudo systemctl disable udisks2.service
```

　さらに、udevルールで自動マウントトリガを抑止するルールを追加して、マウント自体をブロックする方法もある。

　さて、udisks2が有効であれば、udisksctlコマンドを使って、マウント操作ができる。

fd@pi4:~ $ sudo udisksctl mount -b /dev/sda1

Mounted /dev/sda1 at /media/root/bootfs

fd@pi4:~ $ sudo df /dev/sda1

Filesystem     1K-blocks  Used Available Use% Mounted on

```
/dev/sda1         522230 75762    446468  15% /media/root/bootfs
```

fd@pi4:~ $ sudo udisksctl unmount -b /dev/sda1

Unmounted /dev/sda1.

　USBストレージを切ることもできる。

fd@pi4:~ $ sudo fdisk -l /dev/sda1

Disk /dev/sda1: 512 MiB, 536870912 bytes, 1048576 sectors

Units: sectors of 1 * 512 = 512 bytes

Sector size (logical/physical): 512 bytes / 512 bytes

I/O size (minimum/optimal): 512 bytes / 512 bytes

Disklabel type: dos

fd@pi4:~ $ sudo udisksctl power-off -b /dev/sda1

fd@pi4:~ $ sudo fdisk -l /dev/sda1

fdisk: cannot open /dev/sda1: No such file or directory

　もっとプリミティブに、mount/umountコマンドを使ってもいい。
