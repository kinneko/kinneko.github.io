　macOSでは「ホスト名」に関連する名前が3種類ある。

　100円投げ銭 　https://kinneko.booth.pm/items/1963720

　ComputerName：Finderや「システム設定 → 一般 → 情報」などに表示される名前

　LocalHostName：Bonjour / mDNS用

　HostName：Unixとしてのホスト名

　通常はセットアップしたときのユーザー名を基準に勝手に付けられている。

　% hostname

　kinnekonoMac-mini.local

　そうやって自動で付けられたホスト名は一致していない値が入っている。

　% scutil --get ComputerName

　kinnekoのMac mini

　% scutil --get LocalHostName

　kinnekonoMac-mini

　% scutil --get HostName

　HostName: not set

　HostNameが未設定だと、LocalHostNameが返る仕様のようだ。

　これでは、mDNSとかから使うときに不便なので変更する。

　ホスト名の操作には、scutilコマンドを使う。

　通常は3つとも同じ名前にしておく。

　% sudo scutil --set ComputerName "ebikin"

　% sudo scutil --set LocalHostName "ebikin"

　% sudo scutil --set HostName "ebikin"

　設定結果の確認。

　% scutil --get ComputerName

　ebikin

　% scutil --get LocalHostName

　ebikin

　% scutil --get HostName

　ebikin

　mDNSのアナウンスをやりなおすには、mDNSResponderのプロセスを強制終了しておく。launchdがmDNSResponderを自動的に再起動する。

　しかし、それはやらなくても、新しいアナウンスが出ていた。

　別端末から名前解決を確認する。

　% ping ebikin.local. -c 1

　PING ebikin.local (192.168.0.11): 56 data bytes

　64 bytes from 192.168.0.11: icmp_seq=0 ttl=64 time=19.456 ms

　--- ebikin.local ping statistics ---

　1 packets transmitted, 1 packets received, 0.0% packet loss

　round-trip min/avg/max/stddev = 19.456/19.456/19.456/0.000 ms
