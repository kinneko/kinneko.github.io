　シリアルデバイス側はこんな感じで認識した。給電はどちらからでもよさげ。

　シリアルデバイスとしては、tty.usbserial-1140として見えている。

　% ls /dev/tty.*

　/dev/tty.Bluetooth-Incoming-Port	/dev/tty.usbserial-1140

　接続してみる。

　% python -m serial.tools.miniterm /dev/tty.usbserial-1140 115200

　なんも見えないな...

　なんか、プロトコルが独特ね... とりあえずPythonスクリプトがあるので、それで動作確認してみるか。

　サンプルコードは、接続先がCOM24にハードコードされている。うーん。

　んで、操作部分が全部コメントアウトされている。

　AIに分析させてみると、明らかに間違いもいくつか見つかる。うーん...

　とりあえず、abcだけキーインするものを書き直し。

　import time

　import serial

　class CH9329:

```text
TBL = {
'a': [0x00, 0x04],
'b': [0x00, 0x05],
'c': [0x00, 0x06],
}
```

　def __init__(self, port="/dev/tty.usbserial-1140", baud=9600):

```text
self.ser = serial.Serial(
port=port,
baudrate=baud,
timeout=0.1
)
```

　def sendpacket(self, data):

```text
self.ser.write(bytes(data))
self.ser.flush()
time.sleep(0.02)
return self.ser.read(7)
```

　def push(self, modifier, key):

# Key down

```text
packet = [
0x57, 0xAB, 0x00,
0x02,       # keyboard command
0x08,       # data length
modifier,
0x00,
key,
0x00,
0x00,
0x00,
0x00,
0x00,
]
packet.append(sum(packet) & 0xFF)
self.sendpacket(packet)
```

# Key up

```text
packet = [
0x57, 0xAB, 0x00,
0x02,
0x08,
0x00,
0x00,
0x00,
0x00,
0x00,
0x00,
0x00,
0x00,
]
packet.append(sum(packet) & 0xFF)
self.sendpacket(packet)
```

　def type_text(self, text):

　for ch in text:

　if ch in self.TBL:

　modifier, key = self.TBL[ch]

```text
self.push(modifier, key)
```

　def close(self):

```text
self.ser.close()
```

```text
drv = CH9329("/dev/tty.usbserial-1140", 9600)
```

　try:

```text
drv.type_text("abc")
finally:
drv.close()
```
