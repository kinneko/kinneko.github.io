　このSET MAXされたドライブを全部使えるようにしたい。


```text
kinneko@llmbuild:~$ lsblk
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
(snip)
sdb      8:16   0 232.9G  0 disk
├─sdb1   8:17   0 220.9G  0 part
├─sdb2   8:18   0     1K  0 part
└─sdb5   8:21   0    12G  0 part
```

　ATA のSET MAXで容量を制限されたドライブは、通常は HPA (Host Protected Area) を hdparm -Nで解除することで、全エリアが使えるようになる。-Nオプションでは、現在の最大セクタ数とドライブ本来の最大セクタ数を表示する。

```text
$ sudo hdparm -N /dev/sdb
/dev/sdb:
max sectors   = 488397168/781422768, HPA is enabled
```

　このドライブでは、左右の数字が一致していないので、SET MAXされているのがわかる。右の数字が本来の容量だ。

　中身はなんだったっけ...

```text
$ lsblk -f /dev/sdb
NAME FSTYPE FSVER LABEL UUID                                 FSAVAIL FSUSE% MOUNTPOINTS
sdb
├─sdb1
│    ext4   1.0         d4b7ff5f-a389-43ef-ba48-a60b41f98922
├─sdb2
│
└─sdb5
swap   1           5b6bc11a-eb46-48e3-aa3f-9727e93c6c32
```

　これまた古いね... homeにもなんもないし消しても問題はなさそう。

```text
$ sudo mount /dev/sdb1 /mnt
$ cat /mnt/etc/os-release
NAME="Ubuntu"
VERSION="14.04.1 LTS, Trusty Tahr"
ID=ubuntu
ID_LIKE=debian
PRETTY_NAME="Ubuntu 14.04.1 LTS"
VERSION_ID="14.04"
HOME_URL="http://www.ubuntu.com/"
SUPPORT_URL="http://help.ubuntu.com/"
BUG_REPORT_URL="http://bugs.launchpad.net/ubuntu/"
$ sudo umount /mnt
```

　一時的に全容量へ戻すには、以下を実行する。この設定は、電源断・ハードウェアリセットで元に戻ってしまう。

　sudo hdparm -N 781422768 /dev/sdb

　恒久的に戻す場合は `p` を付けて実行する。今回はこちらで。

```text
$ sudo hdparm -N p781422768 /dev/sdb
/dev/sdb:
setting max visible sectors to 781422768 (permanent)
max sectors   = 781422768/781422768, HPA is disabled
```

　確認のために、いったん完全に電源を切って再投入する。ドライブをあとで入れてないので、ドライブ名が変わった。

　SET MAXは無効になっている。

```text
$ sudo hdparm -N /dev/sda
```

　/dev/sda:

　max sectors   = 781422768/781422768, HPA is disabled

　なんかドライブのアクセス音がジジジジとうるさい感じ。使わないほうがいいかも。

　うーん、これはダメだな... ECCでも訂正できなかった読み取りエラーが13回もあるわ。

```text
$ sudo smartctl -a /dev/sda
(snip)
ATA Error Count: 13
...
Error: UNC at LBA = 5000000
Error: UNC at LBA = 5033941
Error: UNC at LBA = 5033941
Error: UNC at LBA = 5033941
Error: UNC at LBA = 8000000
```

　ダメな部分をさわらないようにSET MAXされていたのかもな...

　とりあえず、セルフテストを走らせる。

　134分後に処理が終わったら、もう一度状態を確認してみる。
