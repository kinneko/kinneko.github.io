　macOS 11.6.1では、USB差し込んでも認識しない。ドライバがいるんだろうな。再起動いるよなぁ... それは、めんどくさいよ。

　カメラのデフォルトアドレスは、10.254.239.1という変なアドレスになっている。unitv2.pyで画面が開かないときには、これを呼んでもいい。

　一方で、/etc/init.d/S05initled では、常時ハイスペックで動くようになっている。

```
echo "performance" > /sys/devices/system/cpu/cpufreq/policy0/scaling_governor
```

　ドライバは Mstar cpufreq なので、SoCベンダー独自の周波数切り替え処理が組み込まれている。Linux標準のgovernorが、このドライバを通じて周波数を変更している。

　利用可能なgovernorを確認しておく。現在は1.4GHzで67度。

```
unitv2# cat /sys/devices/system/cpu/cpufreq/policy0/scaling_cur_freq
1400000
```

```
unitv2# cat /sys/devices/system/cpu/cpufreq/temp_out
Temp=67
```

　設定できるのは、userspace, powersave, ondemand, performanceか。

```
unitv2# cat /sys/devices/system/cpu/cpufreq/policy0/scaling_available_governors
userspace powersave ondemand performance
```

　ondemandに下げてみる。400MHzに落ちた。温度はすぐには下がらないよね。

```
unitv2# echo ondemand > /sys/devices/system/cpu/cpufreq/policy0/scaling_governor
```

```
# cat /sys/devices/system/cpu/cpufreq/policy0/scaling_cur_freq
400000
unitv2# cat /sys/devices/system/cpu/cpufreq/temp_out
Temp=68
```

　ondemand は負荷に応じて自動的に周波数を上げるので、400MHzに固定されるわけではない感じ。

> Power Consumption Adjustment - SigmaStarDocs<br>
> <https://wx.comake.online/doc/d8clf27cnes2-SSD20X/customer/development/reference/Power%20Consumption.html>

> Power Consumption Adjustment Guide - Sigmastar Docs<br>
> <https://git.sigmastar.com.cn/html/sgs_docs/D3/NLSSV01C12/customer/Common/Development/power.html>

　こんな感じらしい。

| governor | 動作 | 発熱・消費電力 | 性能 |
| --- | --- | --- | --- |
| performance | 上限周波数を維持 | 高くなりやすい | 最大性能 |
| powersave | 下限周波数を維持 | 低くなりやすい | 制限される |
| ondemand | CPU負荷に応じ自動変更 | 負荷に応じて低減 | 高負荷時に上昇 |
| userspace | 指定周波数に設定 | 設定値による | 設定値による |

　実機で対応可能なクロックを調べる。

```
unitv2# P=/sys/devices/system/cpu/cpufreq/policy0
for f in scaling_driver scaling_available_frequencies cpuinfo_min_freq cpuinfo_max_freq scaling_min_freq scaling_max_freq scaling_governor; do
[ -r "$P/$f" ] && echo "$f: $(cat "$P/$f")"
done
scaling_driver: Mstar cpufreq
scaling_available_frequencies: 400000 600000 800000 1000000 1100000 1200000 1400000
cpuinfo_min_freq: 400000
cpuinfo_max_freq: 1400000
scaling_min_freq: 400000
scaling_max_freq: 1400000
scaling_governor: ondemand
```

| 周波数 | 最大周波数に対する比率 |
| --- | --- |
| 400 MHz | 28.6% |
| 600 MHz | 42.9% |
| 800 MHz | 57.1% |
| 1,000 MHz | 71.4% |
| 1,100 MHz | 78.6% |
| 1,200 MHz | 85.7% |
| 1,400 MHz | 100% |
