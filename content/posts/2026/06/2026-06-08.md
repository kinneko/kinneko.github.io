　チャットコンソールが起動できたのだけど、何するかね？

![](/2026-06-08/n8U6QwERrUznWb421KQzfctE.png)

![](/2026-06-08/JNId7lqv0zaT7C0CWKPkdyMh.png)

　はい。Signal のホームチャンネルを設定するには、端末で次を実行します。

　1. 送信先の Signal チャンネルIDを用意する

　2. そのIDをホームに設定する

　コマンド:

　hermes config set SIGNAL_HOME_CHANNEL <channel_id>

　設定後、必要なら Hermes を再起動してください。

　確認コマンド:

　hermes config get SIGNAL_HOME_CHANNEL

　または

　hermes config で全体確認できます。

　もし channel_id の調べ方が必要なら、続けて案内します。

![](/2026-06-08/07kBRE5aWbX386tJruDJ8vSe.png)

　HermesでTelegramを使う場合は、Telegram Botを作って、そのBot TokenをHermes Gatewayに登録する。

　まずは、Botを作るのに、Telegramアプリを開いて、検索で@BotFatherを探す。

![](/2026-06-08/fIvkgTUuszh14DblIJYIF2MR.png)

　Botの表示名を聞かれます。これは自由です。

　次に username を聞かれます。これは 必ず bot で終わる必要があります。

　成功すると、BotFatherがこのような Bot Token を返します。

　ふーん。いろいろとめんどくさい。

　さらに、自分のIDを知っている必要がある。これには、AndroidのTelegramで @userinfobotを検索して開き、/startすると自分のIDがわかる。

　これらを調べた上で、Gateway SetupでTelegramを設定する。

　→ (○) 📱 Telegram  (not configured)

　Start the gateway service? [Y/n]: n

　サービスは手動設定する。

　前に設定したものが動いているので殺しておく。

　% ps ax | grep gateway

　4531 s000  SN     0:21.81 /Users/kinneko/.hermes/hermes-agent/venv/bin/python3 /Users/kinneko/.hermes/hermes-agent/venv/bin/hermes gateway run

　% pkill -f "hermes gateway run" 2>/dev/null

　[2]  + exit 1     nohup hermes gateway run > ~/.hermes/logs/hermes-gateway.log 2>&1

　一応、ログを残すようにして手動起動。

　% mkdir -p ~/.hermes/logs

　% nohup hermes gateway run > ~/.hermes/logs/hermes-gateway.log 2>&1 &

　[1] 4773

　作ったbotを呼び出して、チャットを開始している必要があるようだ。

　Android端末側で作る。

　作っただけで対話が開始できたよ。
