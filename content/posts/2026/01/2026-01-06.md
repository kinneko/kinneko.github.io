　Pi3Aの無線の設定を変更するときには、ROM化を解除して設定変更が必要になる。

![](/2026-01-06/0quSKRFTWPcJKFY3RK7UIhwN.png)

　そのまえに、1日一回落ちるバグ。

　kinneko@radio:~ $ sudo journalctl -u nhk-r1.service -b --no-pager | grep Failed

　Dec 30 13:26:04 radio mpv[1563]: [ffmpeg] tcp: Failed to resolve hostname simul.drdi.st.nhk: Temporary failure in name resolution

　Dec 30 13:26:04 radio mpv[1563]: [ffmpeg/demuxer] hls: Failed to reload playlist 0

　Dec 30 13:26:04 radio mpv[1563]: [ffmpeg] tcp: Failed to resolve hostname simul.drdi.st.nhk: Temporary failure in name resolution

　Dec 30 13:26:04 radio mpv[1563]: [ffmpeg/demuxer] hls: Failed to reload playlist 0

　Dec 30 13:26:48 radio mpv[3367]: [cplayer] Failed sending hook command auto_profiles/on_before_start_file. Removing hook.

　Dec 30 13:26:48 radio mpv[3367]: [cplayer] Failed sending hook command auto_profiles/on_load. Removing hook.

　Dec 30 13:26:48 radio mpv[3367]: [ffmpeg] tcp: Failed to resolve hostname simul.drdi.st.nhk: Temporary failure in name resolution

　Dec 30 13:26:48 radio mpv[3367]: [stream] Failed to open https://simul.drdi.st.nhk/live/10/joined/master.m3u8.

　Dec 30 13:26:58 radio mpv[3367]: [cplayer] Failed sending hook command auto_profiles/on_preloaded. Removing hook.

　hook関係のは問題なさそう。

　13:26:04：再生中にプレイリスト更新できず（reload playlist失敗）

　13:26:48：再起動後の初回オープンでもDNSが引けず、URLを開けずに終了

　問題はDNSに絞られた。上流接続更新のタイミングとマッチしたのかもな...

　というわけでLTEルーターへの接続先の切り替えを行う。

　ROM化解除。

　kinneko@radio:~ $ sudo raspi-config nonint disable_overlayfs

　kinneko@radio:~ $ sudo reboot

　再ログイン。

　kinneko@radio:~ $ sudo raspi-config nonint disable_bootro

　kinneko@radio:~ $ sudo reboot

　無線の接続状態を確認する。

　kinneko@radio:~ $ nmcli dev status

　DEVICE         TYPE      STATE                   CONNECTION

　wlan0          wifi      connected               netplan-wlan0-MyPlace

　lo             loopback  connected (externally)  lo

　p2p-dev-wlan0  wifi-p2p  disconnected            --

　kinneko@radio:~ $ nmcli connection show

　NAME                   UUID                                  TYPE      DEVICE

　netplan-wlan0-MyPlace  fd236b07-6128-3f61-99f7-e91c47731bb4  wifi      wlan0

　lo                     dcd5d794-a484-402c-b1a8-a1e5cfd03a0c  loopback  lo

　netplan-eth0           75a1216a-9d1a-30cd-8aca-ace5526ec021  ethernet  --

　新規接続先を設定する。

　sudo nmcli --ask dev wifi connect "SSID名" ifname wlan0

　あら、ステルスSSIDには接続できないな。このコマンドは見えてる前提か。

　kinneko@radio:~ $ sudo nmcli --ask dev wifi connect "radiohost" ifname wlan0

　Error: No network with SSID 'radiohost' found.

　うーん、ダメだな。

　kinneko@radio:~ $ sudo nmcli --ask dev wifi connect "radiohost" ifname wlan0 hidden yes

　Error: No network with SSID 'radiohost' found.

　一つづつやるか。

　kinneko@radio:~ $ sudo nmcli con delete radiohost 2>/dev/null || true

　kinneko@radio:~ $ sudo nmcli con add type wifi ifname wlan0 con-name radiohost ssid radiohost

　Connection 'radiohost' (a272330f-6c0a-414b-86fb-883f615a6374) successfully added.

　kinneko@radio:~ $ sudo nmcli con mod radiohost 802-11-wireless.hidden yes

　kinneko@radio:~ $ sudo nmcli con mod radiohost wifi-sec.key-mgmt wpa-psk

　kinneko@radio:~ $ sudo nmcli con mod radiohost wifi-sec.psk 'パスワード'

　kinneko@radio:~ $ sudo nmcli con up radiohost

　既存の無線接続が切れたかな？

　APに入ってみると見えていた。

　kinneko@radio:~ $ nmcli dev status

　DEVICE         TYPE      STATE                   CONNECTION

　wlan0          wifi      connected               radiohost

　lo             loopback  connected (externally)  lo

　p2p-dev-wlan0  wifi-p2p  disconnected            --

　kinneko@radio:~ $ nmcli connection show

　NAME                   UUID                                  TYPE      DEVICE

　radiohost              a272330f-6c0a-414b-86fb-883f615a6374  wifi      wlan0

　lo                     dcd5d794-a484-402c-b1a8-a1e5cfd03a0c  loopback  lo

　netplan-eth0           75a1216a-9d1a-30cd-8aca-ace5526ec021  ethernet  --

　netplan-wlan0-MyPlace  fd236b07-6128-3f61-99f7-e91c47731bb4  wifi      --

　ラジオ音声も無事流れている。

　システムをROM化しておく。

　kinneko@radio:~ $ sudo raspi-config nonint enable_overlayfs

　kinneko@radio:~ $ sudo raspi-config nonint enable_bootro

　kinneko@radio:~ $ sudo reboot

　ROM化の確認。問題なさそう。

　kinneko@radio:~ $ cat /proc/mounts |grep root

/dev/mmcblk0p2 /media/root-ro ext4 ro,relatime 0 0

　tmpfs-root /media/root-rw tmpfs rw,relatime 0 0

　overlayroot / overlay rw,relatime,lowerdir=/media/root-ro,upperdir=/media/root-rw/overlay,workdir=/media/root-rw/overlay-workdir/_,uuid=on 0 0

　kinneko@radio:~ $ cat /proc/mounts |grep boot

/dev/mmcblk0p1 /boot/firmware vfat ro,relatime,fmask=0022,dmask=0022,codepage=437,iocharset=ascii,shortname=mixed,errors=remount-ro 0 0

　費用面では、43.2 MB/時くらいになりそう。40GBか。結構な金額になってしまうな。

　約 1.09〜1.24 GB/日

　約 32.7〜37.3 GB/30日

　いまはシンプル290プランで契約しているので、デフォルトは1GB。追加1GBあたり220円。１万円弱になってしまうじゃないの。合理的50GBプラン：2,178円/月に変更したほうが良さそう。

　というわけで、プランを変更しようと思ったのだが、開通当日のプラン変更ができなかった。
