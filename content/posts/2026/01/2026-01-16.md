　Pi3AでLTEルーターと無線接続していたけれど、どうも切れてしまうと対応のしようがない。Pi3Bに切り替えて有線接続にすることにした。

![](/2026-01-16/MbLxlvrXb33t2t795ofYsgaH.png)

　Pi3Bをセットアップする。出張時のホテルでのセットアップ。手持ちの小型の有線キーボードが動作がイマイチだったので、アキバのハードオフのジャンク屋で1500円でキーボードを買う。

![](/2026-01-16/FzOOw2ELupnauv1Z6qEOoNyA.png)

　LTEルーターは設置済みで手元にないので、MBAからインターネット共有で接続する。

![](/2026-01-16/gtcV4rUktXYhnyWmG0ZCo9no.png)

　んで、テストに使おうと思ったら、ラジオの電源が入らない。バッテリが放電しちゃったかな？半分以上ある状態でスイッチ切ってあったのだけど。うーん。

　あ、スピーカーない... ピロースピーカーの予備は置いてきてしまったな。昨日、aitendoに行った時に似たようなの売ってたの買えばよかった。あ、会議用の有線イヤホンあったのだった。とりあえず、それで。

　ラジオの再生できているのは確認できた。

　RaspiConnectのバージョンが2.7.0に上がっていた。前回は2.6.1。接続の確認もOK。

　ROM化しておく。あとはエンジングテスト。

　トランスミッタのテストができなかったのは参ったな。アキバだし、シゲゾーン寄ってラジオをみてもらうかな。安い買い物でもなかったし。あー、めんどくさい。PCとACアダプタからの充電では、液晶にインジケーターも出ない。

> マニュアルがあった。<br>

> <https://cdn.shopify.com/s/files/1/0448/8151/0566/files/V115_8499eb46-c3dd-4677-b211-c5bdcd24ed87.pdf>

　電源は500mAしか動かないと書かれているナ。うーん、これはUSBではないのだな。保護回路で止まっているのかも。500mAしか出ないACがあったので充電したらインジケーターが表示された。充電中。

　電源入れられるようになったので、結合試験。問題なく動いているので、エイジング。

![](/2026-01-16/th5U6ZRsCzvmxHAqCEM5vSeQ.png)

　定期リブートでも仕込んだほうがいいかな。ラジオ深夜便の時間が聞きたい時間のようなので、夜中に再起動というわけにもいかないので、朝8時にしておく。

　まずはROM化解除。

　kinneko@radioB:~ $ sudo raspi-config nonint disable_overlayfs

　kinneko@radioB:~ $ sudo reboot

　再ログイン。bootはいいか。

　kinneko@radioB:~ $ sudo crontab -e

　no crontab for root - using an empty one

　Select an editor.  To change later, run select-editor again.

1. /bin/nano        <---- easiest

2. /usr/bin/vim.tiny

3. /bin/ed

　Choose 1-3 [1]: 2

　crontab: installing new crontab

　実験兼ねて、21:30くらいでいいか。

　30 21 * * * /sbin/reboot

　再ROM化。

　kinneko@radioB:~ $ sudo raspi-config nonint enable_overlayfs

　kinneko@radioB:~ $ sudo reboot

　指定時間で無事再起動してきた。sysytemdでやるのは面倒だよね。

　あれ？ なんか再起動繰り返しているのだけど... なんだこれ？ cronは問題なく設定されている。

　kinneko@radioB:~ $ sudo grep -R --line-number -E "^\s*@reboot\b|/sbin/reboot\b|systemctl\s+reboot\b|\breboot\b" \ /var/spool/cron/crontabs /etc/crontab /etc/cron.d /etc/cron.* 2>/dev/null

/var/spool/cron/crontabs/root:27:30 21 * * * /sbin/reboot

　再起動後の時刻同期関係か、ROM化で動きが妙な感じになっているのか？

　うーん、眠いし、systemdでやるのもめんどうなので再起動をやめた。

　たぶん、ROM化のせいだな。こんなふうに実行ディレイをいれるといいのかも。未テストだけど。

　30 21 * * * /bin/sleep 180; /sbin/reboot
