　出荷時にどんなファームウエアが書かれているのかは、ドキュメントには何も書かれていない。

　M5BurnerではStamp-C5（S016）ファームウェアが登録されている。最新版は、v2.5.3 — 2026-09-11になっている。ファイルはuiflow-db526ecc-esp32c5-4mb-stampc5-v2.5.3-20260911.binなので、UIFlow2用ファームウェアということは、MicroPythonの実行環境のバイナリという感じか？ それはいらない。

　ESP-Hosted-MCUにするためのバイナリは公開されていないので、自分でビルドするしかないようだ。そのくらいは用意してくれてあっても良さそうな。

　自分でやるしかないのか...

　ESP32-C5は、ESP-IDF v5.5.2から正式サポートされている。

　とりあえず、青LEDあるからLチカからかな...

```text
% . ~/esp/esp-idf/export.sh
% idf.py --version
ESP-IDF v5.5.3

% idf.py create-project blink_c5
Executing action: create-project
The project was created in /Users/kinneko/Downloads/esp553/blink_c5

% cd blink_c5
% find ./
./
.//CMakeLists.txt
.//main
.//main/CMakeLists.txt
.//main/blink_c5.c

% vi main/blink_c5.c
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/gpio.h"
#include "esp_log.h"

#define LED_GPIO GPIO_NUM_28

static const char *TAG = "blink";

void app_main(void)
{
gpio_reset_pin(LED_GPIO);
gpio_set_direction(LED_GPIO, GPIO_MODE_OUTPUT);

bool level = false;

while (1) {
level = !level;

gpio_set_level(LED_GPIO, level);

ESP_LOGI(TAG, "LED GPIO level: %d", level);

vTaskDelay(pdMS_TO_TICKS(1000));
}
}

% vi main/CMakeLists.txt
idf_component_register(
SRCS "blink_c5.c"
INCLUDE_DIRS "."
REQUIRES esp_driver_gpio
)

% idf.py set-target esp32c5
% idf.py build
```
