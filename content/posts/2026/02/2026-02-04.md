　create_local_json.pyを実行してみる。

![](/2026-02-04/1f1mnDmy1QfmAvfXELTYcYTB.png)

　実行に必要なPythonライブラリ(argparse, hashlib, json, os.path, pathlib, shutil, sys, urllib.request)は、標準ライブラリなのでインストール済み。

　ダウンロードして実行してみる。

　% curl -OL https://raw.githubusercontent.com/raspberrypi/rpi-imager/refs/heads/main/doc/local_json/create_local_json.py

　% Total    % Received % Xferd  Average Speed   Time    Time     Time  Current

　Dload  Upload   Total   Spent    Left  Speed

　100 12299  100 12299    0     0  52972      0 --:--:-- --:--:-- --:--:-- 53012

　% python3 ./create_local_json.py --online --capabilities usb_otg --device-capabilities usb_otg

　Wrote 176 images to os_list_local.rpi-imager-manifest

　cache/os_list_imagingutility_v4.jsonと、os_list_local.rpi-imager-manifestが生成されている。

　インプットとアウトプットを比べると、os_list_imagingutility_v4.jsonは、subitemsがある階層構造のJSONファイルになっている。一方、生成されたos_list_local.rpi-imager-manifestはフラットな構造になっている。ぜんぜん違うやん。

　imagerブロックも、オリジナルにはlatest_versionとurlがあったのに、改変後はこれらがなくなっていてdevicesのみになっている。

　URLを持つ要素はオリジナルでは178件あるのだけど、改変後は176件になっている。消えているのは、info-beamer OSとPINN。

　生成されたファイルをダブルクリックすると、妙な拡張子だけどちゃんとImagerが起動する。

　USB Gadget Mode Warning

　USB Gadget Mode can change how your device behaves and may impact connectivity and host interaction.

　Please review the documentation before proceeding.

　Only continue if you are sure you know what you are doing.

> ドキュメントのリンク先はここになっている。オプション指定されているようなタブはないのだけど。<br>
> <https://github.com/raspberrypi/rpi-usb-gadget?tab=readme-ov-file>

　まぁ、USB Gadget Modeを有効にすると、USBの役割や振る舞いが変わるので、接続やPC側の扱いが変わる。分かっている人だけ使ってね、というような意味。

　確認して書き込み。
