　今更ながら、Claude codeを使う環境を用意したいのだけど、メインマシンのメモリは仮想マシンをずっと立ち上げておくほど余裕がない。いまは使っていないPi5があるので、こちらに環境を作って、sshから使うことにする。

　インストールしたイメージはこれ。

![](/2026-02-26/Y3tu6imUWnCKK8yduQCpZW35.png)

　SDカードは、ちょっと少ないかな。作業領域は、USBストレージを追加することになりそう。

![](/2026-02-26/uftIa9iXghLCNr1ZzgUtyhMx.png)

　焼き終わり。

![](/2026-02-26/TEkN6G5ukVnkmKUDuTObzCzs.png)

　WiFiの設定はしてあるので、電源を入れて、そのままssh接続。

　% ssh kinneko@pi5.local.

　kinneko@Pi5:~ $ sudo apt-get update

　kinneko@Pi5:~ $ sudo apt-get upgrade

　unzipはデフォルトでインストール済み。いるのか？

　kinneko@Pi5:~ $ unzip -v

　UnZip 6.00 of 20 April 2009, by Debian. Original by Info-ZIP.

　(snip)

　公式マニュアルに従って設定する。

> Claude Code をセットアップする<br>
> <https://code.claude.com/docs/ja/setup>

![](/2026-02-26/qJVrpIeMK8vn0F3KZaVyQFb8.png)

　RaspiOSは、Debian系なので、インストール条件のDebian10以降に合致する。

　「ハードウェア: 4 GB 以上の RAM」とある。このPi5ってどんな構成だっけ？

　環境は8GのRaspi5ね。

　kinneko@Pi5:~ $ free -h

　total        used        free      shared  buff/cache   available

　Mem:           7.9Gi       423Mi       6.6Gi        14Mi       951Mi       7.5Gi

　Swap:          2.0Gi          0B       2.0Gi

　「Node.js 18 以上: 非推奨の npm インストールにのみ必要です」とあるので、とりあえずはいらないね。

　インストールはインストールシェルスクリプトをcurlで落として、シェル直渡し。

　curl -fsSL https://claude.ai/install.sh | bash

　中身が気になるところだけど、みなさん使っているやつだし、今回は中まで見ないでインストールを優先する。

　kinneko@Pi5:~ $ curl -fsSL https://claude.ai/install.sh | bash

　しばらく何も応答がないね...

　なんか出てきたけど、やってるだけでレスポンスはない。なんかビルドしているのかな？

![](/2026-02-26/2XleZ46hUuZPtVXdLVHJIHBp.png)

　10分くらいなにも起きない。謎。

　kinneko@Pi5:~ $ curl -fsSL https://claude.ai/install.sh | bash

　Setting up Claude Code...

　Installing Claude Code native build latest...

　bash: line 150:  9975 Killed                  "$binary_path" install ${TARGET:+"$TARGET"}

　エラーだよ... まぁ、こうでなくっちゃねw

　ダウンロードには成功していて、実行時のエラーだね。

　日本語のほうのトラブルシューティングにはそれっぽい項目はない。

> トラブルシューティング - Claude Code Docs<br>
> <https://code.claude.com/docs/ja/troubleshooting>

　が、英語のほうにはあるのね。

> Troubleshooting - Claude Code Docs<br>
> <https://code.claude.com/docs/en/troubleshooting>

　メモリが付属してOOM Killerに終了させられたということらしい。マジかよ...

> Install killed on low-memory Linux servers<br>
> <https://code.claude.com/docs/en/troubleshooting?#install-killed-on-low-memory-linux-servers>

　もっかい、8GBあることを確認してみる。swapも2GB設定されている。

　kinneko@Pi5:~ $ free -h

　total        used        free      shared  buff/cache   available

　Mem:           7.9Gi       271Mi       7.6Gi       2.8Mi       148Mi       7.6Gi

　Swap:          2.0Gi        48Mi       2.0Gi

　これでも足りないって、どゆこと？

　解決方法には、2GBのswapを作ってリトライせよとある。いや、もうあるってば。

　なんか不安定という報告もあるねぇ...

　この例ではインストールは成功しているみたいだけど。

> [BUG] Native installer reports success but fails to install binary on Raspberry Pi (ARM64) · Issue #20490 · anthropics/claude-code<br>
> <https://github.com/anthropics/claude-code/issues/20490>

　アーキの誤認識問題は解決されているよう。

> Native Installer Incorrectly Rejects aarch64 as "Unsupported architecture: arm" #3569<br>
> <https://github.com/anthropics/claude-code/issues/3569>

　インストールの進捗が表示されないというのもバグっぽい。

> install.sh appears stuck during download and fails silently when installMethod=native exists #20345<br>
> <https://github.com/anthropics/claude-code/issues/20345>

　まぁ、そのままもっかい実行してみるか。

　インストール中のメモリをモニタにしてみる。あー、あかん、食い尽くした...

　kinneko@Pi5:~ $ free -h

　total        used        free      shared  buff/cache   available

　Mem:           7.9Gi       7.9Gi        34Mi       880Ki        30Mi        16Mi

　Swap:          2.0Gi       2.0Gi       640Ki

　ssh切れた。

　kinneko@Pi5:~ $ client_loop: send disconnect: Broken pipe

　というわけで、OOMであることははっきりした。
