　時代は変わっていくのね...

　前は、nodeの実行環境の問題で、ロゼッタ２のi386環境で動かしていたな。こんな感じか。

```text
% arch -x86_64 zsh
% arch
i386
```

　新しいプレゼン用にディレクトリを切って、slidevの環境を整える。

```text
% mkdir ~/Documents/ossslide
% cd ~/Documents/ossslide
% npm init slidev
Need to install the following packages:
create-slidev@0.33.1
Ok to proceed? (y) y

●■▲
Slidev Creator  v0.33.1

✔ Project name: … ossslide
Scaffolding project in ossslide ...
Done.

✔ Install and start it now? … yes
? Choose the agent › - Use arrow-keys. Return to submit.
❯   npm
yarn
pnpm
```

　npmを選ぶ。

```text
✔ Choose the agent › npm

added 430 packages, and audited 431 packages in 40s

65 packages are looking for funding
run `npm fund` for details

found 0 vulnerabilities

> dev
> slidev --open



●■▲
```

　ブラウザがラウンチしてスライドが開いた。"http://localhost:3030/1"になっている。slidevもv0.33.1に上がっている。
