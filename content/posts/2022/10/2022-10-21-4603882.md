　22.10では、aptコマンドを実行するとUbuntu Proの宣伝が表示されるそうだ。

　Try Ubuntu Pro beta with a free personal subscription on up to 5 machines.

　Learn more at https://ubuntu.com/pro

　個人的にはあんまり気にならない１行表示の広告。ユーザーのクレームがあるので、そのうちやめるのじゃないかな？

　22.10のリリーススケジュールでは、現在はまだRC版。

　RC版　　　　2022年10月13日

　リリース版　2022年10月20日

　UTM環境があるので、ちょっと試してみるかな。もうRC期間に入っているのだけど、サイトはまだβのまま。

> Ubuntu 22.10 (Kinetic Kudu) Beta<br>
> <https://cdimage.ubuntu.com/releases/22.10/beta/>

　arm64のイメージはこれかな。

<https://cdimage.ubuntu.com/releases/22.10/beta/ubuntu-22.10-beta-live-server-arm64.iso>

　ubuntu-advantageというデーモンが動いている。表示の情報更新をやっているのはこいつかな？

　aptコマンドで広告を表示している実体は/etc/apt/apt.conf.d/20apt-esm-hook.conf。

```text
kinneko@2210ubuntu:~$ cat /etc/apt/apt.conf.d/20apt-esm-hook.conf
APT::Update::Post-Invoke-Stats {
"[ ! -f /usr/lib/ubuntu-advantage/apt-esm-hook ] || /usr/lib/ubuntu-advantage/apt-esm-hook post-invoke-stats || true";
};

APT::Install::Post-Invoke-Success {
"[ ! -f /usr/lib/ubuntu-advantage/apt-esm-hook ] || /usr/lib/ubuntu-advantage/apt-esm-hook post-invoke-success || true";
};

APT::Install::Pre-Invoke {
"[ ! -f /usr/lib/ubuntu-advantage/apt-esm-hook ] || /usr/lib/ubuntu-advantage/apt-esm-hook pre-invoke || true";
};

AptCli::Hooks::Upgrade {
"[ ! -f /usr/lib/ubuntu-advantage/apt-esm-json-hook ] || /usr/lib/ubuntu-advantage/apt-esm-json-hook || true";
};
```

　いまのところ、スクリプトで指定されたファイルはどれも存在しなかった。情報更新されていないからかな？

```text
kinneko@2210ubuntu:~$ ls /usr/lib/ubuntu-advantage
auto_attach.py    daemon.py             reboot_cmds.py  upgrade_lts_contract.py
cloud-id-shim.sh  patch_status_json.py  timer.py
```

　広告を出さないようにするには、４つ方法がある。

**1. ubuntu-advantage-toolsを削除する**

```text
$ sudo apt-get --purge  remove  ubuntu-advantage-tools
```

　これは、ちょっと乱暴かな。ubuntu-advantage-toolsには他にもメリットがありそうなので、そのまま削除するのはもったいない気もする。

　一方で、そもそも、こんなお仕着せのツールはいらないとう考えもありそう。

**2. 20apt-esm-hook.confを削除して空のファイルを置く**

```text
$ sudo mv /etc/apt/apt.conf.d/20apt-esm-hook.conf
$ sudo mv /etc/apt/apt.conf.d/20apt-esm-hook.conf.bak
$ sudo touch /etc/apt/apt.conf.d/20apt-esm-hook.conf
```

　これは、あんまりスマートな方法ではない感じ。広告を表示するフックポイントを削除する。空のファイルを置くのは、パッケージ管理を壊さないため。トリガをピンポイントで無効にするという点では良いhackだ。

**3. 88-esm-announceを削除して空のファイルを置く**

　２と同様の手法で、こちらはメッセージを表示させている実体を削除してしまう方法。こちらも、あんまりスマートな方法ではない感じ。

```text
$ sudo rm /etc/update-motd.d/88-esm-announce
$ sudo touch /etc/update-motd.d/88-esm-announce
$ sudo systemctl disable ubuntu-advantage
```

```text
kinneko@2210ubuntu:~$ cat /etc/update-motd.d/88-esm-announce
#!/bin/sh
stamp="/var/lib/ubuntu-advantage/messages/motd-esm-announce"

[ ! -r "$stamp" ] || cat "$stamp"

kinneko@2210ubuntu:~$ ls /var/lib/ubuntu-advantage/messages/motd-esm-announce
ls: cannot access '/var/lib/ubuntu-advantage/messages/motd-esm-announce': No such file or directory
```

**4. /var/lib/ubuntu-advantage/messages/*.tmplを削除する**

　これは、メッセージテンプレートの削除。上書きされちゃいそうな感じがするので、あまりよい対策ではなさそう。

```text
$ sudo rm /var/lib/ubuntu-advantage/messages/*.tmpl

kinneko@2210ubuntu:~$ ls /var/lib/ubuntu-advantage/messages/*.tmpl
ls: cannot access '/var/lib/ubuntu-advantage/messages/*.tmpl': No such file or directory
```

**5. /etc/default/motd-newsに設定があるのでENABLEDを0にする**

　これは、そもそも組み込まれている設定なので、一番矛盾が少ない気がする。

```text
kinneko@2210ubuntu:~$ cat /etc/default/motd-news
# Enable/disable the dynamic MOTD news service
# This is a useful way to provide dynamic, informative
# information pertinent to the users and administrators
# of the local system
ENABLED=1

# Configure the source of dynamic MOTD news
# White space separated list of 0 to many news services
# For security reasons, these must be https
# and have a valid certificate
# Canonical runs a service at motd.ubuntu.com, and you
# can easily run one too
URLS="https://motd.ubuntu.com"

# Specify the time in seconds, you're willing to wait for
# dynamic MOTD news
# Note that news messages are fetched in the background by
# a systemd timer, so this should never block boot or login
WAIT=5
```

　とりあえず、いまのところ広告は表示されていないし、２行くらいだと気にならないので、変更はせずに静観することにする。実行するなら５番目の方法かな。
