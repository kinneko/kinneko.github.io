　組み立てはできたので、こんどはインストールをやろう。

　CDメディアが付属していたので、中を見てみた。

![](/2022-12-13/4810451-01.png)

　Windows専用のexeファイルがあるだけで、macOSでは何もできない感じ。おそらく、Windows用のキーボードのドライバだと思われる。

![](/2022-12-13/4810451-02.png)

　付属のSDカードには、「WD Labs Foundation Editionソフトウェア」がインストールされている。これは、標準的なNOOBSブートローダーをforkしたもので、選択したOSをUSBハードディスクドライブ（HDD）に直接インストールすることができるようになっている。複数のOSのインストールも可能。

　正式版からさらにforkしたコミュニティエディションは、ここで公開されている。あまり保守はされていない感じ。

> GitHub - PiDrive/CommunityFoundationEdition: A community maintained version of the discontinued software for the WDLabs PiDrive<br>
> <https://github.com/PiDrive/CommunityFoundationEdition>

　USBストレージから起動するようなforkがあるのは面白い。

　現在は、Pi3B+以降についてはUSBブートができるfirmwareが公開されているので、こういうソフトウエアももう開発されないのだろうな。

　まずは、イメージのバックアップを作っておく。マウントして見えるfatの中身はこんな感じ。

![](/2022-12-13/4810451-03.png)

![](/2022-12-13/4810451-04.png)

　そのままディスクユーティリティでイメージバックアップしようと思ったら、失敗した。どゆこと？

![](/2022-12-13/4810451-05.png)

　ドライブの中身を見ると、fatだけでないパーティションも含まれているようだ。でも、なんでイメージ作成に失敗するの？

```text
% diskutil list /dev/disk4
/dev/disk4 (external, physical):
#:                       TYPE NAME                    SIZE       IDENTIFIER
0:     FDisk_partition_scheme                        *4.0 GB     disk4
1:             Windows_FAT_16 RECOVERY                2.2 GB     disk4s1
2:                      Linux                         33.6 MB    disk4s5
(free space)                         1.7 GB     -
```

　ddでバックアップしてみる。

```text
% sudo diskutil unmountDisk /dev/disk4
Password:
Unmount of all volumes on disk4 was successful
% sudo dd if=/dev/rdisk4 of=~/Downloads/RECOVER_PiDrive.img bs=1m
dd: /dev/rdisk4: Operation not permitted
% sudo dd if=/dev/disk4 of=~/Downloads/RECOVER_PiDrive.img bs=1m
dd: /dev/disk4: Operation not permitted
```

　ん？ パーミッションエラーになってますね。なんでだろ？

　調べてみると、ファイルシステムへのアクセス権限が細かくなって、Catalina 10.15以降は、デフォルトでは許可されていないようだ。

　システム環境設定の「セキュリティとプライバシー」から、iTermにディスクフルアクセスの権限を付与する。

![](/2022-12-13/4810451-06.png)

　iTermを指定したら再起動を要請されたので、使ってないターミナルを追加指定した。

![](/2022-12-13/4810451-07.png)

　再度やってみたけれど、こちらも失敗。「No such file or directory」という妙なエラーになった。シェルがうまく展開できていないのかも。

```text
% sudo dd if=/dev/disk4 of=~/Downloads/RECOVER_PiDrive.img bs=1m
Password:
dd: ~/Downloads/RECOVER_PiDrive.img: No such file or directory
% sudo dd if=/dev/rdisk4 of=~/Downloads/RECOVER_PiDrive.img bs=1m
dd: ~/Downloads/RECOVER_PiDrive.img: No such file or directory
```

　ディスクユーティリティのほうにも権限を追加する。

![](/2022-12-13/4810451-08.png)

　イメージ作ってみたけれど、これはFat部しかバックアップされないわ...

![](/2022-12-13/4810451-09.png)

![](/2022-12-13/4810451-10.png)

　ddで三度目。こんどはパスを入れないようにディレクトリを移動しておく。

```text
% cd Downloads
% sudo dd if=/dev/rdisk4 of=RECOVER_PiDrive.img bs=1m
3781+1 records in
3781+1 records out
3965190144 bytes transferred in 100.030136 secs (39639956 bytes/sec)
% sudo dd if=/dev/disk4 of=RECOVER_PiDrive2.img bs=1m
3781+1 records in
3781+1 records out
3965190144 bytes transferred in 228.858123 secs (17325975 bytes/sec)
```

　こんどは、diskでもrdiskでも成功した。なんか、すごく遠回りした気分だ。

　PiImagerでSDカードからのバックアップできたような気がしたのだけど、そんな機能はなかった。残念だ。

　imager_1.7.3が出ていたので、ついでにアップデートしておいた。
