　というわけで、まずは標準ファームを焼き直してみる。バージョン情報は表示されていないので、現在のファームウエアバージョンはわからな。

　製品添付のデータは、CD-Rに詰まったものが物といっしょに引き渡されている。中はまったくみていなかったので、確認してみたけれどファームイメージのファイルは含まれていなかった。

![](/2022-02-06/3250807-oJIbgBMkkhRKpPpVvOIbBZQH.png)

　ファームウエアイメージは、HICTOPのサイトからhexファイルがダンロードできる。

> Firmware - Hictop 3d printer<br>
> <https://www.hic3dprinter.com/pages/firmware>

![](/2022-02-06/3250807-1WDUZyybuvDdpjaJn2vtz59F.png)

　と、思ったら、アクセス権が必要と言われる。リクエスト出してみる。まぁ、ダメかな。

![](/2022-02-06/3250807-XG6nR4ACd2lYnIPgHgCxPLMn.png)

![](/2022-02-06/3250807-DrATfRqGeB3vx5tHexegOsms.png)

　ソースコードは落とせる。rarアーカイブファイルになっている。398というのがバージョンのようだ。

![](/2022-02-06/3250807-o8Wx1ANOpBbWqCrWtvd3L14I.png)

　Webサイトには、「E0ポートの代わりにE1を使用する 」と注意書きが書かれているのはなんだろう？ USBからはアップデートできないのかな？

　3Dプリンタ関連では、わりとファームウエアなども置いてあるThingiverseを検索してみる。

　あったあった。純正のファームウエアのソースコードを、この時点(2018/12/16)の最新のMarlin 1.1.9にポートして、さらに修正を加えたもののようだ。オリジナルのパッチには「// Hictop」、作者のパッチには「// BNV」がコメントとしてつけられているとのこと。

> Hictop 3DP17 Marlin latest firmware configuration by vlachoudis - Thingiverse<br>
> <https://www.thingiverse.com/thing:2829405>

![](/2022-02-06/3250807-BznrRfFCXfcA9hXCrT6Mv8XB.png)

　作者の使っているボードの写真が上がっているけど、シルクには「MPX.3」とある。手持ちのものは「MPX V1」なので微妙に違うのが気になるところだ。

　ダウンロードしたHictopConfiguration.zipファイルの中には、"Configuration.h"と"Configuration_adv.h"しか入っていない。こんなものか。

　Marinの開発は、最近はすっかり2.0ベースになってしまっていて、1.1.x系は2年くらい前からメンテナンスされていない。

> GitHub - MarlinFirmware/Marlin at 1.1.x<br>
> <https://github.com/MarlinFirmware/Marlin/tree/1.1.x>

　Thingiverseには、こんなものもあった。

> Hictop 3DP17_398 Bad firmware partial fixed:14116 - General - Prusa i3 - Groups - Thingiverse<br>
> <https://www.thingiverse.com/groups/prusa-i3/forums/general/topic:14116>

　GitHubにも3DP-17関連がないか探してみる。

　これはオリジナルの398と同じかな？

> GitHub - andywiddess/Marlin_3DP17_398: Hictop 3DP17 Printer Firmware<br>
> <https://github.com/andywiddess/Marlin_3DP17_398>

　こちらは改変されているもの。

> GitHub - jbramsden/Hictop-Marlin: Marlin configuration files for a Hictop 3D printer<br>
> <https://github.com/jbramsden/Hictop-Marlin>

　ダウンロードして差分を確認してみる、

　Thingiverseにあるものと多少は内容が違うようだ。githubのほうが少し新しい感じがする。

　とりあえずは、純正のhexが手に入らない感じなので、HICTOPからダウンロードしたファイルをビルドしてみる。

　"/Users/[ユーザー名]/Documents/Arduino/"に、rarアーカイブファイルを展開した「Marlin_3DP17_398」をコピーして、ArduinoIDEから開く。

![](/2022-02-06/3250807-KaM00EKvUtwI5KVT1v4FLuNu.png)

　Marlin_3DP17_398.inoを選んで開く。

![](/2022-02-06/3250807-sPhHHdZ5wrYC2wvirI6CqVbU.png)

![](/2022-02-06/3250807-scuEZ3zqJQtJetF7mkFFB8Wb.png)

　ボードに乗っているのは、ATMEGA2560なので、ターゲットボードをMega 2560に設定する。

![](/2022-02-06/3250807-dl0BAI4xF2tX03ve1UIBHK4S.png)

　まずは、ビルドできるかどうか確認する。さっそくエラーで止まった。メッセージは、"using typedef-name 'fpos_t' after 'struct'"。

![](/2022-02-06/3250807-suA3NMbBQ8npGceYVFMI5opp.png)

　こちらの動画では、かなり古いArduinoIDEを入れるように案内している。それは乱暴すぎてないな...

　Solution for "using typedef-name 'fpos_t' after 'struct'" error in Arduino while uploading - YouTube

ttps://www.youtube.com/watch?v=2rRCdFzMxG4

　Arduino AVR Boards 1.6.12以降でコンパイラが変更になって対応できないようだ。

　1.6.11を入れると問題ないらしい。しかし、このためだけにライブラリのダウングレードもないな...

　というわけで、ビルドエラーの解決編は支援者向けのSideBをご覧ください。
