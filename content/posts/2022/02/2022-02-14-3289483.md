　Marlin 2.0で設定ファイルを書いて、ビルドできるものを作った。できたファームウエアを本体に焼いてみる。Y軸の戻りがダメなのの確認と、エクストルーダーが動くようになっているといいな。

　ファームを焼き込みした。

![](/2022-02-14/3289483-01.png)

　表示がカタカナになったのだけど、わかりにくいのと、なんかメニューによってはちゃんと動作していない感じ。誰も日本語メニュー使っていないのもわかる感じ。最近は、こんな表示装置使わずに、カラー液晶で大型になってきているので、誰もメンテナンスしないのだろうなぁ。

![](/2022-02-14/3289483-02.png)

　Y軸、前後は問題なく動いている。おそらく、HICTOPのソースコードに何か問題があったと思われる。

　ただし、動きがなんか逆回転のような。Auto Homeにすると、ステージがまず前にでてくる。Y軸のエンドストップのスイッチは後ろ側にあるので、稼働範囲のリセットが効いていない。これはダメじゃなかろうか。動作中にエンドストップのスイッチを押して見ても反応しなかった。スイッチもおかしい？

![](/2022-02-14/3289483-03.png)

　エクストルーダーの動作については、温度センサーをチェックしていて、ヘッドのヒーターが動作しない現状では、回してみることもできなかった。サーミスタをライターで炙るみたいな手も使えるのだけど、そこまではやらなかった。

　サーミスタそのものは、指でつまむと温度表示が上がるので、動作しているのは確認できた。

![](/2022-02-14/3289483-04.png)

　ヒードベッドのセンサも、室温が上がると反応していたので、温度センサまわりは問題なく動作しているようだ。

　X軸とZ軸のセンサも動作している。

　Y軸の逆回転設定を戻してみるか。あとは表示は英語モードにしよう。こういうとき、gitで管理していると差分探すのが楽だ。

　エンドストップのスイッチは軸に対して１つしかないので、MAXのほうはない。これ間違いね。falseにしてみる。

```diff
-#define X_MAX_ENDSTOP_INVERTING false // Set to true to invert the logic of the
endstop.
-#define Y_MAX_ENDSTOP_INVERTING false // Set to true to invert the logic of the
endstop.
-#define Z_MAX_ENDSTOP_INVERTING false // Set to true to invert the logic of the
endstop.
+#define X_MAX_ENDSTOP_INVERTING true // Set to true to invert the logic of the
endstop.
+#define Y_MAX_ENDSTOP_INVERTING true // Set to true to invert the logic of the
endstop.
+#define Z_MAX_ENDSTOP_INVERTING true // Set to true to invert the logic of the
endstop.
```

　言語設定もenにする。

```diff
+#define LCD_LANGUAGE jp_kana
```

　反転設定はこのへんかな。INVERT_Y_DIR trueにする。

```diff
// Invert the stepper direction. Change (or reverse the motor connector) if an axis goes the wrong way.
#define INVERT_X_DIR false
-#define INVERT_Y_DIR true
-#define INVERT_Z_DIR false
+#define INVERT_Y_DIR false
+#define INVERT_Z_DIR true
```

　焼くと無事英語表示された。

![](/2022-02-14/3289483-05.png)

　AutoHomeも無事うまくいくようになった。Y軸のエンドストップスイッチは使われている気がしないけど、まぁいいか。

![](/2022-02-14/3289483-06.png)

　Marlin 2.0での動作がうまくいような素直なハードウエア構成でよかったという感じ。

　あとは、利用許諾がGPLなMarlin使っているのに、まともに動くソースコード出してないHICTOPは選んではいけないメーカーということで。

　さて、ようやく譲り受けたときの不具合報告のあった、サーミスタが異常値を出してしまう問題に取り組める。

　たぶん、サーミスタの配線が剥き出しなので、ショートしただけではないかと思っているだけど。とりあえず、片側をマスキングテープで絶縁して、動作がうまくいくようならハンダ付けして熱収縮チューブをかける方針。

![](/2022-02-14/3289483-07.png)

　さて、ヘッド部を再度組み上げて電源を入れていろいろ試してみる。

　フィラメントロードをするのに、ヘッドの温度を180度に上げてみたのだが、みごとに240度を越えて止まる気配がない。報告のあったのはこれか。ヒーターの電源をオフにする制御ができていない感じ。やっぱボードダメかな...

　普通の場合より、サーミスタでの温度検知の上がり具合が数倍くらい早い。3DP-17は24V機なので、12V用のヒーターに24V流している疑惑もある。ヒーターには規格は何もプリントされていないので困る。同じようなヒーター間違いの症状は、MagicにDelta機の予備のヒーター使って試したときにも経験している。

　ヒーターのボード側への接続は問題なさそう。

![](/2022-02-14/3289483-08.png)

　フィラメント検出用のスイッチは、取り付け位置的に、どうにも使えないような配置になっている。Z軸が上の方に上がってきたとき、フィラメントが通っていると、ダイレクトエクストルーダーの穴と並行に近い位置になってしまって、フィラメントが折れてしまう。これはヘッド部に移動しなくてはいけないだろう。とりあえず、固定するのをやめて、ぶら下げて使うことにした。

![](/2022-02-14/3289483-09.png)

　フィラメントフォルダには、製品には付属しいているはずの長めの8mmくらいのボルトとナットが付属していなかったので、とりあえずバーレンチの8mmを使ってしのぐ。

![](/2022-02-14/3289483-10.png)

　あと、やっぱりY軸のエンドストップスイッチは反応していないようだ。ただ、表示されるY軸の数値的には、こちらはMAX側なので、Y軸だけMAX側のスイッチという設計なのかもしれない。設定を変更してみる。

```diff
#define Y_MIN_ENDSTOP_INVERTING false
#define Y_MAX_ENDSTOP_INVERTING true
```

　ダメだな。ステージが前に出過ぎて空回りしてしまう。

　これを指定した上で、"INVERT_Y_DIR false"かな？ 変更しておく。でも、それって、最初に戻っただけ？

　Y軸のスイッチをベッドの下に付け直し、出荷時状態に戻してリトライすると、こんどはスイッチはうまく効いて、ちゃんと動いている。うーん...

　ヘッドを再度加熱してみる。ビビってコンセントを抜かずにいると、PLAのデフォルト値の180度設定が一度240度まで上がり、さらにそこから下げている。制御が間に合ってないだけで、しばらく放置すると174-185度くらいの間で落ち着いてくる。ちょっと振れ幅が大きいが、これはパラメーター調整を詰めていけばしのげそうだ。

![](/2022-02-14/3289483-11.png)

　ヘッドの加熱ができたので、エクストルーダーの動作も確認できた。ちゃんと動いている。

　しかし、ヘッドを加熱してフィラメントをロードしてもフィラメントが押し込まれない。

　こんどは、ヘッドが詰まっている疑惑。いろいろ問題が出て、先が長すぎるわ...

　ノズルを外してみると、完全に詰まっている。

![](/2022-02-14/3289483-12.png)

　ノズルは、なんか買ったときにオマケでついてきたやつを使う。５個入りでどれも同じだろうと無意識に最初に出てきたやつを付けたら0.6mmのやつだったので、残りから0.4mmのものを探して交換した。

![](/2022-02-14/3289483-13.png)

　詰まっていたのはノズルだけで、ヒートブレイク側は詰まってない様子。向こう側の明かりが見えるし、付着物もほとんどないようだ。ヒートブロック側への樹脂漏れもおきていない。

　ヒートブレイクは、ちょっと長い特殊なやつなのでスペアパーツを頼んでおいたほうがいいのかもしれない。

![](/2022-02-14/3289483-14.png)

　PLA設定でのベッドの温度のデフォルトが70度とちょっとありえないので、Marlinの設定で30度に変更した。

　再度ヘッドを加熱して、フィラメントをロードしてみる。こんどは、ヒートブレイクとエクストルーダーの穴がうまく合ってないようで、フィラメントが押し込めない。組み立ての時には、フィラメントの端っこを入れてみて通るのを確認したのだけどな...
