　表示はうまくいったので、サンプルコードを試してみる。

　提供されているサンプルコードは以下の図のように６種類ある。

![](/2022-01-07/3140336-wxGuHgEHnzVkWZJtxhgLmeAy.png)

　SSD1306SimpleDemoは素直に動く。右下の数字をカウントアップしながら、フォントサイズ３種類のハロワ三行表示、英文字四行表示、図形表示、進捗表示のラインアニメーション、WiFiのロゴ表示などを行なってゆくデモが見られる。

　Hellowリフレッシュも結構早いじゃないの。このくらい出れば、LovyanGFXはいらないかな。

![](/2022-01-07/3140336-wgDVnxWw6fkCq2w3Vc1nb18H.png)

![](/2022-01-07/3140336-rQWS7ggjYlkVGndBX2ZMu2pt.png)

　リフレッシュの具合が写真ではわからないので動画を撮っておく。

　ttps://www.youtube.com/watch?v=Hih9uGi5tfw

　配線がいろいろ邪魔なので、ジャンパ線を短いものに変更する。クロスする配線２本になるのでめんどくさい。

![](/2022-01-07/3140336-kvCsnpc0DnKdpGqsjWTXAMmB.png)

　SSD1306DrawingDemoも普通にビルドと書き込みができた。

　このデモは無限ループではないようだ。表示は、四隅からのライン描画、四角を細線と太線で入れ子描画、同心円描画、円の描画、小さい文字の立てスクロールという感じ。

![](/2022-01-07/3140336-b5HHFyMNyopp7wvJgq9UMiwV.png)

　SSD1306TwoScreenDemoは、動かないようだ。リセットしても画面真っ暗。シリアルポートには何も出していないようだ。

　スケッチを見ると、２つのLCDを初期化しているので、スクリーンバッファが２つというわけではなく、物理２画面という感じ。めんどくさいのでパス。

```cpp
　　SSD1306Wire  display(0x3c, 0, 14);
　　SSD1306Wire  display2(0x3c, 5, 4);
```

　SSD1306UIDemoは、５つの画面をスクロールで順に表示するもの。なにかボタンでも用意する必要があるのかと思ったけど、そういうことではないようだ。uiでラップしてやると、画面数に応じたドットのガイドが出てくるような感じか。

![](/2022-01-07/3140336-T9XlvIpftXrhEMBcLILWemgZ.png)

![](/2022-01-07/3140336-25V0fTT2tM5QTXkLkDSRTYnY.png)

　SSD1306OTADemoを書き込む。なにも起きない。しょうがないので中を見る。

```cpp
const char *ssid         = "[Your SSID]";
const char *password     = "[Your Password]";

void setup() {
  WiFi.begin ( ssid, password );
  // Wait for connection
  while ( WiFi.status() != WL_CONNECTED ) {
    delay ( 10 );
  }
```

　ネットワークにつながらないと先に進まないのね。WiFi接続のssidとpasswordは入れて書き込まないといけない作りだ。

　ネットワークが認識すると、"Ready for OTA: IPアドレス"を表示。OTAを検知すると"OTA Update"と表示する。OTAが開始されるとプログレスバーを表示する。OTA完了をフックして"Restart"を出す。という感じ。

　ArduinoOTAは使ったことないからわかんないな... 確か、これ入れるとシリアル奪われるのでシリアルも使えなくなるんだよな...

　というわけで、書き込む。想定通りの表示になった。

![](/2022-01-07/3140336-9QpFGd2dKYlOU7U6xG1OI6FZ.png)

　ArduinoOTAで使うネットワークポートが表示されないので、Macbook Proを同じ2.4GHzに接続しないおして、ArduinoIDEを再起動したら表示されるようになった。

![](/2022-01-07/3140336-msPdbELNTEmU6OABijZGSKNM.png)

　シリアルポートをネットワークポートに設定して、スケッチを"Ready for OTA2"に変更してアップデートを実行してみる。とはいっても普通にコンパイルして書き込むのと同じ。

![](/2022-01-07/3140336-zhupspy662JocgWTTtERj8aC.png)

　認識した。プログレスバーが表示される。ファームウエアの転送は、USBシリアル接続よりも時間がかかる。

![](/2022-01-07/3140336-5Ns6llQtH4WeT1JQiRuuIE4T.png)

　終わるとRestartが表示された。

![](/2022-01-07/3140336-IypGx8TQ0FCnmjPbhQlLe3x7.png)

　表示もOTA2になっている。

![](/2022-01-07/3140336-F41FjlwHXdwYW6ZdyvivsnK7.png)

　SSD1306ClockDemoは、デジタル時計とアナログ時計を表示するだけのもののようだ。TimeLib.hがないというエラーになる。なんだこのライブラリ？

![](/2022-01-07/3140336-mcL6fUNepBHWPHBU7RKJCrcM.png)

　Arduino Time Libraryは、基本的には、Playground DateTime libraryを改良したもので、APIを使いやすくしたということらしい。必要かといわれると、そうでもない気がする。ESP32向けということではないようだ。

> GitHub - PaulStoffregen/Time: Time library for Arduino<br>
> <https://github.com/PaulStoffregen/Time>

　ライブラリマネージャでPaulStoffregenで検索しても、それらしいものは出てこない。

![](/2022-01-07/3140336-JEq3Bi0BGLjDIiKdfu1upzVP.png)

　Githubに「Using the Arduino Library Manager, install "Time by Michael Margolis".」と書かれているので、Time by Michael Margolisで検索してみたけれど、こちらも何も出てこない。

![](/2022-01-07/3140336-pkH48KtVc2x8QUNQPPZrvuXe.png)

　ArduinoIDE 1.8系対応にメンテナンスされていないので、ライブラリマネージャから除外されたのかもしれないな。手動で入れるしかないのかな？ 時計は特にいらないといえばいらないのでパスだな...
