> SSD1306のデータシートは、このへん。<br>
> <https://cdn-shop.adafruit.com/datasheets/SSD1306.pdf>

　制御はI2Cで、アドレスは0x3cのようだ。基板上のジャンパでアドレスが0x3aとトグルのようなので、現物の配線を確認すること。でも、たいていは0x3cがデフォルト。

　R3,R4が関連してそうだけど、表記は特になくてよくわからない。0Ωのチップ抵抗でハンダされている。チップが揃ってなくて、ハンダのリフロー温度か加温時間がイマイチかもしれない。

![](/2022-01-04/3138207-x5ucMqMiiWGXOuO4XsSzj0aV.png)

　基板からは４ピンが生えていて、以下のような並び。

　1: GND

　2: VDD (3.3〜5V)

　3: SCK (I2Cクロックライン)

　4: SDA (I2Cデータライン)

　SDA・SCL線は、I2C使用時にはプルアップの必要なのだが、ArduinoのI2Cライブラリ(esp32-hal-i2c.c)内で自動でpinModeの設定をやってくれるようだ。

　ターゲットデバイスは、今回はESP32で配線することにした。NodeMCU-32Sと自作のバタフライブレッドボードの組み合わせは便利だもの。

　ESP32との接続配線は、GPIO21(SDA),22(SCL)を使う。電源は5Vじゃないくて、同じ側にある3.3Vでもだいじょうぶだろう。配線が基板の片側だけで済む。

　SSD1306のドライバは、シンプルな描画用には"ESP8266 and ESP32 Oled Driver for SSD1306 display"というのがあるので、まずはそれを使う。ライブラリマネージャから導入できる。ソースはこちら。

> GitHub - ThingPulse/esp8266-oled-ssd1306: Driver for the SSD1306 and SH1106 based 128x64, 128x32, 64x48 pixel OLED display running on ESP8266/ESP32<br>
> <https://github.com/ThingPulse/esp8266-oled-ssd1306>

　ライブラリマネージャを開いてキーワード検索してやる。

![](/2022-01-04/3138207-IbG9ExgpjlA9KWkmWgNEYBTm.png)

　インストールボタンを押して、インストール完了。

![](/2022-01-04/3138207-1eaPtM1BKkoibTqi9YbjUmm7.png)

　ドライバ類については、ググってみると、SSD1306用の汎用ライブラリと、描画を支援するAdafruit GFX Libraryを使う例が書かれていることが多いようだ。

> GitHub - adafruit/Adafruit-GFX-Library: Adafruit GFX graphics core library, this is the 'core' class that all our other graphics libraries derive from<br>
> <https://github.com/adafruit/Adafruit-GFX-Library>

　ESP32の場合は、SSD1306Wire.hでとりあえず足りるようなので、２つ入れなくていい分楽だ。

　ただ、高速描画が必要になってくると、らびやんさんが公開しているグラフィックライブラリLovyanGFXが必要になるかもしれない。

> GitHub - lovyan03/LovyanGFX: SPI LCD graphics library for ESP32 (ESP-IDF/ArduinoESP32) / ESP8266 (ArduinoESP8266) / SAMD51(Seeed ArduinoSAMD51)<br>
> <https://github.com/lovyan03/LovyanGFX>

　まずは基本のハロワ表示をする。(0,0)の位置にHello Worldを表示するサンプル。

　I2Cを使うためのWire.hの宣言は、1.6.5以降のArduinoIDEでは不要になったそうだ。ビックリ。

```cpp
#include "SSD1306Wire.h"
SSD1306Wire display(0x3c, 21, 22);
void setup() {
  display.init();
  display.setFont(ArialMT_Plain_16);
  display.drawString(0, 0, "Hello World");
  display.display();
}
void loop() {}
```

　パラメーターはこんな感じ。シリアルポートをボードに合わせておく。
