　USB-HDMIコンバータでデフォルト表示すると、解像度がFull HDになってしまうので、キャプチャ画像を作るときに見にくい。/boot/config.txtを編集して、出力解像度を抑制する。

![](/2021-03-15/1989478-PLmcHY054CTUJLv1qbe06DkL.png)

　Ubuntu 20.04 LTSのconfig.txtを見ると、このファイルは編集するなと書かれている。設定を書き込むファイルは、後ろのほうで指定されているsyscfg.txtとusercfg.txtに移動しているようだ。

```
Please DO NOT modify this file; if you need to modify the boot config, the "usercfg.txt" file is the place to include user changes. Please refer to the README file for a description of the various configuration files on the boot partition.
```

　このファイルは変更しないでください。 ブート構成を変更する必要がある場合は、"usercfg.txt"ファイルがユーザーの変更を書き込むための場所です。 ブートパーティション上のさまざまな構成ファイルの説明については、READMEファイルを参照してください。

```
The unusual ordering below is deliberate; older firmwares (in particular the version initially shipped with bionic) don't understand the conditional [sections] below and simply ignore them. The Pi4 doesn't boot at all with firmwares this old so it's safe to place at the top. Of the Pi2 and Pi3, the Pi3 uboot happens to work happily on the Pi2, so it needs to go at the bottom to support old firmwares.
```

　以下には通常とは異なる順序でコマンドが書かれていますが、これは意図的なものです。 古いファームウェア（特に最初にbionicに同梱されていたバージョン）は、以下の条件付き「セクション」を解釈せず、単に無視します。 Pi4では、古いファームウェアではまったく起動しないため、一番上に配置しても安全です。 Pi2とPi3のうち、Pi3 ubootはたまたまPi2で正常に動作するため、古いファームウェアをサポートするには下部に配置する必要があります。

　この場合は、syscfg.txtを見ればいいのかな？ デフォルトでは、以下のような内容だった。

```
enable_uart=1
dtparam=audio=on
dtparam=i2c_arm=on
dtparam=spi=on
cmdline=cmdline.txt
```

　usercfg.txtには、設定は何も書かれていなかった。

　参考までに、Ubuntu 20.04 LTSでは、cmdline.txtは以下に設定されていた。

```
net.ifnames=0 dwc_otg.lpm_enable=0 console=serial0,115200 console=tty1 root=LABEL=writable rootfstype=ext4 elevator=deadline rootwait fixrtc
```

　解像度のパラメータは以下に書かれている。

> Video options in config.txt - Raspberry Pi Documentation<br>
> <https://www.raspberrypi.org/documentation/configuration/config-txt/video.md>

　Pi4用の720p 30Hzの設定はCEAモードで67番になる。以下の設定を書き込む。

```
hdmi_ignore_edid=0xa5000080　←　HDMIから送信されるディスプレイ情報を無視する
hdmi_group=1　←　CEAモード（TV風の解像度モード指定）
hdmi_mode=67
```

　こんな感じ。

```
hdmi_ignore_edid=0xa5000080
hdmi_group=1
hdmi_mode=67
enable_uart=1
dtparam=audio=on
dtparam=i2c_arm=on
dtparam=spi=on
cmdline=cmdline.txt
```

　起動する。

![](/2021-03-15/1989478-nVOdXS2ZGCHYlwjeOHu9TJ5D.png)

　入力解像度は強制できたけど、出力解像度は強制できていないな... これはしょうがないか。
