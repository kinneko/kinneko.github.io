　Raspi4に、いつも入れるUbuntu Server版ではなくDesktop版をインストールしたい。が、Raspberry Pi Imagerからは Desktop 20.04が選べなくなっていた。しょうがないので、Ubuntu Serverを入れたものにDesktop環境をインストールすることになった。

　Raspberry Pi Imagerを起動して、Ubuntuを選ぶ。

![](/2021-03-16/1989831-rGgplT2JP8qJlZtxOEqJOYS6.png)

![](/2021-03-16/1989831-GLAlyXsH5wyFyNKxsaOX3pdg.png)

　が、Raspi用のUbuntuは、もう20.10がリリースされているので、Desktop版の選択肢は20.10だけで、20.04 LTSにはDesktopがない。

![](/2021-03-16/1989831-dz1adFzt59ycLbWzTCWvTXWQ.png)

　しょうがないのでUbuntu Serverを入れてからデスクトップが使えるようにする。

![](/2021-03-16/1989831-fmZ7fymw6owsq77oXur3qF12.png)

　USBアダプタにmicroSDを入れて、USB端子に差し込み、Raspberry Pi Imagerで選択する。

![](/2021-03-16/1989831-m2gjJnUOxsA6XJPoGbWLqLgn.png)

　WRITEボタンを押して書き込みを開始する。

![](/2021-03-16/1989831-nQLLo6SmrcAZ8dX5MOn3RIhH.png)

　デバイスへの書き込みは管理者権限を要求されるので、管理者パスワードを入力する。

![](/2021-03-16/1989831-s4tR49v6wmXw2VBhu7RMr0WW.png)

　ダウンロードと書き込みが開始される。

![](/2021-03-16/1989831-kcBZ1QuPjy0X9SYdH58FhSwc.png)

　書き込み後は、書き込み確認のため、ベリファイが行われる。

![](/2021-03-16/1989831-NNN46Bb5pqNkU5rF8fjiPzWd.png)

　ベリファイが成功すると、ダイアログが表示される。Raspberry Pi Imagerを終了する。

![](/2021-03-16/1989831-yfUXLd3U5bZo948IKEgwRtaB.png)

　Pi4にmicroSDを挿入して起動する。Pi4の発熱対策は、とりあえずファンは付けずにSoCにヒートシンクだけを付けておく。クロックダウンなどの問題が出るようならファンを追加することにする。

　設定には、有線LANとHDMIモニタ、キーボードの接続が必要になる。Ubuntu ServerがデフォルトでmDNSに対応してくれていれば少し楽ができるのだけど、残念ながら対応していない。

　電源を入れて起動する。初回はコンソールからしかログインできない。ユーザー名ubuntu、パスワードubuntuでログインすると、パスワードの変更を求められるので、適切なものに変更しておく。

![](/2021-03-16/1989831-cNigxdQsjXQlPaaT1oVP8Zao.png)

　パッケージデータベースを最新のものに更新し、インストール済みのパッケージも最新のものに更新しておく。41パッケージがアップグレードされて、kernel関係の４パッケージが新規にインストールされた。

```text
ubuntu@ubuntu:~$ sudo apt update && sudo apt upgrade
```

　ubuntu-desktopメタパッケージをインストールして、Desktop環境に変更する。1065パッケージが追加でインストールされるので時間がかかる。

```text
ubuntu@ubuntu:~$ sudo apt install ubuntu-desktop
(snip)
0 upgraded, 1065 newly installed, 0 to remove and 0 not upgraded.
Need to get 546 MB of archives.
After this operation, 2270 MB of additional disk space will be used.
```

　インストール後は、再起動する。

```text
ubuntu@ubuntu:~$ sudo shutdown -r now
```
