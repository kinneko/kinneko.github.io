　モーションを作っていると、USBケーブルが邪魔で引っ張られてバランスが悪くて安定しないので、Bluetoothシリアルで通信したい。

![](/2021-05-24/2222494-01.png)

　ESP32のライブラリには、標準でBluetooth SPP(Serial Port Protocol)通信のライブラリが含まれている。

> arduino-esp32/libraries/BluetoothSerial at master · espressif/arduino-esp32 · GitHub<br>
> <https://github.com/espressif/arduino-esp32/tree/master/libraries/BluetoothSerial>

　サンプルコードはこんな感じ。普通のシリアルとSPPのそれぞれで、送信されてきたデータを反対のシリアルにエコーバックしているだけ。

```cpp
#include "BluetoothSerial.h"
BluetoothSerial SerialBT;
void setup() {
  Serial.begin(115200);
  SerialBT.begin("ESP32test"); //Bluetooth device name
  Serial.println("The device started, now you can pair it with bluetooth!");
}
void loop() {
  if (Serial.available()) {
    SerialBT.write(Serial.read());
  }
  if (SerialBT.available()) {
    Serial.write(SerialBT.read());
  }
  delay(20);
}
```

　めんどくさいので、普通のシリアル通信の部分は省いてSPPだけの通信にしてテストする。

![](/2021-05-24/2222494-02.png)

```cpp
#include <M5StickC.h>
#include "BluetoothSerial.h"
BluetoothSerial SerialBT;
void setup() {
  SerialBT.begin("MyM5StickC");
}
void loop() {
  if (SerialBT.available()) {
    SerialBT.println("This is MyM5StickC.");
    SerialBT.write(SerialBT.read());
  }
  delay(20);
}
```

　M5StickCにスケッチを書き込んでmacOSとペアリングする。ちゃんとデバイスが見えているので、接続ボタンで接続する。

![](/2021-05-24/2222494-03.png)

![](/2021-05-24/2222494-04.png)

　シリアルデバイスを確認すると、"tty.MyM5StickC-ESP32SPP"として見えているのがわかる。

```text
% ls -l /dev/tty.*
crw-rw-rw-  1 root  wheel    9,   4  4 12 00:00 /dev/tty.Bluetooth-Incoming-Port
crw-rw-rw-  1 root  wheel    9,  10  5 11 20:33 /dev/tty.MyM5StickC-ESP32SPP
crw-rw-rw-  1 root  wheel    9,   0  4 11 23:59 /dev/tty.debug-console
crw-rw-rw-  1 root  wheel    9,   8  5 11 20:32 /dev/tty.usbserial-9552E83892
crw-rw-rw-  1 root  wheel    9,   2  4 11 23:59 /dev/tty.wlan-debug
```

　cuコマンドでシリアル通信してみる。screenではなく、まだcuコマンド使うとか、古い人間なのですまぬな。

　cuコマンドでデバイスを指定する"l"はLineの略。エラーになった。デバイスのパーミッションかな？

```text
% cu -l /dev/tty.MyM5StickC-ESP32SPP
cu: creat during lock (/var/spool/uucp/TMP0000012309 in /Users/kinneko as uid 501): Permission denied
cu: /dev/tty.MyM5StickC-ESP32SPP: Line in use
```

　sudoで実行。通信できた。

　リターンだけだと"This is MyM5StickC."が返る。abcdeと打ち込んでいくとエコーバックされる。

```text
% sudo cu -l /dev/tty.MyM5StickC-ESP32SPP
Password:
Connected.
This is MyM5StickC.
aThis is MyM5StickC.
bThis is MyM5StickC.
cThis is MyM5StickC.
dThis is MyM5StickC.
e
```

　通信はできたので、シリアルのスケッチにSPPのコードを組み込んで、BTSPPで通信するスケッチにして書き込む。

![](/2021-05-24/2222494-05.png)

　再度Bluetoothデバイスとしてペアリングしなおして、シリアル通信してみる。"100,100,100,100"を送って動作するか確認する。

```text
% sudo cu -l /dev/tty.MyM5StickC-ESP32SPP
Password:
Connected.
100,100,100,100
100:100
100:80
100:100
100:80
```

　なんかすんなり動いてしまって、つまらないな... さすがESP32で、このへんのライブラリはこなれているということなんだけどね。

![](/2021-05-24/2222494-06.png)
