　Windows環境は手元にないので、EasyLoaderは使えないようだ。ArduinoIDEを使って書き込みする必要がありそう。

　最近、M1 MBP13に環境を移行したので、ArduioIDEにはM5Stack関係のライブラリはインストールされていない。ただ、ESP32の環境は導入済みだ。

> M1環境でArduino IDEを入れてみる -2- (ESP32)<br>
> <https://kinneko.fanbox.cc/posts/2079055>

　ArduinoIDEのライブラリマネージャから、M5StickC用のライブラリを追加する。ライブラリマネージャからm5stikcで検索すると表示されるので、インストールボタンを押してインストールする。

![](/2021-05-19/2217994-03.png)

　インストールが終わると、INSTALLEDと表示される。終わったら、閉じるボタンで閉じる。

![](/2021-05-19/2217994-04.png)

　サンプルコードは、すごい深いところにある。

![](/2021-05-19/2217994-05.png)

　開いてみる。内容はこんな感じ。

![](/2021-05-19/2217994-06.png)

```cpp
#include <M5StickC.h>
#include "puppy.h"
void puppy_start()
{
angle_all_set(90,90,90,90);	//servo 1 2 3 4 => set 90°
delay(100);
}
void puppy_go()
{
angle_all_set(55,60,130,120);	 delay(100);
angle_all_set(55,160,130,120); delay(100);
angle_all_set(120,130,150,60); delay(100);
angle_all_set(120,130,60,60); delay(100);
angle_all_set(55,130,60,60); delay(100);
angle_all_set(55,60,130,30); delay(100);
}
void puppy_back()
{
angle_all_set(120,130,60,55); delay(100);
angle_all_set(120,130,160,55); delay(100);
angle_all_set(60,150,130,120); delay(100);
angle_all_set(60,60,130,120); delay(100);
angle_all_set(60,60,130,55); delay(100);
angle_all_set(30,130,60,55); delay(100);
}
// the setup routine runs once when M5StickC starts up
void setup(){
// Initialize the M5StickC object
M5.begin();
// LCD display
M5.Lcd.println(" ");
M5.Lcd.println("  IIC_PUPPY");
IIC_Init();     //sda  0     scl  26
/*
1              2
3              4
*/
angle_set(1,90);		//servo 1	=>	set	90°
angle_set(2,90);
angle_set(3,90);
angle_set(4,90);
delay(1000);
}
// the loop routine runs over and over again forever
/*
1              2
3              4
*/
uint8_t cnt=10;
void loop() {
while(cnt!=0)
{
cnt--;
puppy_go();
}
cnt=10;
puppy_start();
while(cnt!=0)
{
cnt--;
puppy_back();
}
cnt=10;
puppy_start();
}
```

　基本的には、puppy.cppとpuppy.hで定義されているサーボ制御機能として、I2Cのピンを指定して、angle_all_set([SV1],[SV2],[SV3],[SV4])で角度を指定する感じ。個別には、angle_set([SVNo],[角度])で制御できる。

　サンプル内では、puppy_start()で足を90度にして、puppy_go()で前進のモーション、puppy_back()で後退のモーションが定義されている。起動時に液晶にIIC_PUPPYと表示して、I2Cを初期化し、足を90度に揃えている。最後のにpuppy_start()を使っていないのはどうしてだろう？サンプルだから制御方法例を書いてくれてあるのかな？

　動作用のループでは、カウンタを10セットして、前進と後退のモーションを繰り返すようになっている。

　M5StickCを接続し、ボードの設定をM5StickCにして、シリアルポートを合わせる。

　書き込みが終わると、すぐに動き出した。ほんとに虫みたいだな... ロボ感がまったくないよ。

<https://www.youtube.com/watch?v=F3n4KEhn7Mg>

　ちょっとせわしないので、関数内をdelay(500)にしてみたら、足が１つづつ動く感じで同じ位置で滑って何も移動しないのができあがった。200にしたら、かろうじてゆっくり進む感じ。

　delayを50にすると、だいぶ生き物っぽい感じになった。
