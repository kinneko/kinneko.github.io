　電池脱落の問題は修正したのだけど、会社に持ってくると切れる症状が出る。調子のいいときには、１日普通に動作しているのだけど、調子よかったのに突然ダメになることもあれば、朝一からダメなこともある。

　これって、近所のドングルとの混信ではないですかね？

　なんか、このへんを調整してペアリングをやりなおしてくれるSetPointツールがあるらしいので、使ってみる。

> ダウンロード - ワイヤレス マウス M325<br>
> <https://support.logi.com/hc/ja/articles/360024704274>

![](/2021-07-15/2373649-01.png)

　macOS版はこんな感じ。M1対応かどうかは書かれていないけど、４月なら対応できているよね...

````text
Software Version: 2.5.108413
Last Update: 2021-04-15
OS: macOS 10.15, macOS 10.14, macOS 11, macOS 10.13
File Size: 19 MB
Software Type: 64 bit
````

![](/2021-07-15/2373649-02.png)

　起動すると、シンプルな画面だ。

![](/2021-07-15/2373649-03.png)

　デバイスを探している。

![](/2021-07-15/2373649-04.png)

　なんか見つからないみたいだな。ドングルを差し込み直したりしてみる。

![](/2021-07-15/2373649-05.png)

　認識したので、アップデートする。

![](/2021-07-15/2373649-06.png)

　アップデートははじまったのだけど、なかなか進まない。

![](/2021-07-15/2373649-07.png)

　エラーになった。わかりやすいエラー画面だ。びっくりするけど。

![](/2021-07-15/2373649-08.png)

　リトライしてもダメだったみたい。

![](/2021-07-15/2373649-09.png)

　続けても、見つからない。

![](/2021-07-15/2373649-10.png)

　再度やってみる。何回か認識せずに失敗した後に、アップデートが進んだ。

![](/2021-07-15/2373649-11.png)

　成功したみたい。

![](/2021-07-15/2373649-12.png)

　しかし、なんかマウスもドングルも認識しませんが...

　やってしまった？

　死んでしまった？
