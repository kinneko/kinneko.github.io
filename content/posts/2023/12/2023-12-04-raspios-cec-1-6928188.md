　HDMIのついたTVをCECで切り替え制御したくて、ちょっとテストしてみることにした。

　CECは前職のときにも、結構めんどくさくて、メーカーによって実装の度合いがいろいろで、結構苦労したけど、入力の切り替えくらいベーシックな機能なら大丈夫ではないかと思ったのだけど...

　Pi3にRaspiOS bookwormを入れた状態でテスト。

　遠い昔の記憶では、CECまわりって、確かライブラリとユーティリティがあったような。

　パッケージをCECで検索してみる。

~~~text
kinneko@raspberrypi:~ $ apt-cache search cec-
cec-utils - USB CEC Adaptor communication Library (utility programs)
golang-github-btcsuite-btcd-btcec-dev - Go library for Elliptic curve cryptography
libcec-dev - USB CEC Adaptor communication Library (development files)
libcec-platform-dev - CEC Platform support library -- development files
libcec-platform1v5 - CEC Platform support library
cec-utils-dbgsym - debug symbols for cec-utils
python3-cec-dbgsym - debug symbols for python3-cec
~~~

　とりあえず、cec-utilsを入れると必要なものは依存関係でインストールされそうね。なんか、python3からも使えそうなライブラリある。

　cec-utilsをインストールする。

kinneko@raspberrypi:~ $ sudo apt-get install cec-utils

　基本的にはlibcec6とcec-utilsという感じか。シンプルでよい。

　パッケージ名のcec-clientがコマンド名そのものか。それ以外には入っていない。シンプルだ。

　実行には、root権限必要だったりするんだろうか？

　bookwormでは、実行ユーザーがvideoグループに入っているから問題ないかな？

　何も接続していないけれど、とりあえず--list-devicesしてみる。

~~~text
haudi@sign:~ $ cec-client --list-devices
libCEC version: 6.0.2, compiled on Linux ... , features: P8_USB, DRM, P8_detect, randr, RPi, Exynos, Linux, AOCEC
Found devices: 1

device:              1
com port:            /dev/cec0
vendor id:           0000
product id:          0000
firmware version:    0
type:                Linux
~~~

　libcec6のバージョンは6.0.2。

　Raspiは、/dev/cec0ってデバイスが生えているのね。生えているデバイスはそれ１つだけ。Pi4/5だと2つになるんだろうか？

　Exynosと書かれているのが気になる。SamsungのSoCの開発コードと同じ？ RaspiのSoCは、GPU側から派生した設計になっていると聞いたのだけど、それと関係ある？

　vidもpidも0000だな... fwversionもからっぽ。

　/dev/cec0を見てみる。所有者はrootだけど、グループはvideoに設定されている。videoグループであれば触れる感じ。

~~~text
kinneko@raspberrypi:~ $ ls -al  /dev/cec0
crw-rw---- 1 root video 240, 0 Nov  6 16:27 /dev/cec0
~~~

　さて、うちにTVはないんだけど、テスト用にだいぶ古いTOSHIBAのTVを借りられることになった。古いと、CECはたいへんなんだけど、最近のCEC実装の具合はさらに知らないので大差ないか。
