　さて、インタプリンタが実行されている環境にはたどりついたのだけど、これをインタラクティブに使うのは、ちょっと面倒だ。

　なんで唐突にMicroPythonをはじめたかというと、Arduinoのスケッチで開発していると、ライブラリがLGPLなので、書かれたソースコードをビルドするとスタティックにリンクされてしまい、スケッチそのものはGPLライセンスということになってしまう。市場に出す製品に入れるわけにはいかない。

　かといって、ESP-IDFを使って直接開発を行うのは、保守性を含めてややハードルが高い感じ。誰にでもはオススメできない。

　MicroPythonはMITライセンスなので、Arduinoスケッチで発生するようなライセンスの制約がない。また、インタプリンタ言語であるので、引き継ぎが比較的楽だ。

　個人的にはプロジェクトのソースコードを全部出してしまってもいいと思うのだけれど、利害関係者が複数いる場合は説得そのものが面倒なことになってしまう。

　MicroPythonの情報は、Raspberry Pi PicoやRaspberry Pi Pico Wを使ったものは多いのだけど、ESP32についての日本語の情報はあまりない。あっても古い内容になっている。

　とりあえず、最新版のv1.21とかを焼いたわけだけど、本家では今年から2.0の開発がスタートしているらしい。しかし、その実態はまだなにもないので、気にしなくてよさそうだ。

　普通のPythonでは、パッケージマネージャとしてpipなどを使うのだけど、MicroPythonではupipや最近導入されたmipを使うようだ。パッケージマネージャが動くのはありたがい。

　また、最近のESP関係の更新では、ESP-NOWがサポートされたそうだ。ESP-NOWはWiFiのMAC層で通信する、独自プロトコル。大量に通信すると詰まるようだけど、軽くて便利だ。

　MicroPythonは、M5Stick Vのときに少しさわっていて、そこではboot.pyで起動して、main.pyにコードを保存していた。どうやってファイルを転送していたかは、すっかり忘れている。その時の感想としては、なんだか制約も多くてすぐに使わなくなってしまった。あ、思い出した！ M5Stick VはmicroSDカードが付いているので、そこにファイルを書けば実行してくれたのだった。

　今回のターゲットにはSDカードリーダーは付けていないハダカのESP32なので、ファイルをコピーする方法がないな...

　MicroPythonのクイックリファレンスは、ボードごとに日本語訳されたものが公開されている。まずはこれを読むか。

> ESP32 用クイックリファレンス — MicroPython latest ドキュメント<br>
> <https://micropython-docs-ja.readthedocs.io/ja/latest/esp32/quickref.html>

　ざっと読んでみると、開発についてはWebREPLというブラウザ経由で利用するツールを使うか、mpremoteコマンドを使う感じのようだ。なんだか不便だな。

> micropython/webrepl: WebREPL client and related tools for MicroPython<br>
> <https://github.com/micropython/webrepl>

![](/2023-12-20/7139691-01.png)

　WebREPLはローカルにインストールして使うこともできるが、オンラインでホストされているものも使うことができる。リンクを踏んでみたけれど、どうも最近のブラウザ環境にはフィットしていないようで、httpでアクセスする必要があるのだけど、httpsにリダイレクトされてしまい使うことはできないようだ。一度HSTSが有効になってしまうと、これを回避する手段はなさそう...

> MicroPython WebREPL<br>
> <https://micropython.org/webrepl/>

　さて、ターゲットデバイスでWebREPLを使うには、ターゲットデバイスをAPにして、そこにアクセスできないといけないようだ。うーむ。これはちょっとハードル高いな...

　WiFiなどにアクセスできるようにしてあれば使えるようだが、初期設定を実行するには、シリアルコンソール経由でREPLを利用する必要がある。ううう、めんどくさい...

　みなさん、こんなめんどくさいことしているの？？？

　ArduinoIDEが起動していると、minicomでシリアルを開くことができなかった。当たり前か。

　minicom: cannot open /dev/tty.usbserial-0001: Resource busy

　ArduinoIDEを終了してminicomからシリアル接続する。

![](/2023-12-20/7139691-05.png)

　MicroPythonを書き込んだ時点で、ターゲットはすでにAPモードで動作しているようだ。スキャンすると、ESP_085409というそれっぽいのが見える。デフォルトのパスワードはドキュメントには"micropythoN"だと書かれているけれど、パスワードの設定はされていないようだ。選択するだけでつながった。

　接続してみると、192.168.4.2のアドレスが割り振られる。ターゲットは192.168.4.1になっている。

　このまま使うのは面倒なので、既存のWiFi APに接続させる。APモードで動作しているのを確認してみたけれど、このモードはMicroPythonとは無関係に低レイヤーで動作しているようだ。

~~~text
>>> import network
>>> ap_if.active()
>>> ap_if = network.WLAN(network.AP_IF)
>>> ap_if.active()
False
~~~

~~~text
>>> sta_if = network.WLAN(network.STA_IF)
>>> sta_if.active()
False
~~~

　ネットワークインターフェイスを有効にして、接続先のAPの設定を流し込み、接続して状態を確認する。

~~~text
>>> sta_if.active(True)
True
>>> sta_if.connect('MyPlace', 'XXXXXXXXXXX')
>>> sta_if.isconnected()
True
>>> sta_if.ifconfig()
('192.168.0.13', '255.255.255.0', '192.168.0.1', '192.168.0.1')
~~~

　ターゲット側で、WebREPLの初期化を行う。

　>>> import webrepl_setup

　WebREPL daemon auto-start status: disabled

~~~text
Would you like to (E)nable or (D)isable it running on boot?
(Empty line to quit)
>
~~~

　有効にするにはEを入力する。続いてパスワードを設定する。

~~~text
Would you like to (E)nable or (D)isable it running on boot?
(Empty line to quit)
> E
To enable WebREPL, you must set password for it
New password (4-9 chars):
~~~

　４−９文字のパスワードの設定と確認、その後再起動される。

~~~text
To enable WebREPL, you must set password for it
New password (4-9 chars): XXXX
Confirm password: XXXX
Changes will be activated after reboot
Would you like to reboot now? (y/n) y
~~~

　再起動したら、無線の設定が消えてしまったよ...

~~~text
>>> import network
>>> sta_if = network.WLAN(network.STA_IF)
>>> sta_if.active()
False
~~~

　再設定する。

~~~text
>>> sta_if.active(True)
True
>>> sta_if.connect('MyPlace', 'XXXXXXXXXXX')
>>> sta_if.isconnected()
True
>>> sta_if.ifconfig()
('192.168.0.13', '255.255.255.0', '192.168.0.1', '192.168.0.1')
~~~

　ターゲットで、webreplを起動する。ポートは8266になった。

~~~text
>>> import webrepl
>>> webrepl.start()
WebREPL server started on http://192.168.0.13:8266/
Started webrepl in normal mode
~~~

　ブラウザで開いたWebREPLに、指示されたURLを渡す。通信にはwebsocketを使うので、リクエストはws://を使う。Connectボタンを押すと接続された。パスワードが求められるので、先ほど設定したものを入力するとプロンプトが表示された。
