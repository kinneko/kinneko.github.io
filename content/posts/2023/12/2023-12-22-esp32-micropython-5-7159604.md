　シリアル接続したコンソールには、エラーが出ていた。

~~~text
WebREPL connection from: ('192.168.0.2', 49737)
dupterm: Exception in read() method, deactivating: OSError: [Errno 2] ENOENT
~~~

　以下のmain.pyをブラウザのWebREPLクライアントから流し込んで、ネットワークの設定をして、Lチカを実行させる。

~~~text
import network
import machine
import time
sta_if = network.WLAN(network.STA_IF)
sta_if.active(True)
sta_if.connect('MyPlace', 'XXXXXXXXXXX')
sta_if.isconnected()
sta_if.ifconfig()
~~~

~~~text
led = machine.Pin(2, machine.Pin.OUT)
while True:
    led.value(1)
    time.sleep(1)
    led.value(0)
    time.sleep(1)
~~~

　main.pyを書き込んでも自動でリセットされないのね。不便ではある。手動でリセットする。

~~~text
>>> import machine
>>> machine.reset()
~~~

　再起動したらLチカがはじまったので、main.pyの書き込みと実行は成功しているようだ。

　ブラウザのWebREPLクライアントからも接続ができたので、ネットワークの設定も行われているのが確認できた。

　先程書き込んだmain.pyがあるので、ブラウザのWebREPLクライアントからmain.pyをダウンロードしてみる。こんどは接続が切れたりせずに、main.pyがダウンロードされた。

　主な情報源として、本家のドキュメントを見てやってきたけど、なんか、ちょっとヒドいよなぁ...

　MicroPythonをよく使うエンジニアが、こんな使いにくい環境に甘んじているはずがない。たぶん、どこかにもっといい方法があるはずだよね...
