　/home/pi/binに環境がインストールされたが、~/binにはパスが通っていない。

```text
pi@pi:~ $ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/local/games:/usr/games
```

　とりあえず、PATH通す。

```text
pi@pi:~ $ export PATH=$PATH:~/bin
pi@pi:~ $ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/local/games:/usr/games:/home/pi/bin
pi@pi:~ $ which arduino-cli
/home/pi/bin/arduino-cli
```

　毎回PATH通すの面倒で、次回使うとき忘れていると思うので、シェル設定に書いておく。

```text
pi@pi:~ $ vi .bashrc
export PATH=$PATH:~/bin
pi@pi:~ $ source .bashrc
pi@pi:~ $ which arduino-cli
/home/pi/bin/arduino-cli
```

　configを初期化して、arduino-cli.yamlを作る。

```text
pi@pi:~ $ arduino-cli config init
Config file written to: /home/pi/.arduino15/arduino-cli.yaml
```

　arduino-cli.yamlにDigisparkのボード情報を追記する。

```text
pi@pi:~ $ arduino-cli config add board_manager.additional_urls https://raw.githubusercontent.com/ArminJo/DigistumpArduino/master/package_digistump_index.json
```

　スリープレスドングルのスケッチを作る。まずはarduino-cliコマンドにスケルトンを作ってもらう。

```text
pi@pi:~ $ arduino-cli sketch new digispark_sleepless
Sketch created in: /home/pi/digispark_sleepless
```

　できたスケルトンのinoファイルを書き換える。こんな感じだっけかな。

```text
pi@pi:~ $ vi digispark_sleepless/digispark_sleepless.ino
#include "DigiMouse.h"
void setup() {
  pinMode(1, OUTPUT);
  DigiMouse.begin();
}
void loop() {
  DigiMouse.update(); // DigiMouse.update() at least every 50ms
  DigiMouse.moveY(-1); //mouse Y up 1
  digitalWrite(1, HIGH);
  DigiMouse.delay(100); // wait 0.1sec
  DigiMouse.moveY(1); //mouse Y down 1
  digitalWrite(1, LOW);
  DigiMouse.delay(29900); // wait total 30sec
}
```

　49-micronucleus.rulesの中身はこれだけ。

```text
SUBSYSTEMS=="usb", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666"
KERNEL=="ttyACM*", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666", ENV{ID_MM_DEVICE_IGNORE}="1"
```

　VIDとPIDの組み合わせが16d0:0753のデバイスがホットプラグされたらusbとttyACMのパーミッションを変えているだけ。この環境で使うのは/dev/ttyAMA0なので、関係ないのでは？ そっちは、さっきデフォルトを手動で書き換えたので、まぁ、いいか。

　VIDとPIDの組み合わせはDigiSparkなので合っている。

> USB\VID_16D0&PID_0753 - Digistump DigiSpark | Device Hunt<br>
> <https://devicehunt.com/view/type/usb/vendor/16D0/device/0753>

　ブートローダーが1.6とやや古いが、まぁいいか。高速起動かつメモリ節約版ではないけど、普通には動く。またnucreus潰しても嫌だしね。

　あとは、ビルド時に毎回warningを見るのも気持ち悪い感じ。warningが出る２つはこれ。

```text
warning: invalid conversion from 'const unsigned char*' to 'unsigned char*' [-fpermissive]
usbMsgPtr = rt_usbDeviceDescriptor;
usbMsgPtr = rt_usbHidReportDescriptor;
```

　代入されたものは、こんな定義がされている。

```text
static const uchar *rt_usbDeviceDescriptor = NULL;
static const uchar *rt_usbHidReportDescriptor = NULL;
```

　const ucharをucharにキャストした問題なのだけど、warning止まりで特に実害はない感じだ。

　とりあえず、こうしてキャスト時にconstを無効にすると解決するのかな？

```text
usbMsgPtr = const_cast<uchar*>rt_usbDeviceDescriptor;
usbMsgPtr = const_cast<uchar*>rt_usbHidReportDescriptor;
```

　変更すると、ビルド時にwarningは出なくなった。

　あとは、clockを毎回入れるのはめんどくさいので入れておく。書き込んでおくsketch.jsonを作る。

```text
pi@pi:~ $ arduino-cli board attach -b digistump:avr:digispark-tiny:clock=clock165 digispark_sleepless
Selected fqbn: digistump:avr:digispark-tiny:clock=clock165
pi@pi:~ $ cat digispark_sleepless/sketch.json
{
  "cpu": {
    "fqbn": "digistump:avr:digispark-tiny:clock=clock165"
  }
```
