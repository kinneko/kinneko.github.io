　さて、AWS IoT Coreでthingを作成して、MQTTの疎通試験はできた。次は外部からのフルスペックの疎通確認をしてみる。

　macOSで使えるツールを調べてみると、MQTT Xがよさげ。dmgでの提供もあるので、AppStoreいらずでよい。

> MQTT X: Cross-platform MQTT 5.0 Desktop Client<br>
> <https://mqttx.app/>

![](/2023-02-07/5159888-01.png)

![](/2023-02-07/5159888-02.png)

　MQTT Xは、EMQXというOSSのMQTTブローカーを開発するMQXがOSSで開発している。元の会社名は、「Hangzhou Yingyun Technology Co., Ltd」なので中国系かな？ MQTT

> EMQX: The World's #1 Open Source Distributed MQTT Broker<br>
> <https://www.emqx.io/>

![](/2023-02-07/5159888-03.png)

　MQTT Xは、Electronベースで作られている。GitHubはここ。日本語メニューにも対応している。

> GitHub - emqx/MQTTX: Powerful cross-platform MQTT 5.0 Desktop, CLI, and WebSocket client tools<br>
> <https://github.com/emqx/MQTTX>

　EMQの会社案内はこんなところにあった。

> About Us | EMQ<br>
> <https://www.emqx.com/en/about>

　ダウンロードして起動してみる。Electronなので、Appにインストールしなくても起動できるでしょ。

![](/2023-02-07/5159888-04.png)

　起動はできた。

![](/2023-02-07/5159888-05.png)

　Settingsを開いて日本語に設定する。

![](/2023-02-07/5159888-06.png)

![](/2023-02-07/5159888-07.png)

![](/2023-02-07/5159888-08.png)

　日本語になった。メニューの＋マークか、画面の「＋新しい接続」で接続先の設定ができるようだ。アイコンにはtoolchipは設定されていないので、直感で意味がわからないアイコンを押すのは怖い。

![](/2023-02-07/5159888-09.png)

　＋を押すと、「新規」画面になった。

![](/2023-02-07/5159888-10.png)

　AWS IoTに接続するための情報を登録する。

![](/2023-02-07/5159888-11.png)

　ホストに入力するエンドポイントは、AWS IoT Coreの設定から確認できる。

![](/2023-02-07/5159888-12.png)

　証明書情報は、Self Singnedを選ぶと選択できるようになる。

　詳細では、MQTTの詳細設定ができる。一部表示が重なっておかしいところがある。

![](/2023-02-07/5159888-13.png)

　他に設定が必要な場合は、独自のユーザープロパティを設定できる。

![](/2023-02-07/5159888-14.png)

　遺言は妙な訳だなw トピックやペイロードを指定できる。

![](/2023-02-07/5159888-15.png)

　とりあえず、こんな感じかな。

![](/2023-02-07/5159888-16.png)

　右上にある接続リンクを押す。接続できなかったわ...

![](/2023-02-07/5159888-17.png)

　AWS IoT Coreのモニタリング画面のダッシュボードでも、接続に来ていないのがわかる。

　なんか設定間違っているか... とはいっても、そう設定する必要のある内容がないのだけど。

![](/2023-02-07/5159888-18.png)

　４つ並びのアイコンの一番下がログ表示のようだ。コネクションへの応答がない感じ。

![](/2023-02-07/5159888-19.png)

```text
[2023-01-24 14:13:18] [INFO] MQTTX client with ID be205928-0e94-4aff-ad66-bceecbce7427 assigned
[2023-01-24 14:13:18] [INFO] Connect client AWS IoT, MQTT/SSL connection: mqtts://xxxxxxxxxxxxx-ats.iot.ap-northeast-1.amazonaws.com:8883 with Properties: {"sessionExpiryInterval":0,"receiveMaximum":null,"maximumPacketSize":null,"topicAliasMaximum":null,"requestResponseInformation":false,"requestProblemInformation":false,"userProperties":{},"authenticationMethod":null}
[2023-01-24 14:13:28] [INFO] AWS IoT connect close, MQTT.js onClose trigger
```

　レスポンス情報をリクエストするスイッチをオンにしてみる。特に応答に変化はない。あかーん。

　クライアント名にthing名でない、デフォルトの値を入れたら普通に接続できたじゃん...

　そういえば、AWS IoTはクライアント認証しているから、IDとか関係ないんだった。ここに入れるのは接続に行くクライアントアプリの名前を入れるだけみたいなイメージでいい。さっきエラーになったのは長すぎる名前だったのかな？

![](/2023-02-07/5159888-20.png)

　モニタリング画面でも接続してきたのを確認できる。

![](/2023-02-07/5159888-21.png)

　失敗したやつは削除する。

![](/2023-02-07/5159888-22.png)

![](/2023-02-07/5159888-23.png)
