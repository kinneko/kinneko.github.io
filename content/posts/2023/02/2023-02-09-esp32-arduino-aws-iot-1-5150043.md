　ちょっとした作り物で、AWS IoTと通信する必要が出てきた。前の記事にて、AWS IoT Coreでthingを作成するのは終わっている。

> AWS IoT Coreを久しぶりにGUIからさわってみる -1-<br>
> <https://kinneko.fanbox.cc/posts/5141618>

> AWS IoT Coreを久しぶりにGUIからさわってみる -2-<br>
> <https://kinneko.fanbox.cc/posts/5159433>

　ESP32にボタンをつけて、ボタンを押したら押された情報がAWS IoTに飛ぶようにしてみる。それだけだと状態がわからないので、シリアルに状態を出力する。

　Arduinoでは、MQTTSを実行するのに、どんなライブラリが用意されているのだろう？

　まずはライブラリマネージャでAWS IoTと検索してみる。２つ出てきた。

![](/2023-02-09/5150043-01.png)

　aws-sdk-arduino-esp8266は、Experimentalって書いてあるのは、ちょっと嫌だな。メンテもされていない感じ。ヘッダファイル名は、AmazonIOTClient.hとか書かれている。

> GitHub - Schm1tz1/aws-sdk-arduino-esp8266: An experimental SDK for working with AWS Services on Arduino-compatible devices. Currently has support for DynamoDB and Kinesis.<br>
> <https://github.com/Schm1tz1/aws-sdk-arduino-esp8266>

　simpleiot-arduinoも大差ない。メンテされてなさげ。

> GitHub - awslabs/simpleiot-arduino: Arduino SDK for SimpleIOT project.<br>
> <https://github.com/awslabs/simpleiot-arduino>

　MQTTSで再検索。２つ出てきた。

![](/2023-02-09/5150043-02.png)

　AsyncMQTT_ESP32は、最近までメンテナンスされている。いいかもしれない。非同期通信なのは面白いのだけど、メモリを余計に食いそうな感じだ。

> GitHub - khoih-prog/AsyncMQTT_ESP32: Arduino Library for ESP32/S2/S3/C3 asynchronous MQTT client implementation. This library, ported to support ESP32/S2/S3/C3, WT32_ETH01 (ESP32 + LAN8720), ESP32 using LwIP ENC28J60, W5500, W6100 or LAN8720. Supporting TLS/SSL for MQTTS Client<br>
> <https://github.com/khoih-prog/AsyncMQTT_ESP32>

　MQTT and Serial Printerは、名前からしても、用途が違う感じ。パスする。

　ライブラリをMQTTで検索する。ぞろぞろ出てくる...

　EspMQTTClientは保守されているようだ。でも、MQTTSには対応していない感じだ。残念。

> GitHub - plapointe6/EspMQTTClient: Wifi and MQTT handling for ESP8266 and ESP32<br>
> <https://github.com/plapointe6/EspMQTTClient>

　LTEモジュールに対応したものもあるな。最近はBG96になってるのだけど、対応しているのかな？ ちょっとよくわからない。

> GitHub - zimbora/esp32-BG95: package to communicate with BG95 modem<br>
> <https://github.com/zimbora/esp32-BG95>

　ぞろぞろ出てきた中で、わりとよく使われているのはPubSubClientのような感じ。「Latest version: 2.8 - released 2020-05-20」なので、あまりメンテナンスはされていないか...

> Arduino Client for MQTT<br>
> <https://pubsubclient.knolleary.net/>
> <https://github.com/knolleary/pubsubclient>

![](/2023-02-09/5150043-03.png)

　AWS IoTの接続実績もあるので、無難な選択で、これにしておくか... 入れる。

![](/2023-02-09/5150043-04.png)

　PubSubClientのサンプルスケッチは、７つ登録された。

![](/2023-02-09/5150043-05.png)

　mqtt_basicはNIC付きの状態で通信するもの。

　WiFi環境のは、mqtt_esp8266なのだろうけど、これはMQTTSではない。なんか、スケッチ全般に完成はされているんだろうけど、わかりにくい感じ。

　PubSubClientを使ったAWS IoT実装は、からあげさんが、ずっと前に解決しているので、参考になる。

> ESP32でAWS IoTに繋いでThing Shadowを弄る – コーヒーサーバは香炉である<br>
> <https://blog.maripo.org/2017/07/esp32-aws-iot/>

　からあげさんの成果を参考に、スケッチを書いてみよう。
