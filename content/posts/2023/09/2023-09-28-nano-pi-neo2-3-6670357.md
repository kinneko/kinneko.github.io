　少し間があいてしまったけれど、とりあえずArmbian入れるあたりからやっていくかな。

　Armbianのインストールイメージは、CLIとMINIMALの２種類がある。Nano Pi NEO2にはディスプレイは付かないので、RaspiOSのようにGUIの選択肢はない。

> Nanopi Neo 2 – Armbian<br>
> <https://www.armbian.com/nanopi-neo-2/>

![](/2023-09-28/6670357-03.png)

　バージョンは、Armbian 23.8 Bookwormとある。Bookwormは、Debian 12のコードネームなので、その派生ということなのだろう。Armbianのリビジョン的なものは独自につけられているようだ。ハードウエアによっては、Ubuntuからの派生もあるそうだ。そちらはGUIがあるものかな。

　CLIとMINIMALの内容はこんな感じ。それぞれのイメージのSHAハッシュと、PGPシグネチャをみることができる。

```text
CLI: Kernel 6.1, Size: 424Mb, Release date: Aug 31, 2023
```

```text
MINIMAL: Kernel 6.1, Size: 265Mb, Release date: Aug 31, 2023
```

　ダウンロード方法は、Direct downloadと、Torrent downloadがある。まだTorenntって生きているのだなぁ。もちろんDirectからイメージをダウンロードする。とりあえず、MINIMALでいいかな。

　ダウンロードはここからになる。

<https://www.armbian.com/nanopi-neo-2/>

<https://mirrors.tuna.tsinghua.edu.cn/armbian-releases/nanopineo2/archive/Armbian_23.8.1_Nanopineo2_bookworm_current_6.1.47_minimal.img.xz>

　えらく長いxzアーカイブのイメージがダウンロードされた。

```text
Armbian_23.8.1_Nanopineo2_bookworm_current_6.1.47_minimal.img.xz
```

　イメージをSDに展開するのは、Raspi Imagerが楽だ。メニューから「カスタムイメージを使う」を選んで、ダウンロードしたイメージを指定する。

![](/2023-09-28/6670357-04.png)

　ストレージを指定して書き込む。

![](/2023-09-28/6670357-05.png)

　イメージサイズが小さいので、書き込みも確認もすぐに終わる。

![](/2023-09-28/6670357-06.png)

![](/2023-09-28/6670357-07.png)

![](/2023-09-28/6670357-08.png)

　作成したSDカードをNano Pi NEO2に差し込む。

![](/2023-09-28/6670357-09.png)

　Raspi用のUSBシリアルがまだ見当たらないので、設定はEthernetから行うので有線LANに接続する必要がある。なんか、それも面倒だ。

　こんなものが見つかった。

![](/2023-09-28/6670357-10.png)

　mini-BショートケーブルにType-A to Cの変換を噛ませて、MBPに差し込むと認識したので使えそう。TTL基板は3.3V仕様だったので、RX/TX/GNDだけを配線する。給電はUSB側から行う。

![](/2023-09-28/6670357-11.png)

　電源は、Pi3B用の3A品を接続する。電源を入れると、グリーンのLEDが点灯する。起動するとブルーのLEDが点滅している。

　MBP側でminicomを起動してみて、NEO2に電源入れてみたけど、シリアル側には反応がない。別のTTLコンバーターが見つかったので、それを試しても結果同じ。シリアルにコンソールが来ていないのかもしれない。

　しかたがないので、sshで入って作業する。昔、DebianのインストーラーをSH4やARM対応をするのに、GUIのないデバイスではどうしようとかMLで話していたのを思い出して懐かしい。

　インストーラーのユーザーはroot。パスワードは1234。

　スキャンするのもめんどくさいので、当てずっぽうでアクセスしてゆく。

　いた。

![](/2023-09-28/6670357-12.png)

```text
Welcome to ARMBIAN!
Documentation: https://docs.armbian.com | Community: https://forum.armbian.com
IP address: 192.168.0.13
Create root password:
```

　新しいパスワードを入れろと言われる。入れる。確認もある。

![](/2023-09-28/6670357-13.png)

```text
Support status: community support (looking for a dedicated maintainer)
Shell: BASH
Creating a new user account. Press <Ctrl-C> to abort
Please provide a username (eg. your first name):
```

　Support statusとかあるのか。有償サポートでも選べるのかな？

　shellはbashか、Debian系なのにdashじゃないのは謎。メンテナの趣味かな？

　ユーザーを作るので名前を入れろと言われる。パスワードも設定する。

![](/2023-09-28/6670357-14.png)

```text
Please provide your real name: kinneko
```

```text
Dear kinneko, your account kinneko has been created and is sudo enabled.
Please use this account for your daily work from now on.
```

```text
Detected timezone: Asia/Tokyo
```

```text
Set user language based on your location? [Y/n]
```

　sudoできるユーザーを登録して、タイムゾーンはおそらくIPアドレスから推定されたのだろう。

　locationとあるのは何かと思ったらlocale設定だった。これには、少し時間がかかる。

![](/2023-09-28/6670357-15.png)

```text
Generating locales: ja_JP.UTF-8
root@nanopineo2:~#
```

　インストール終わった。

　インストールパッケージ数は327。案外多い感じ。最近のシステムだと依存関係がタイトで150くらいに抑えるのは難しいのかな。

```text
root@nanopineo2:~# dpkg -l | wc
332    3267   41879
```

　パッケージDBの更新と、アップデートをやっておく。
