　ROMシステムを用意する必要が出てきたので、ちょっとOpenWRTを再履修しておく。前に、テスト用のルーターとかゲイトウエイなどを整備したときには、まだRaspiの公式サポートがなくて手間がかかったけど、いまはもうサポートされている。

　本家のRaspi対応情報はこちら。

> [OpenWrt Wiki] Raspberry Pi<br>
> <https://openwrt.org/toh/raspberry_pi_foundation/raspberry_pi>

![](/2023-08-29/6587378-01.png)

　言語設定を日本語にしてみても、翻訳は存在しないと表示される。こういうところに、日本のRaspi界隈とかOpenWRT界隈の敗北を感じるね。

![](/2023-08-29/6587378-02.png)

　ターゲットには、そのへんに転がっていたPiっぽいやつを使う。中身が簡単にはわからないので分解してボードを確認する。

![](/2023-08-29/6587378-03.png)

　コンパクトでいいのだけれど、背面のネジ四本を外して分解しないとなんのボードだかわからない。ヒートシンクはなし、風穴も片側だけなのでちょっとつらい。ヒートシンクも貼ってない。

![](/2023-08-29/6587378-04.png)

　ターゲットは、Pi3 B V1.2だった。クロック1.2GHz、RAM 1G品かな。OpenWRTにはちょっと贅沢かも。

![](/2023-08-29/6587378-05.png)

　ケースはこんな感じで、一面がメッシュで外れるようになっている。写真とるために外してみたのだけど、あんまり組み立てのことは考えていないみたいで、基板を嵌め込みにくい。

![](/2023-08-29/6587378-06.png)

　SDカードは、だいぶ前に買ってあったのが発掘されたので、それを使う。OpenWRTにはデカすぎるくらい。

![](/2023-08-29/6587378-07.png)

　さて、OpenWRTの起動イメージはターゲットごとに公開されているので、それを焼くと無線ルーターとしては普通に起動してくる。パッケージ管理システムとしてopkgを採用しているので、ROM化されたSquashFSに追記することでパッケージで機能を追加することもできる。

　また、ターゲットごとに別れたImage Builderという仕組みを使って、ビルド済みのバイナリを組み合わせて起動イメージを作ることができる。バイナリの追加や削除はopkg単位で行われる。

> [OpenWrt Wiki] Using the Image Builder<br>
> <https://openwrt.org/docs/guide-user/additional-software/imagebuilder>

![](/2023-08-29/6587378-08.png)

　今回は、ROM化する必要のある組み込みのベースシステムとして使いたいので、少し手間と時間がかかるが、自前でビルドしてゆくことにする。他に追加する必要のあるハードウエアもあるので、こういう構成を選択することにした。

　OpenWRTでは、toolchainやビルドシステムは、独自のものを使う。ソースコードも、独自の配布になっている。

> Index of /<br>
> <https://sources.openwrt.org/>

　ビルドを行うシステムとしては、64bitのLinux環境が推奨されている。他に手がないでもないけれど、ここは素直に従ってゆくのがいいだろう。

　M1 macOS上にUTMでUbuntu環境を作成して、ビルドを行うことにする。

　UbuntuのOpenWRTビルドの推奨環境は、現在は22.04になっている。アーキテクチャはIA64を使うのが無難だが、今回は、ネイティブのarm64環境で試してみることにする。

　UTMを起動する。前に作ったイメージはあるが、今回は新規に作成する。

![](/2023-08-29/6587378-09.png)

　ネイティブを使用するので、仮想化を選択する。

![](/2023-08-29/6587378-10.png)

　OSはLinuxを使う。

![](/2023-08-29/6587378-11.png)

　Linuxの設定。Appleの仮想化は使用せず、QEMUを使用する。Ubuntuのインストール用のISOイメージを選択する。

![](/2023-08-29/6587378-12.png)

　と、思ったら、Ubuntuのarm64のISOイメージが見当たらない。ダウンロードしてくる。

> Ubuntuを入手する | Ubuntu | Ubuntu<br>
> <https://jp.ubuntu.com/download>

![](/2023-08-29/6587378-13.png)

　今回はGUIは不要なので、Ubuntu Server 22.04.3 LTSをダウンロードする。そのままダウンロードボタンを押すと、amd64がダウンロードされてしまうので、右側にあるUbuntu Server for ARMをクリックする。

![](/2023-08-29/6587378-14.png)

　Ubuntu Server for ARMのページが開く。

> Ubuntu for ARM | Download | Ubuntu<br>
> <https://ubuntu.com/download/server/arm>

![](/2023-08-29/6587378-15.png)

　下のほうに、ダウンロードボタンがあるので押す。

![](/2023-08-29/6587378-16.png)

https://cdimage.ubuntu.com/releases/22.04/release/ubuntu-22.04.3-live-server-arm64.iso

　ubuntu-22.04.3-live-server-arm64.isoがダウンロードされた。

　切りがイマイチだけど、続く。
