　イベントに参加したらもらえたStampS3なのだけど、イマイチ使う用途を思いつかない。なので、長いこと放置していた。第二回は、スケッチを書き込んでみる。でも、そんだけで終わりそうw

　Arduino IDEでSTAMP-S3でボードとしては認識して、シリアルポートも合わせたので、シリアル通信ができているのは確認できた。

　でも、STAMP-S3用のサンプルスケッチはインストールされていない感じ。ボードマネージャで、最新バージョンがインストールされているか確認してみる。Stampで検索しても何も出てこない。これって、SoCごとだったっけ？

![](/2023-08-03/6435107-02.png)

　ESP32で検索する。Arduino ESP32 Boardsはインストールされていない。これは、Arduino Nano ESP32という純正ボードの設定。今回は関係なさそう。

![](/2023-08-03/6435107-03.png)

　ESP32のほうは、2.0.8はインストールされていたけれど、最新は2.0.11になっている。これを更新する。S3対応は2.0.6からなので、アップデートしなくても動作には問題なさそう。

![](/2023-08-03/6435107-04.png)

　ちょっと時間がかかったが、アップデートされた。

![](/2023-08-03/6435107-05.png)

　サンプルスケッチは出てこない。ライブラリマネジャーを起動する。Stampのライブラリは検索してもなさそうだ。

　インストールされているM5Familyのライブラリが少し古い。アップデートしておく。

![](/2023-08-03/6435107-06.png)

　依存関係の警告が出るので、allを選ぶ。

![](/2023-08-03/6435107-07.png)

　インストール完了。

![](/2023-08-03/6435107-08.png)

　M5Stackのライブラリを入れていなかったな。

![](/2023-08-03/6435107-09.png)

　こちらも依存関係の警告が出るので、allを選ぶ。

![](/2023-08-03/6435107-10.png)

　インストールされた。

![](/2023-08-03/6435107-11.png)

　サンプルスケッチはまだ出てこない。Arduino IDEを再起動してみる。出てこない。

　サンプルスケッチはセットされていないということ？

　フルカラーLEDの制御には、FastLEDを使うので、これも確認しておくか。少し上がっていたので、これもアップデートする。

![](/2023-08-03/6435107-12.png)

![](/2023-08-03/6435107-13.png)

```cpp
/*
*******************************************************************************
* Copyright (c) 2022 by M5Stack
*                  Equipped with StampS3 sample source code
*                          配套  StampS3 示例源代码
* Visit for more information: https://docs.m5stack.com/en/core/stamps3
* 获取更多资料请访问: https://docs.m5stack.com/zh_CN/core/stamps3
*
* Describe: LED Show example.  LED展示示例
* Date: 2023/1/11
*******************************************************************************
Press button to change LED status
按下按键切换LED状态.
*/
#include <Arduino.h>
#include <FastLED.h>
#define PIN_BUTTON 0
#define PIN_LED    21
#define NUM_LEDS   1
CRGB leds[NUM_LEDS];
uint8_t led_ih             = 0;
uint8_t led_status         = 0;
String led_status_string[] = {"Rainbow", "Red", "Green", "Blue"};
/* After StampS3 is started or reset
the program in the setUp () function will be run, and this part will only be
run once.
在StampS3启动或者复位后，即会开始执行setup()函数中的程序，该部分只会执行一次。
*/
void setup() {
USBSerial.begin(115200);
USBSerial.println("StampS3 demo!");
pinMode(PIN_BUTTON, INPUT);
FastLED.addLeds<WS2812, PIN_LED, GRB>(leds, NUM_LEDS);
}
/* After the program in setup() runs, it runs the program in loop()
The loop() function is an infinite loop in which the program runs repeatedly
在setup()函数中的程序执行完后，会接着执行loop()函数中的程序
loop()函数是一个死循环，其中的程序会不断的重复运行
*/
void loop() {
switch (led_status) {
case 0:
leds[0] = CHSV(led_ih, 255, 255);
break;
case 1:
leds[0] = CRGB::Red;
break;
case 2:
leds[0] = CRGB::Green;
break;
case 3:
leds[0] = CRGB::Blue;
break;
default:
break;
}
FastLED.show();
led_ih++;
delay(15);
if (!digitalRead(PIN_BUTTON)) {
delay(5);
if (!digitalRead(PIN_BUTTON)) {
led_status++;
if (led_status > 3) led_status = 0;
while (!digitalRead(PIN_BUTTON))
;
USBSerial.print("LED status updated: ");
USBSerial.println(led_status_string[led_status]);
}
}
}
```
