　card2で5秒間のwavファイルを録音してみる。

```text
kinneko@ti3070:~$ arecord -c 2 -t wav -d 5 test.wav
Warning: Some sources (like microphones) may produce inaudiable results
with 8-bit sampling. Use '-f' argument to increase resolution
e.g. '-f S16_LE'.
Recording WAVE 'test.wav' : Unsigned 8 bit, Rate 8000 Hz, Stereo
```

　ワーニングが出ている。データソースのフォーマットを指定せよということらしい。

　ファイルはできている。

```text
kinneko@ti3070:~$ ls -alh test.wav
-rw-r--r-- 1 kinneko kinneko 79K Apr  6 07:46 test.wav
kinneko@ti3070:~$ file test.wav
test.wav: RIFF (little-endian) data, WAVE audio, Microsoft PCM, 8 bit, stereo 8000 Hz
```

　-cはカード番号の指定ではなく、チャンネル数の指定ようだ。--helpとmanで解説している中身が違うのは困る。

　CD品質だと、-f S16_LE -c2 -r44100と同等ということなので、-f cdとかにしたらいいのかな？ マイクはモノラルっぽいけど。データ量を考えると-c1とかのがいいかな？

```text
kinneko@ti3070:~$ arecord -c 2 -t wav -d 5 -f cd test.wav
Recording WAVE 'test.wav' : Signed 16 bit Little Endian, Rate 44100 Hz, Stereo
kinneko@ti3070:~$ file test.wav
test.wav: RIFF (little-endian) data, WAVE audio, Microsoft PCM, 16 bit, stereo 44100 Hz
```

　-f cdでワーニングはおさまった。

```text
kinneko@ti3070:~$ arecord -c 1 -t wav -d 5 -f cd test.wav
Recording WAVE 'test.wav' : Signed 16 bit Little Endian, Rate 44100 Hz, Stereo
kinneko@ti3070:~$ file test.wav
test.wav: RIFF (little-endian) data, WAVE audio, Microsoft PCM, 16 bit, stereo 44100 Hz
```

　-c 1でやっても出力ファイルはステレオだな。後ろの-f cdで設定がオーバーライドされたのかも。

　-f cdをやめて、-f S16_LE -r44100にしてやり直すとモノラルになった。

```text
kinneko@ti3070:~$ arecord -c1 -f S16_LE -r44100 -t wav -d 5  test.wav
Recording WAVE 'test.wav' : Signed 16 bit Little Endian, Rate 44100 Hz, Mono
kinneko@ti3070:~$ file test.wav
test.wav: RIFF (little-endian) data, WAVE audio, Microsoft PCM, 16 bit, mono 44100 Hz
```

　でも、キャプチャデバイスの指定ができてないな... たぶんファイルは無音だろう。

　manのほうにあるデバイス指定のオプションである-Dは、by NAMEで設定せよってことだけど、どれを名前に入れたらいいのかわかんないな...

　試しに、デバイス指定しないで、イヤホン入れてマイクの音を流してテストしてみる。

　音は出てない。やっぱ、デバイス指定しないとダメっぽい。

```text
kinneko@ti3070:~$ arecord -c1 -f S16_LE -r44100 | aplay -c1 -f S16_LE -r44100
Recording WAVE 'stdin' : Signed 16 bit Little Endian, Rate 44100 Hz, Mono
Playing WAVE 'stdin' : Signed 16 bit Little Endian, Rate 44100 Hz, Mono
^CAborted by signal Interrupt...
Aborted by signal Interrupt...
aplay: pcm_write:2127: write error: Interrupted system callarecord: pcm_read:2221:
read error: Interrupted system call
```

　-Dは、plughw:2,0のように設定するのが正しいらしい。やってみる。

　前より少し大きいファイルができた。無音だとサイズが79kだったので、録音はできている模様。

```text
kinneko@ti3070:~$ arecord -D plughw:2,0 -c1 -f S16_LE -r44100 -t wav -d 5  test.wav
Recording WAVE 'test.wav' : Signed 16 bit Little Endian, Rate 44100 Hz, Mono
```

```text
kinneko@ti3070:~$ ls -alh test.wav
-rw-r--r-- 1 kinneko kinneko 431K Apr  6 08:10 test.wav
```
