　"VOICEVOX.Installer.0.14.6.Linux.sh"が落ちてくる。そーだよな、debで一発じゃないよなぁ... w

　中身はこんな感じ。

```bash
#!/usr/bin/env bash

## ファイルの内容
# このファイルはLinux用のVOICEVOXインストールスクリプトです。
# 実行権限を与えてからこのファイルをダブルクリックするか、後述の方法を使ってターミナルで実行してください。

## ダブルクリックでインストールを実行する方法
# 1. このファイルを閉じる
# 2. ローンチ左上の「ファイル」→「設定」→「動作」→「実行可能なテキストファイル」を「どうするか確認する」にする
# 3. ファイルを右クリック→「プロパティ」→「アクセス権」→「プログラムとして実行可能」にチェックを入れる
# 4. ファイルをタブルクリックする

## ターミナルでインストールを実行する
# 1. ターミナルを起動する
# 2. 次のように入力して実行する
#    chmod +x [ファイル名].sh
#    ./[ファイル名].sh

set -euo pipefail

if ! command -v curl &>/dev/null; then
cat <<'EOS'
* curl コマンドが見つかりません。

以下のコマンドを実行してください。

Ubuntu/Debian:
sudo apt install curl

CentOS/Fedora:
sudo dnf install curl
もしくは
sudo yum install curl
EOS
sleep 365d
exit 1
fi

curl -fsSL https://raw.githubusercontent.com/VOICEVOX/voicevox/0.14.6/build/installer_linux.sh >tmp_voicevox_installer.sh
VERSION=0.14.6 NAME=linux-nvidia-appimage bash tmp_voicevox_installer.sh
rm tmp_voicevox_installer.sh
```

　pipefailが設定されているのは、シェルスクリプトの実行途中でエラーが出たら、あとは実行しないという設定。あとは、curlが入っていないとインストールする。

　installer_linux.shを落として来て、tmp_voicevox_installer.shと名前を付けて保存して、VERSIONとNAMEを与えてtmp_voicevox_installer.shを実行して、最後にtmp_voicevox_installer.shを削除している。

　つまり実体であるinstaller_linux.shを起動しているというわけだ。落としてみる。

　Linux amd64アーキテクチャ向けは、x64という名前になっている。今回の環境はCUDAが使えるので、whlは対応のものを使う。

　ダウンローダ：download-linux-x64

　動的ライブラリ：voicevox_core-linux-x64-gpu-0.14.3.zip

　Python wheel：voicevox_core-0.14.3+cuda-cp38-abi3-linux_x86_64.whl

　落とすのはこの３つ。

> https://github.com/VOICEVOX/voicevox_core/releases/download/0.14.3/download-linux-x64<br>
> <https://github.com/VOICEVOX/voicevox_core/releases/download/0.14.3/voicevox_core-linux-x64-gpu-0.14.3.zip>

　ダウンローダーというやつはシェルスクリプトで、実行権限を与えて実行したらいいということのようだ。解説はこちら。

> voicevox_core/download.md at main · VOICEVOX/voicevox_core · GitHub<br>
> <https://github.com/VOICEVOX/voicevox_core/blob/main/docs/downloads/download.md>

　ダウンローダーのスクリプトには、デフォルトのCPU版と、DirectML版、CUDA版のそれぞれのオプションを渡して実行する。CUDA版のダウンロードをさせるのはこんな感じ。

　download --device cuda
