　テストにあるwidget_test.dartがエラーになって、ビルドを止めているので、こちらも修正する。

　Flutterの静的解析ツール（lint）が、Widgetのコンストラクタにkeyパラメータを追加しろと言っている。keyパラメータは、Flutterのウィジェットツリー内でウィジェットを一意に識別するために使用される。一般的に、キーオブジェクトを使用することで、ウィジェットが動的に変更されたときに正しく再構築されることを保証する。

　ほかのワーニングは、コンストラクタの呼び出しにconstキーワードを使用することを推奨しているから出ている模様。エラーではないのでビルドは通るけどね。

![](/2023-06-22/6106699-20.png)

　とりあえず、こんな感じで。

　MyAppにStatelessWidgetを貼って、中身はMaterialAppにして、Scaffoldを貼って、その中にAppBar作ってtitleを貼って、bodyの中に子要素としてCenter配置でstyle指定したTextを貼るという感じ。

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  MyApp({Key? key}) : super(key: key); // コンストラクタにkeyパラメータを追加
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold( // Scaffoldウィジェットを追加
        appBar: AppBar(
          title: const Text('Flutterサンプル'), // タイトルバーのテキスト
        ),
        body: Center(
          child: const Text(
            'Hello Flutter World!',
            style: TextStyle(fontSize: 32.0),
          ),
        ),
      )
    );
  }
```

　}

　ビルドしたapkファイルは、このへんに置かれている。

　% find ./build | grep "apk$"

　./build/app/outputs/flutter-apk/app-debug.apk
