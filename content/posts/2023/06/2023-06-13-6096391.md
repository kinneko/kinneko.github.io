　ということで、UD-CO2Sの出力値は信頼できない気がするのだけど、これまでの記事で、パーツは揃ったので、UD-CO2Sの出力を７セグ表示してみることにする。(6/4)

　UD-CO2SをRaspiに接続して、Pythonでpyserialを使って値を取得し、それを７セグに表示する。これで、とりあえずNT金沢に展示できるものが１つできる。

　コードはこんな感じ。使っている７セグでは、小数点が表示できないので、四捨五入で丸めて整数にしている。

```
pi@pi:~ $ cat co2.py
import serial, time, tm1637
ser = serial.Serial('/dev/ttyACM0', 9600)
ser.write("STA\r\n".encode())
time.sleep(0.1)
tm = tm1637.TM1637(clk=3, dio=2)
tm.brightness(0)
while True:
data = ser.readline().decode().strip()
if data.startswith('CO2='):
data = data.replace('CO2=', '')
values = data.split(',')
co2 = int(values[0])
hum = int(round(float(values[1].replace('HUM=', ''))))
tmp = int(round(float(values[2].replace('TMP=', ''))))
print(f'CO2濃度: {co2}, 温度: {tmp}, 湿度: {hum}')
tm.scroll("CO2 {}ppm".format(str(co2)), delay=400)
tm.temperature(tmp)
time.sleep(3.0)
tm.scroll(f'HUM {hum}', delay=400)
```

　まぁ、あっさり動くわなぁ...

　応答にゴミが入ると、７セグコントローラーとの通信が切れてしまうけど、エラーハンドリングは入れていない。

　保存して、実行テスト。当たり前だけど、普通に動く。

```
pi@pi:~ $ vi co2.py
pi@pi:~ $ python co2.py
CO2濃度: 1047, 温度: 26, 湿度: 51
CO2濃度: 1047, 温度: 26, 湿度: 51
```

　自動起動に設定して有効化する。

```
pi@pi:~ $ sudo vi /etc/systemd/system/co2.service
[Unit]
Description=UD-CO2S
After=network.target
[Service]
ExecStart=/usr/bin/python /home/pi/co2.py
WorkingDirectory=/home/pi
SyslogIdentifier=co2
StandardOutput=inherit
StandardError=inherit
Restart=always
User=pi
[Install]
WantedBy=multi-user.target
```
