　しょうがないので、Android Studioを起動して、SDK Managerを開くことにする。

　Android Studioを起動する。Documentsフォルダへのアクセス権限を要求されるので、許可する。

　まだ足りないのねぇ...

　sdkmanagerでcmdline-toolsを入れろと言っている。

　Android StudioのPrefereces... (設定)を開いて、Appearance & Behaver > System Settings > Android SDK > SDK Tooles タブを開く。

![](/2023-06-05/6055647-17.png)

　ここに「Android SDK Command-line Tools (latest)」があるので、チェックを入れる。

![](/2023-06-05/6055647-18.png)

　OKボタンを押すと、ダイアログが出る。こちらもOKを押す。

![](/2023-06-05/6055647-19.png)

　SDK Compornent Installerが起動してインストールを行う。

![](/2023-06-05/6055647-20.png)

　終わったので、Finishボタンを押す。

![](/2023-06-05/6055647-21.png)

　Xcode以外は問題なくなった。

　flutterコマンドの設定情報は、~/.config/flutter/settingsに書かれている(2系になる前は、~/.flutter_settingsだったらしい)。デフォルトでは、何もない。

~~~text
% ls ~/.config/flutter/settings
ls: /Users/kinneko/.config/flutter/settings: No such file or directory
~~~

　flutter configコマンドを実行してみても、実行内容の指定がないとファイルは作成されなかった。

~~~text
% flutter config
(snip)

No settings have been configured.
(snip)
~~~
