　VS Codeって、だいぶ前にインストールした記憶があるのだけど、M1になってからは入れていなかった。ちょっとアプリを１つ作る用事が出てきたので入れる。

　本家サイトはこちら。

> Visual Studio Code - Code Editing. Redefined<br>
> <https://code.visualstudio.com/>

![](/2023-06-07/6011005-01.png)

　macOS版は、ユニバーサルバイナリ版しかないみたい。ダウンロードはStableとInsidersの２種類が選べる。普通にStableをダウンロードする。

![](/2023-06-07/6011005-02.png)

　４月に出た、Version 1.78が最新版らしい。

> <https://code.visualstudio.com/sha/download?build=stable&os=darwin-universal>

![](/2023-06-07/6011005-03.png)

　ブラウザ画面は、「Getting Started」に移動する。インストール方法についての解説はとくになさそう。

> Documentation for Visual Studio Code<br>
> <https://code.visualstudio.com/docs/?dv=osx>

![](/2023-06-07/6011005-04.png)

　アーカイブを展開すると、500MBほどのバイナリが出てくる。バージョンは、1.78.2になっている。そのままアプリケーションフォルダにコピーする。

![](/2023-06-07/6011005-05.png)

　ん？AppStore署名はされていないのね。ちょっとキモい。

![](/2023-06-07/6011005-06.png)

　起動すると、Welcomeのタブが表示されている。

![](/2023-06-07/6011005-07.png)

　右下にポップアップが出てくる。OSのロケール表示を読み取って日本語表示には言語パックが必要と言ってきている。

![](/2023-06-07/6011005-08.png)

　表示言語を 日本語 に変更するには言語パックをインストールします。 (Install language pack to change the display language to Japanese.)

　とりあえず、日本語言語パックを入れることにする。

　日本語パックを入れるには、以前は「view」メニューから「Command Palette」を開く->「Configure Display Language」選択してクリック->「Install additional languages」をクリック->画面左側に表示されるインストール可能な言語パッケージから「Japanese Language Pack for Visual Studio Code」をクリック(表示が多すぎるので検索もできる)->再起動というプロセスが必要だったようだ。楽になってるのはいいことだね。

　「インストールして再起動 (Install and Restart)」ボタンを押すと、再起動して、タブが「ようこそ」になった。

　このタブには、設定のチューニングや、簡単な使い方のチュートリアルが表示される。「次のセクション」を押すと、詳細がいろいろ出てくる。

![](/2023-06-07/6011005-09.png)

　通常の起動画面はこちら。下のほうにある「起動時にウェルカムページを表示」のチェックを外しておくと、この画面は出なくなる。

![](/2023-06-07/6011005-10.png)

　「VS Codeを開始する」では、「好きな外観を選択します」、「他のデバイスとの同期」、「すべてにアクセスするためのショートカット」、「すべての言語の豊富なサポート」、「コードを開く」の５つの項目がある。

　日本語の言語パックをインストールして再起動した時点で、「好きな外観を選択します」については完了してしまっているようで、チェックが付いた状態になっている。

![](/2023-06-07/6011005-11.png)

　「好きな外観を選択します」の項目をクリックすると、設定を変更することができる。一般的なダークモダンで進めることにする。白背景のが読みやすいかな... ダメそうなら後で変更する。なぜか、「すべてにアクセスするためのショートカット」に勝手にチェックが追加されている。そういう品質のプログラムなのね...

![](/2023-06-07/6011005-12.png)

　「他のデバイスとの同期」は、VS Codeの設定情報を他の端末と共通化するために、クラウド経由で設定を同期するもののようだ。

　Settings Syncという機能名のようだ。

> Settings Sync in Visual Studio Code<br>
> <https://code.visualstudio.com/docs/editor/settings-sync>

　同期できるのは、「設定」、「キーボードショートカット」、「ユーザースニペット」、「拡張機能」、「UIの状態」の５項目。

　同期には、GitHubアカウントかMicrosoftアカウントを使用する。同期するには、どちらかのアカウントを用意して、ここで登録する必要がある。

　良し悪しな機能だ。とりあえず使わないので設定しない。

![](/2023-06-07/6011005-13.png)

　「すべてにアクセスするためのショートカット」は、キーボードショートカットをカスタマイズできるという説明。普段慣れている環境があれば、そのショートカットを設定して同じように使うのもいいけれど、あんまりカスタムすると過適応で慣れの問題が出てしまうので、そのまま使う。

![](/2023-06-07/6011005-14.png)

　「すべての言語の豊富なサポート」は、言語設定は最初に終わってしまったので、通常は関係ないだろう。

![](/2023-06-07/6011005-15.png)

　「コードを開く」は、既存のプロジェクトを取り込んで開始するように書かれている。新規なので、今回は関係ない。

![](/2023-06-07/6011005-16.png)

　項目を開くだけでチェックがついて、５つの項目を終了した。なんもしてないけどw

　「次のセクション」を押すと「基礎の学習」画面に移動する。またチェックが勝手に少し進んでいる。

![](/2023-06-07/6011005-17.png)

　「編集スキルを再定義する」では、エディタープレイグラウンドを開くように促される。エディタープレイグラウンドでは、VS Codeの代表的な機能10個を試すことができる。

![](/2023-06-07/6011005-18.png)

　エディタープレイグラウンドは、ヘルプメニューからいつでも開くことができる。

![](/2023-06-07/6011005-19.png)

　内容は翻訳されていないのね。パス。

![](/2023-06-07/6011005-20.png)

　「便利な組み込みターミナル」では、シェル操作を行うための「ターミナルパネル」を開く。

![](/2023-06-07/6011005-21.png)

　「ターミナルパネルの表示」ボタンを押すと、画面の下側にシェルが起動する。ここから進行中のビルドのログを見たり、コマンド操作を行うことができる。とりあえず、今すぐには不要なので閉じておく。

![](/2023-06-07/6011005-22.png)

　「無限の拡張性」では、VS Codeの拡張機能の説明をしている。インストール後は、Flutterの開発環境を整備するので、拡張機能を使うことになる。日本語言語パックも拡張機能の１つである。

![](/2023-06-07/6011005-23.png)

　「おすすめの拡張機能の参照」ボタンを押すと、@recommendedで検索された拡張機能の一覧表示される。ここでは、とりあえず何も入れない。

![](/2023-06-07/6011005-24.png)

　@recommendedを削除すると、インストール済みの拡張機能が表示される。

![](/2023-06-07/6011005-25.png)

　開いた拡張機能メニューは、ウインドウ右上の「プライマリサイドバーを切り替える」で閉じることができる。

![](/2023-06-07/6011005-26.png)

　閉じると、アイコンが白くなくなる。

![](/2023-06-07/6011005-27.png)

　「設定の調整」。あとはザッと見てゆくだけでw

![](/2023-06-07/6011005-28.png)

　「ゆったり学習する」

![](/2023-06-07/6011005-29.png)

　「次のセクション」を押すと「生産性の向上」画面に移動する。

![](/2023-06-07/6011005-30.png)

　「左右に並べて編集」

![](/2023-06-07/6011005-31.png)

　「Gitでコードを追跡する」

![](/2023-06-07/6011005-32.png)

　「ショートカットのカスタマイズ」

![](/2023-06-07/6011005-33.png)

　すべてにチェックがつくと、右側に表示されていたチュートリアルは表示されななくなる。左側の「チュートリアルを開く...」から開くことができる。

![](/2023-06-07/6011005-34.png)

　コマンドパレットからも開くことができる。

![](/2023-06-07/6011005-35.png)

　というわけで、インストールは終わった。
