　UD-CO2Sで、macOSからのシリアルの動作は確認ができて、Raspiでの７セグモジュールの制御がPythonからできたので、次はUD-CO2SをRaspiからPython経由でデータ取得してみる。（8/4)

　コードはこんな感じかな...

```
import serial, time
ser = serial.Serial('/dev/ttyACM0', 9600)
ser.write("STA\r\n".encode())
time.sleep(0.1)
while True: # データ読み取りのループ
data = ser.readline().decode().strip()  # シリアルポートからデータを読み取り、文字列にデコードしてトリミング
if data.startswith('CO2='):
# データを抽出
data = data.replace('CO2=', '')
values = data.split(',')
co2 = float(values[0])
hum = float(values[1].replace('HUM=', ''))
tmp = float(values[2].replace('TMP=', ''))
# 取得したデータの表示
print(f'CO2濃度: {co2}')
print(f'湿度: {hum}')
print(f'温度: {tmp}')
```

　別の温度湿度センサでは、23.1度、58%。

　温度は装置内から少し高め。そして温度に釣られて湿度も少し低め。これはしょうがない。

　この値でも、LEDは緑点灯だ。1000ppm越えているのに緑？ それダメじゃね？

![](/2023-06-12/6098759-03.png)

　マニュアルを確認してみる。いやぁ、基準は1500ですか。それはないでしょう... 厚生労働省の定めた基準に従っていないってことは、これは家庭用であって、事業所や学校では使ってはいけないやつなのね。
