　UD-CO2Sは、数値の表示を行うには、Windows用のアプリが必要で多少面倒だ。単体で表示部を追加するには、USBホストがついたマシンがいる。(6/3)

　ESP32-S3でUSBホストしてしまうという手もあるのだけど、簡単にホスト側のインターフェイスが出ている基板が必要になるので、それも少しめんどくさい。なにより、今からの手配ではNT金沢には間に合わない。しょうがないので、あまり使う機会のない初代Raspiとかを使ってみることにする。

　取れる値はCO2ppm、温度、湿度と、数値だけ出ればいいので、ESP32で使っている４桁7セグ付きのコントローラーTM1637がいっぱいあるので、それを使いたい。

![](/2023-06-09/6094525-01.png)

![](/2023-06-09/6094525-02.png)

　しかし、Raspiから簡単に使えるのだろうか？

　Python3向けのこいつが使えそう。

> depklyon/raspberrypi-tm1637: A fork of Micropython ported to Python 3 library for quad 7-segment LED display modules based on TM1637 LED driver<br>
> <https://github.com/depklyon/raspberrypi-tm1637>

　Cのライブラリを作った人もいる。

> Pierre Brial / TM1637 C library for Raspberry Pi · GitLab<br>
> <https://framagit.org/harlock/tm1637-c-library-for-raspberry-pi>

　どのみち、シリアルを読まないといけないので、Python実装のが楽かな。

　制御の目処がついたので、とりあえず7セグの表示を試す。

　接続は、I2C風の接続なので、こんな配線になりそう。


　再度、電源を入れて、pythonのコンソールで点灯試験をしてみる。

```
pi@pi:~ $ python
Python 3.9.2 (default, Mar 12 2021, 04:06:34)
[GCC 10.2.1 20210110] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import tm1637
>>> tm = tm1637.TM1637(clk=3, dio=2)
```

　全点灯のテスト。うまくいった。

```
>>> tm.write([127, 255, 127, 127])
```

![](/2023-06-09/6094525-11.png)

　7セグで表示できる英語を出す。

```
>>> tm.show('help')
```

![](/2023-06-09/6094525-12.png)

　温度表示に数字２桁と°Cを表示する。-9〜99まで表示できる。

```
>>> tm.temperature(24)
```

![](/2023-06-09/6094525-13.png)

　LEDが明るすぎるので、輝度調整をやってみる。エラーは出ないので、値は何でも書けるようだけど、見た目では、0-4の五段階のようだ。

```
>>> tm.brightness(0)
>>> tm.brightness(1)
>>> tm.brightness(2)
>>> tm.brightness(3)
>>> tm.brightness(4)
>>> tm.brightness(5)
```

　スクロールもできるようなので、試してみる。これはうまくいった。

```
>>> tm.scroll("helpmeplease", delay=250)
```

　スペースが入るとうまくいかない。おまけに、I2Cの信号がおかしくなってしまって、初期化しないと使えない。スペースできないのはつらいな。

```
>>> tm.scroll("help me please", delay=250)
```

　アンダースコアもダメ。スペースがダメなら、これが使えてほしいところ。変換テーブルに持っていないだけだと思うけど。

```
>>> tm.scroll("help_me_plase", delay=250)
```

　ハイフンつなぎは大丈夫だった。

```
>>> tm.scroll("help-me-plase", delay=250)
```

　数字も大丈夫。

```
>>> tm.scroll("01010101", delay=250)
```

　スペースできるな... 前にダメだったのは文字数だったのかな？

```
>>> tm.scroll("CO2 2400", delay=250)
>>> tm.scroll("HUM 50", delay=250)
>>> tm.scroll("TMP 24", delay=250)
```

　これも大丈夫だった。=やカンマやピリオドは扱えない。

```
>>> tm.scroll("CO2 494 HUM 50 TMP 26", delay=250)
```

　スクロールするより、順番に表示したほうがいいかも。値が上書きなので、前の文字が上書きされない部分は消えない。４桁というのは最初からわかっているで、スペースを入れて4文字にして右寄せにするといいかも。

```
import time
tm.brightness(1)
time.sleep(2)
tm.show(' CO2')
time.sleep(2)
tm.show(' 954')
time.sleep(2)
tm.show(' HUM')
time.sleep(2)
tm.show('  50')
time.sleep(2)
tm.temperature(24)
```

　TM1637コントローラーを使った７セグLEDモジュールをPythonで制御できることはわかった。
