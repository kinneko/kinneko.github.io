　M5の面々が金沢に来るというので、もう日がないけど、ネタに何か作ろうと思い立った。いや、特にネタはないのだけど。(4/28)

　Stack-chanが流行りなのだけど、残念ながら、M5Stackは持っていない。あるのはStickシリーズばかり。StickC、StickC Plus、StickVしかない。しょうがないので、Stick-chanを作ることにしよう。

　すでに、StickC-chanはすでにいるみたい。まぁいいか。

> スティックCチャン(StickC-chan) feat. toio core cube | ProtoPedia<br>
> <https://protopedia.net/prototype/3238>

　StickC Plusは、ハード的には「ボタン x 2、ブザー、IR送信機、赤色LED、マイクロフォン、6軸IMU、RTC、PMIC（バッテリ管理IC）」とGrove互換コネクタがある。スピーカーがないな。しゃべらせるのは不利が。Groveをスピーカーに使ってしまうのはもったいないし。分岐するのも電気が足りなくなりそう。Groveの圧電ブザーはあるのだけど、歌わせるのは無理かな？ StickVならスピーカーあるけど、ネットワークにつながらない。それはそれで使い手がない。

　サーボを動かすのは面倒なので、ゼンマイロボにくくって歩かせる。LCDは頭表示に使う。歌を歌いながら歩く的な実装になるか。お散歩Stick-chanか、鼻歌Srick-chanといったところ。

　加速度センサあるから、歩いてないと歌わないとかはできそう。歩くと表情が明るくなり、鼻歌歌って、止まると寝てしまうような感じがいいかな。内蔵電池を外してしまってないんだけど... 外につけるとデカくなるね...

　ぜんまい歩行は、前に100均でハロウィンのオモチャがあったような。ぜんまいの巻き上げ用の羽は3Dプリントして付けたい。

　手持ちのStickC Plusは、バッテリ外してしまったし、電源はどうしても別に必要ね。前に買ったバッテリ関係が使えるかな。PowerCってなんで売らなくなってしまったのかな...

　PAM8303を使ったM5StickC Speaker Hatがあるのか。それが使えるかな。色が合ってないのがよろしくないけど。金沢店に在庫２個ある。820円。

> M5StickC Speaker Hat M5STACK-SPK-HAT M5Stack製<br>
> <https://www.marutsu.co.jp/pc/i/1556456/>

　サンプルスケッチ。

> M5StickC/SPEAKER.ino at master · m5stack/M5StickC<br>
> <https://github.com/m5stack/M5StickC/blob/master/examples/Hat/SPEAKER/SPEAKER.ino>

　買ってきた。袋入りの新しいバージョンとケース入りの古いバージョンが在庫していた。ケース入りのほうを購入。袋入りのほうはモジュールと両面テープ的なものが入っていた。

　C Plusも発掘した。

![](/2023-05-01/5826795-01.png)

　ケースのクッションの切り込みが合ってないとか、センターにおさまってないとか、梱包の適当さが中華感ある。

![](/2023-05-01/5826795-02.png)

![](/2023-05-01/5826795-03.png)

　C PlusにHatをつけるには、ここで接続する形になる。固定されていないので、ちょっと不安定。Hatを最初からやる設計なら、もう少し考えたらいいのに。塞がってしまう穴はLEDだったかな？

![](/2023-05-01/5826795-04.png)

![](/2023-05-01/5826795-05.png)

　ついでに、100均でゼンマイおもちゃを探したが、これ１つしかなかった。クワガタか... 恐竜のブロックのやつがあったらよかったのに。使うかどうかわからないけど、とりあえず確保。

![](/2023-05-01/5826795-06.png)

　なんか、見かけないオモチャもあったので確保した。緑のやつ、２種類あったのだけど、どっちもバーコード同じだぞ？

![](/2023-05-01/5826795-07.png)

　スピーカーが来たので、音を出してみる。通電すると、なんかチリチリ音がするんだけど... ノイズがひどいと言われているのはこれかな？

　ボードマネージャで、EPS32が1.0.6とえらく古かったので、最新版2.0.8にする。新しすぎかな？

![](/2023-05-01/5826795-08.png)

　サンプルスケッチからHat->SPEAKERを選ぶ。ボードとシリアルポートを指定して書き込む。

![](/2023-05-01/5826795-09.png)

　なんか、液晶にsperkerと表示されて、ピーっと音が鳴った。とりあえず動作しているみたいだけど、それで動きは合ってる？ と、いまさらスケッチの中身を見る。

　m5stack_startup_music[]ってなんだよ。そんなもの入れてないよ。液晶にspeakerと表示されるのは合ってる。しかし、電源を入れ直すと、ノイズみたいな表示になって、音も出なかった。これ、ダメじゃね？

　m5stack_startup_musicはこれらしい。追加する。

> <https://github.com/m5stack/M5Stack/blob/7e863fb9934bcb25f15afa720e9299b8a8e9a8fd/examples/Basics/FactoryTest/startup_music.c>

![](/2023-05-01/5826795-10.png)

　しかし、書いても反応なし... バッテリ無理やり外したのは、PMIC的にマズかったのかね。

　と、スピーカーハットを外して通電すると、speakerと表示されて、ブザーがピーピーと鳴っている。なんだそれ。スピーカーハットの不良ですかね？

　C Plus用の標準ライブラリが古かった。関連の依存ライブラリを含めてアップデートする。0.0.8になった。でも、それで書いてもダメね。

![](/2023-05-01/5826795-11.png)

　しょうがないので、DACを直接ドライブしてビープ音を出してみる。

```cpp
const int speaker_pin = 26;
void setup() {
  pinMode(speaker_pin, OUTPUT);
}
void loop() {
  tone(speaker_pin, 1000); // 1000Hzの周波数でビープ音を鳴らす
  delay(500); // 500ミリ秒待機する
  noTone(speaker_pin); // ビープ音を停止する
  delay(500); // 500ミリ秒待機する
}
```

　プチ音しかしないですね... dacWrite()を使っても同じ結果。

　前にバッテリ外したときに、メスピンのボード側の接続壊したかなと思って一度開けてみたのだけど、Plusは構造が変わって、そういう破損は起きないようになっていたのだった。

![](/2023-05-01/5826795-12.png)

　あー、なんかやる気なくしたわ...

　マルツにはもう１つ在庫あったのだけど、ガス代使って買いに行く元気はないんだなぁ...
