　招待コードが発行されていた。とりあえず、FANBOXの支援者には、blueskyをやってみたい人はいないみたい(すでにやっている数名の方は除く)。(5/25)

　Kくんがやってみたいと言っていたので、招待コードを発行することにした。

　「1 invite code available」をクリックする。

![](/2023-05-31/6029552-01.png)

　こんな画面になる。前にはなかったという「You'll receive one invite code every two weeks. 」という表示が追加されているようだ。今後は、二週間ごとに１つ発行されるのかな？ (コード見えているけど、これは使ってしまったので問題ない)

![](/2023-05-31/6029552-02.png)

　総当たり攻撃防止のために招待コードの桁数が増えたと聞いたのだけど、自分が招待してもらった時と桁数は変わらない。

　コードをコピーして、twitter DMで連絡する。Doneボタンを押すと画面が戻る。だが減らない！なんで？

![](/2023-05-31/6029552-03.png)

　無限おかわり？ なわけないな。消費されないと減らないのかな？

　登録したと連絡があったので、Blueskyを開く。こんなメッセージが来ていた。招待コードを出した人は自動でフォローされるので、いらなければUnfollowせよってことかな？ Dismissのほうは、発行した人じゃなければ拒否できるってこと？？？

![](/2023-05-31/6029552-04.png)

　この表示はしばらくしたら出なくなった。どっちのボタンも押していない。問題なければ、なにもしないのが正解っぽい。

　招待コードは消尽されたようなので、カウントが０になった。

![](/2023-05-31/6029552-05.png)

　支援者の方で、招待コードがほしい人がいましたら、次は二週間後になります。
