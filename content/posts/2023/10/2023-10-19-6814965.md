　Pi3/RaspiOS、8G microSD、外付け500G HDDでpi-gen環境を再構築したので、apt-cacher-ngは使わなかったけど、何度もやるならapt-cacher-ngを立てておいたほうがいいよね。

　インストール手順などは前回のやつで。

> apt-cacher-ngを入れる<br>
> <https://kinneko.fanbox.cc/posts/6791430>

　キャッシュされるパッケージはデフォルトでは、/var/cache/apt-cacher-ng/に保存される。こいつをシンボリックリンク化することもできるが、あんまりよくない対処なので、設定方法があるかどうか調べる。

　設定は、/etc/apt-cacher-ng/acng.confにある。中を見るとすごくいろいろ設定がある。

　デフォルトで有効な設定はこんな感じ。ポート番号などは設定されていないがデフォルト値(3142)で有効になっている。

```text
kinneko@raspberrypi:~ $ grep -v -e '^$' -e '^#' /etc/apt-cacher-ng/acng.conf
CacheDir: /var/cache/apt-cacher-ng
LogDir: /var/log/apt-cacher-ng
SupportDir: /usr/lib/apt-cacher-ng
Remap-debrep: file:deb_mirror*.gz /debian ; file:backends_debian # Debian Archives
Remap-uburep: file:ubuntu_mirrors /ubuntu ; file:backends_ubuntu # Ubuntu Archives
Remap-klxrep: file:kali_mirrors /kali ; file:backends_kali # Kali Linux Archives
Remap-cygwin: file:cygwin_mirrors /cygwin # ; file:backends_cygwin # incomplete, please create this file or specify preferred mirrors here
Remap-sfnet:  file:sfnet_mirrors # ; file:backends_sfnet # incomplete, please create this file or specify preferred mirrors here
Remap-alxrep: file:archlx_mirrors /archlinux # ; file:backend_archlx # Arch Linux

ReportPage: acng-report.html
ExThreshold: 4
LocalDirs: acng-doc /usr/share/doc/apt-cacher-ng
```

　Remapはデフォルトにおまかせするとして、キャッシュディレクトリの指定、ログディレクトリの指定、ポート設定、リポートページの設定などができる。

　デフォルトで、ExThresholdが4日というのは知らなかった。4日参照されないと削除されてしまう。そんなに頻繁にパッケージのダウンロードしないよ。これは不便。

　無効化できないかと、0にしたら動作しないかというとそうではなくて、即刻削除になるだけのようだ。-1とかは受け付けない模様。なので、999999とかにしておかないといけない感じ。

```text
kinneko@raspberrypi:~ $ sudo vi /etc/apt-cacher-ng/acng.conf
CacheDir: /mnt/apt-cacher-ng/cache
LogDir: /mnt/apt-cacher-ng/log
Port:3142
ReportPage: acng-report.html
ExThreshold: 999999
```

　リポートページとかあるの知らなかったわ。AdminAuth:でIDとパスワードを設定できるようだ。

　なんかわからんけど、たぶんキャッシュやログに指定したディレクトリは自分で作らないという感じね。

```text
kinneko@raspberrypi:~ $ sudo mkdir /mnt/apt-cacher-ng
kinneko@raspberrypi:~ $ sudo chown apt-cacher-ng:apt-cacher-ng /mnt/apt-cacher-ng
```

　もとのディレクトリ/var/cache/apt-cacher-ngは、パーミッションがdrwxr-sr-xになっているので合わせておく。グループのアカウントがディレクトリなどを作ったら所有権も/mnt/apt-cacher-ng同じになるという感じの設定。

```text
kinneko@raspberrypi:~ $ sudo chmod 2755 /mnt/apt-cacher-ng
kinneko@raspberrypi:~ $ ls -al /mnt/|grep apt-cacher-ng
drwxr-sr-x  2 apt-cacher-ng apt-cacher-ng  4096 Oct 11 02:38 apt-cacher-ng
```
