---

　AWS Builder ID は、AWS でビルドするすべての人のための新しい個人プロファイルです。コードを書くソフトウェア開発者、課題に取り組んでいる学生、情報をモデル化するデータアナリスト、またはキャンペーンを構築するマーケターのいずれであっても、AWS Builder ID はあなたのためのものです。

　AWS Builder ID は、Amazon CodeCatalystを含む AWS のツールとビルダー サービスへのアクセスを提供します

　Amazon CodeWhisperer . 仕事、学校、または他の組織間を移動しても、AWS Builder ID を保持できます。時間の経過とともに、特定の興味やスキルレベルなどの追加情報を提供して、AWS エクスペリエンスを調整できるようになります。

　AWS Builder ID は、すでに所有している、または作成したい AWS アカウントを補完します。AWS アカウントは、作成した AWS リソースのコンテナとして機能し、それらのリソースにセキュリティ境界を提供しますが、AWS Builder ID はあなたを個人として表します。AWS Builder ID を使用するツールとサービスのサインアッププロセスの一環として、AWS Builder ID にサインアップできます。

　AWS Builder ID は無料です。AWS アカウントで消費した AWS リソースに対してのみお支払いいただきます。料金の詳細については、AWS の料金表を参照してください。

　. AWS Builder ID が AWS アカウントを補完する方法の詳細については、AWS Builder ID とその他の AWS 認証情報 を参照してください。
