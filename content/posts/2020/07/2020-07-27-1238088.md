　ググったら、シェルスクリプトだけでデータが取れるという情報があった。どっさりパッケージを入れるより、コマンドとシェルで取れたほうがいいに決まっている。


> Using bash and gatttool to get readings from Xiaomi Mijia LYWSD03MMC Temperature Humidity sensor – d0wn<br>
> <http://www.d0wn.com/using-bash-and-gatttool-to-get-readings-from-xiaomi-mijia-lywsd03mmc-temperature-humidity-sensor/>


　掲載しているシェルスクリプトはそのまま使えなかったので、少し手直ししてみる。


　gatttoolが出力奪っていてタレ流しなので、タイムアウトで処理するしかない感じなのね。応答時間が不定なので、12秒くらいは待たないと情報が安定して取れない感じだ。


　ついでに、MACを引数渡しにして、電池残量も出るようにした。


> Gist<br>
> <https://gist.github.com/kinneko/30f51ab42fce2f22ea369b8f388f60ea>


```text
ubuntu@ubuntu:~$ cat LYWSD03MMC.sh
#!/bin/bash
```


```text
if [ -z "$1" ]; then
echo "Usage: $0 [Bluetooth MAC Addr]"
exit 1
else
MAC=$1
fi
```


```text
#bt=$(timeout 15 gatttool -b A4:C1:38:8E:1D:8E --char-write-req --handle='0x0038' --value="0100" --listen)
bt=$(timeout 12 gatttool -b $MAC --char-write-req --handle='0x0038' --value="0100" --listen|awk -F 'value: ' '{print $2}')
if [ -z "$bt" ]; then
echo "The reading failed"
else
temphexa=$(echo $bt | awk -F ' ' '{print $2$1}'| tr [:lower:] [:upper:] )
temperature100=$(echo "ibase=16; $temphexa" | bc)
temperature=`echo "scale=2;$temperature100/100"|bc`
echo "temperature=$temperature"
humhexa=$(echo $bt | awk -F ' ' '{print $3}'| tr [:lower:] [:upper:])
humidity=$(echo "ibase=16; $humhexa" | bc)
echo "humidity=$humidity"
batteryhexa=$(echo $bt | awk -F ' ' '{print $5$4}'| tr [:lower:] [:upper:] )
battery1000=$(echo "ibase=16; $batteryhexa" | bc)
battery=`echo "scale=3;$battery1000/1000"|bc`
echo "voltage=$battery"
fi
```


　実行すると、こんな感じ。


```text
ubuntu@ubuntu:~$ ./LYWSD03MMC.sh A4:C1:38:8E:1D:8E
temperature=25.49
humidity=64
voltage=2.978
```


　ただ、このスクリプトは、気温がマイナスの場合には対応できない。金沢では、気温がマイナスになることは稀なので放置する。


　小一時間動かしてみたけど、12秒のタイムアウトでデータが取れないことはなかった。11秒では取れないことがあるので微妙なところだ。


　データは取れるようになった。このくらいでクラウドに投げるのはアホらしいので、RRDtoolとcactiで可視化する... と思ったけど、cactiはphpだったのでやめた。


　re:dashとかMetabaseとかかなと思ったけど、なんかそこまででもないなということで、普通にテキストに吐いてgnuplotでグラフにするだけにした。


　スクリプトを少し書き換えて、タイムスタンプを吐くようにして、カンマ区切りで１レコードが一行になるように変更した。

　すぐに確認メールが来るのかと思ったら、なかなかやってこない。手動確認なのかな？それとも+入りのメールアドレスなのではじかれたのかな？


　確認メールが来ないので、制限事項を読む。「1チャネルあたり1日3,000件までデーターを登録できます。平均すると28.8秒に1回のペースです。 」いやぁ、これは無理かな。もうちょっと細かくデータを取りたい。

> <https://ambidata.io/refs/spec/>
