　検査をするには、そのための検査治具を作らなくてはいけない。

　Digisparkのピンをはんだ付けすると頒布物としてはアレだしめんどくさい。マックエイトの「コンスルーコネクタ」を使って差し込むだけで動作するコンタクトを作る。

　コンスルーコネクタについては、別に記事にしているので、そちらを見てほしい。

> ボゴピン代わりに使えるコンスルーコネクタ<br>
> <https://kinneko.fanbox.cc/posts/1134576>

　なんかのあまりのピンヘッダにコンスルーコネクタをはんだ付けする。

　作ったコンタクトピンをミニブレッドボードに取り付ける。

![](/2020-07-02/wWWDJ2s06sCQwU14WkBXywsR.png)

　動作を確認するピンにLEDを取り付けて、ジャンパで配線する。

　Digisparkでは、ピン穴の並びが直角になっているので、ブレッドボードでは電源とGNDへ配線する場合は、ジャンパ配線になる。

![](/2020-07-02/oNVyCvK4DIxPKBrOB1t1SbkK.png)

　P0からP4にLEDを接続してあるので、順番に点灯するスケッチを書く。

　Digisparkのピンマップはこんな感じ。

![](/2020-07-02/xJqy3uz5hf9vGK8e3JJoDS6T.png)

<https://www.deviantart.com/mortenaaserud/art/Digispark-Attiny85-Pinout-738150591>

　スケッチは、P0-P5にLEDを接続して点滅するだけのものを用意する。書き込みの確認を兼ねてDigisparkに書き込んでおく。

　P1は、基板上のLEDにつながっている。そのLEDで動作確認できるけれど、一応配線を行った。

　P5は中華クローンではリセットに割り当てられたままになっているので、マイコンのフューズの設定変更をしないと使えない。ここを有効にするとセルフリセットがかかってしまうので、今回はP5のテストはしないようにしてコメントアウトして動作確認はパスする。

```cpp
// Digisprk test program
void setup() {
// initialize the digital pin as an output and LOW.
pinMode(0, OUTPUT); digitalWrite(0, LOW); //LED on Model B
pinMode(1, OUTPUT); digitalWrite(1, LOW); //LED on Model A or Pro
pinMode(2, OUTPUT); digitalWrite(2, LOW);
pinMode(3, OUTPUT); digitalWrite(3, LOW); // USB+
pinMode(4, OUTPUT); digitalWrite(4, LOW); // USB-
//pinMode(5, OUTPUT); digitalWrite(5, LOW); // Reset
}
void loop() {
digitalWrite(0, HIGH); delay(10); // wait for 0.01 second
digitalWrite(0, LOW); delay(1000);
digitalWrite(1, HIGH); delay(10);
digitalWrite(1, LOW);delay(1000);
digitalWrite(2, HIGH); delay(10);
digitalWrite(2, LOW); delay(1000);
digitalWrite(3, HIGH); delay(10);
digitalWrite(3, LOW);delay(1000);
digitalWrite(4, HIGH); delay(10);
digitalWrite(4, LOW);delay(1000);
//digitalWrite(5, HIGH); delay(100);
//digitalWrite(5, LOW); delay(100);
}
```

　当たり前のことだけど、スケッチ書き込み時にGNDへの配線をしてあると、うまく書き込みができなかった。単体で書き込み後に、ブレッドボード上で配線し、ジャンパをGNDに挿し込む。

　LEDが順番に点灯するのを確認し、しばらく動かして、レギュレータなどに過熱がないかも確認する。中華クローンなので、レギュレータはきちんとしたメーカー品が使われていることは期待できないので、この確認は絶対に必要だ。問題なければ、確認完了。

![](/2020-07-02/HXA9AdJtdD3ogxaxFp9y4byd.png)

　あとは、スリープレス・ドングルのスケッチを書き込んで、LEDとPCのマウスドライバで動きを確認し、カットしたスミチューブ(熱収縮チューブ)をかぶせて、ヒートガンで縮める。

　スミチューブをかぶせるのは、通電時に点灯するLEDが眩しい、基板を直接手でさわるのは電気的にも基板の塩分ダメージなどでも避けたい、基板だけPCに挿さっていると怪しい、などの理由がある。

　スリープレス・ドングルとしての動作確認だけなら、ここまでやる必要はないのだけど、本もいっしょに頒布しているので、一応ピンの動作確認もやっている。

　そういえば、ブートローダーが1.6 -> 2.2になっているので、今回のロット用に何か目印があるといい。ホログラムのQCシールがいっぱいあるので、スリープレス・ドングルの裏に貼っておこうかな(と、思っていたがすっかり忘れていた)。
