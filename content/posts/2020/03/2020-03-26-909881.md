　Vistaくらいの古いCoreMのマシンが転がっていたので、ちょっとコンソールくらいの使い道はないかと思ってインストールしてみる気になった。


　ターゲットは、FM/V BIBLO NF50U。


http://www.fmworld.net/product/hard/pcpm0701/biblo_loox/nf/lineup/#cat02


　スペックはこんな感じ。2007年１月のモデル。


　HDDは100GBが積まれているのだけど、転がっていた80GBに差し替えてある。分解してみて、PATA 2.5インチだったので、あーその頃のモデルかという感じ。再生して使うにはちょっと古すぎるかも。


![](/2020-03-26/UK5hknxCylDMYLOX9hrhOzVS.png)


　Ubuntuくらい入るのじゃないかと思ったら、すでにRAMサイズで人権がなかった。


![](/2020-03-26/axZxmZfat2mjFVXZlliFQQx2.png)


　軽量Linuxディストリビューションでまだ開発されているものとしては、"Linux Mint"あたりが候補になるだろう。でも、なんか普通の選択すぎて面白味がない。


　Main Page - Linux Mint


https://www.linuxmint.com/


　Chrome OSもいいかなと思ったのだけど、Chromium OSを入れるのは、ちょっといろいろと遠い感じがする。


　cloudreadyみたいなチューニング済みのプロダクトを使う方法もあるけど、RAM 2Gでも重いようだ。


　CloudReady Home Edition Free Download — Neverware


https://www.neverware.com/freedownload


　そういえば、Raspi3ってこのくらいスペックだな...


　確か、Raspbianにx86版もあったような...


　探してみる。


　あった。


　Raspberry Pi Desktop - Raspberry Pi


https://www.raspberrypi.org/downloads/raspberry-pi-desktop/


![](/2020-03-26/L8PxGv69ylNdt2q9fx0ekxPM.png)


　Debianベースに、Raspberry Pi Desktop環境を用意したものという感じ。特に推奨スペックとかは書いていない。Raspbianとも違うという位置づけか。


　isoイメージでダウンロードされるようなので、落としてUSBメモリに焼いて書き込んで見る。サイズは3.13GBの"2020-02-12-rpd-x86-buster.iso"がダウンロードされた。USBメモリにddで書き込む。


　$ sudo dd if=./2020-02-12-rpd-x86-buster.iso of=/dev/rdisk2 bs=500m


　PCに差し込んで電源を入れ、USBメモリから起動しないと思ったら、BIOSの設定で起動ドライブから除外されていた。


　設定を直して起動。でも認識しない。


　こんなところで時間を食っても仕方がない。使う予定のないDVD-Rメディアは余っているので、焼いて起動した。


　F12を押して起動してBIOSの起動ドライブ選択モードに入る。F12を押すのは一度でよく、押し続けているとBIOS画面でエラーになってしまう。光学メディアを選んで起動する。


　インストール方法には、いくつか選択肢が出てくるが、Graphical Installerを選ぶ。インストーラーは普通のDebianのもののようだ。ただ、日本語を選択しても、以降が日本語表示で進むわけではない。インストールドライブを選んで継続する。GRUBをHDDに書き込む。全行程で40分ほどかかった。インストール後は、自動的に再起動した。


　起動にはやや時間がかかる。インストール時にユーザー設定などはなかったのだけど、そこはRaspbianを踏襲していて、ユーザーpiでログインしている。


　初期設定用のツール"piwiz"が起動しているので、Nextボタンを押す。


　piwizは、設定を終わると二度と自動起動しないが、削除されるわけではなく"sudo -i piwiz"で起動することができる。


![](/2020-03-26/RlPjofaUXsre8KNJcPI2WcHl.png)


　国設定を行う。日本に設定してNextボタンを押す。


![](/2020-03-26/LAsGqQ5CdfQwijV3j8sjHFDj.png)


![](/2020-03-26/X8AC1atQKr9DX5kx1fGps941.png)


![](/2020-03-26/2bKQFrYjOY4zzub2rMMTH2mL.png)


　piユーザーのパスワードを設定する。ここでは面倒なので空欄のままNextボタンを押した。


![](/2020-03-26/FcbxPTXpvnvRCrrOmKFpzFBb.png)


　WiFiの設定を行う。しかし、いつまでたってもAPが表示されない。有線LANでネットワーク接続はできているので、細かい設定は後にしてNextボタンを押す。


![](/2020-03-26/pL7xAUgvOqkLXUlrQ7tAX7hO.png)


　ソフトウエアアップデートを行う。Nextボタンを押すと、自動でアップデートチェックを行い、必要なものはアップデートされる。


![](/2020-03-26/CrjHKPNq8nALx100AVgfpZKW.png)


![](/2020-03-26/dgWX1KhARwReM8SReoLx3rME.png)


![](/2020-03-26/2i7uZShCIKwtPx7q1IyW7eZI.png)


　言語設定で、fcitx-frontend-qt4, fcitx-ui-classic, fcitx-module-x11, fcitx-frontend-gtk2, fcitx-frontend-gtk3, fcitx-mozc, fcitx-bin, fcitx-modulesあたりの依存関係でエラーになっている。fcitxまわりが、1:4.2.9.6が必要なのだが、1:4.2.9.6-5が入っていることが原因のようだ。日本語入力にfcitx-mozcを設定されているのだが、どうもうまく動かないようだ。調査は後回しにしてOKボタンで先に進む。


![](/2020-03-26/AJK6NspruGSt9cdMmHgJGYvs.png)


　設定を終了してRestartボタンで再起動を行う。


![](/2020-03-26/E0mYneqweuKdIpQ4Q8LYYANT.png)


　全体の動作は軽い。ブラウザを起動すると少し時間はかかるが、動いてしまえば軽い。Libra Officeも入っているので、文書作成や表計算には問題なさそうだ。


　起動後にメニューは日本語になっている。ただし、先のパッケージコンフリクトによって日本語入力ができない。


　無線設定を再度やってみる。piwizでの設定と同様にWiFiをONにはできるけど、APをスキャンできない感じ。無線コントローラーはIntelのが入っているのだけど、どうもダメだな。


![](/2020-03-26/aC0CrAeLhAuvkgL85ufKiB47.png)


　有線LANでネット接続し、terminalを起動してパッケージアップデートをして再起動する。firmware-nonfreeがアップデートしていた。少し期待したが、ダメだった。


　Fnキーで設定するバックライトや音量の制御はできている。タッチパッドもクリックも問題なく動く。キーボードも105JPを自動認識している。液晶バックライトも一定時間経過後にオフになる。


　スリープ対応はしていないようだ。メニューにも出てこない。パネルを閉じると電源ランプが点滅になるので、何らかのスリープモードには入っているようだ。


　スクリーンキャプチャは、scrotがプリインストールで入っているので、PrtScボタンでキャプチャできる。


　学校教育用のプログラミング教育用のマシンって、このくらいのスペックで足りるのじゃなかろうか。


　今後、日常的に使うとしたら、日本語入力ができないのが問題だ。日本語フォントは入っているようだが、ひがらなやカタカナのバランスがとても悪いので入れ替える必要があるだろう。動かなかった無線LANも動作するようにしたいところだ。
