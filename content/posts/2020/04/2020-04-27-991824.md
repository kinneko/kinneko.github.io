　新型コロナでは、酸素飽和度(SpO2)の低下に要注意ということなので、測ってみようかなと思った金曜日。

> コロナ｢突然重症化した人｣の驚くべき共通点<br>
> <https://toyokeizai.net/articles/-/346423>

　『肺炎では患者は通常、胸部の不快感や呼吸時の痛みなどの呼吸障害を発症する。しかし、新型コロナ肺炎の場合、当初患者は酸素量が低下しても、息切れを感じない。しかしその間、驚くほど酸素濃度が低下し、中等度から重度の肺炎（胸部X線写真で見られる）になっていく。正常な酸素飽和度は94％から100％だが、私が見た患者の中には、酸素飽和度が50％にまで低下していた例もある。』

　SpO2を測定する代表的な方法はパルスオキシメーターを使う方法。原理を開発したのは日本の方だそうだけど、その発明者の方がつい先日亡くなっている。

> パルスオキシメーターを発明、青柳卓雄さん死去：朝日新聞デジタル<br>
> <https://www.asahi.com/articles/ASN4R74VJN4RULBJ00D.html>

![](/2020-04-27/991824-Bw3C7Zfc.png)

　基本的には、２つの波長の光で酸素と結合したヘモグロビンと、酸素を手放したヘモグロビンの比を確認することで、血中に十分に酸素が供給されているか調べるという方法。

　パルスオキシメーター、売っているのだけど、国内で流通しているものは高価すぎる。

　Amazonでは安いものも並んでいるのだけど、ほとんど国内在庫なしの中華通販業者なのでAliexpressで頼むのと変わらない。そして、のきなみ売り切れ。なんでだ？

　しょうがないので、Aliexpressで３種類ほど見繕ってオーダーしてみた。しかし、このご時世なので、いつ届くかわからない。

![](/2020-04-27/991824-Qoq4T323.png)

　SpO2センサMAX30100も基板実装済みのものが$2くらいで安いのだけど、精度とかよくわかんないな、ということでパス。Arduinoで使えるライブラリはあるそうな。

　調べてゆくと、どうもM5Stackで出しているセンサが安い感じ。ケースに入って扱いやすそう。スイッチサイエンスでさっそくオーダーする。836円＋送料200円。でも金曜オーダーなのでいつ届くやら。

> M5Stack用心拍センサユニット - スイッチサイエンス<br>
> <https://www.switch-science.com/catalog/5695/>

![](/2020-04-27/991824-IiQE7u9q.png)

　たしか、マルツは店頭在庫がチェックできたな、と思って調べる。マルツ金沢には在庫があるようだ。スイッチサイエンスで買う必要なかったか...

　睡眠時無呼吸症候群の検査の時に、このセンサを一晩指にくっつけて寝た記憶があるのだけど、SpO2って透過で測るのじゃなかったか？ 反射でもいいのか？という疑問はある。

　翌日の土曜、さっそく買いに行く。在庫は１つでした。コロナのおかげで、電子工作コーナーはお休みになっている。営業時間も短縮中。マスクして入り口でアルコール消毒しないと入店できない。開いててよかった！

![](/2020-04-27/991824-ZhfSEhLK.png)

　マイコンはNodeMCU-32S、表示は７セグでやろうかなと思っていたのだけど、ちょっとグラフっぽいのも出るといいなということで、M5Stick Cも買う。お天気いいので、日中は庭仕事することにして夜からさわりはじめる。

![](/2020-04-27/991824-QsStRDEa.png)

　しかし、いきなりアウェイな事実が判明。

> HIROSHI SASAKI on Twitter: "m5stackにheart rate(max30100)で脈波を測定。5ー6秒で波形が安定してくる。 m5stickCでは動かなかった。<br>
> <https://twitter.com/hirosh/status/1209057503767453697>

![](/2020-04-27/991824-qvyUO91h.png)

　マヂですか... オラの1800円を返せ... (買う前にリサーチしろよw)

　でも、まぁ、自分でやってみる。接続はGROVEコネクタモドキなので、センサに付属のケーブルで接続するだけ。ピン配置は本体にもモジュールにも明記されているので、わかりやすい。M5Stick CがGND-5V-G32-G33、HeartRate UNITがSCL-SDA-5V-GND。

![](/2020-04-27/991824-alTVkYhX.png)

![](/2020-04-27/991824-SUffbOCt.png)

　M5StickVはさわったことあるのだけど、あちらはMiaxPyで使っていた。普通のM5シリーズをさわるのは初めてだ。これ、どうやってプログラム書くの？

　ドキュメントを見ると、普通にArduinoの開発環境でいい感じだ。

　サンプルコードはこのあたりにある。とりあえず、これをそのまま試す。

> M5StickC/MAX30100_RawData.ino at master · m5stack/M5StickC<br>
> <https://github.com/m5stack/M5StickC/blob/master/examples/Unit/HEART/MAX30100_RawData/MAX30100_RawData.ino>

　/*

　pls install MAX30100lib by library manager first

　addr: https://github.com/oxullo/Arduino-MAX30100

　*/

```
#include <M5StickC.h>
#include <Wire.h>
#include "MAX30100.h"
```

```
// Sampling is tightly related to the dynamic range of the ADC.
// refer to the datasheet for further info
#define SAMPLING_RATE                       MAX30100_SAMPRATE_100HZ
```

```
// The LEDs currents must be set to a level that avoids clipping and maximises the
// dynamic range
#define IR_LED_CURRENT                      MAX30100_LED_CURR_50MA
#define RED_LED_CURRENT                     MAX30100_LED_CURR_27_1MA
```

```
// The pulse width of the LEDs driving determines the resolution of
// the ADC (which is a Sigma-Delta).
// set HIGHRES_MODE to true only when setting PULSE_WIDTH to MAX30100_SPC_PW_1600US_16BITS
#define PULSE_WIDTH                         MAX30100_SPC_PW_1600US_16BITS
#define HIGHRES_MODE                        true
```

```
// Instantiate a MAX30100 sensor class
MAX30100 sensor;
```

```
void setup()
{
M5.begin();
M5.Lcd.setRotation(3);
```

　//M5.Lcd.setTextColor(WHITE);

```
M5.Lcd.setTextSize(3);
M5.Lcd.print("MAX30100");
```

　//M5.Lcd.clear(BLACK);

```
M5.Lcd.setCursor(0, 40);
Serial.begin(115200);
```

```
Serial.print("Initializing MAX30100..");
```

```
// Initialize the sensor
// Failures are generally due to an improper I2C wiring, missing power supply
// or wrong target chip
if (!sensor.begin()) {
Serial.println("FAILED");
for(;;);
} else {
Serial.println("SUCCESS");
}
```

```
// Set up the wanted parameters
sensor.setMode(MAX30100_MODE_SPO2_HR);
sensor.setLedsCurrent(IR_LED_CURRENT, RED_LED_CURRENT);
sensor.setLedsPulseWidth(PULSE_WIDTH);
sensor.setSamplingRate(SAMPLING_RATE);
sensor.setHighresModeEnabled(HIGHRES_MODE);
}
```

```
void loop()
{
uint16_t ir, red;
```

```
sensor.update();
```

```
while (sensor.getRawValues(&ir, &red)) {
Serial.print(ir);
Serial.print('\t');
Serial.println(red);
}
}
```

　コンパイルエラーになつた。"AX30100.h: No such file or directory"。

　ライブラリは別入れか... (アタリマエ)

　ソースにはGithubから落とすように書かれているけど、とりあえずライブラリを検索してみると２つ出てきた。

![](/2020-04-27/991824-CZMH6Hd9.png)

　最初のは、オリジナルが https://github.com/kontakt/MAX30100 らしいのでダメだわ。

　もう１つの方が、ソースで指定されている https://github.com/oxullo/Arduino-MAX30100 のようだ。インストールする。

![](/2020-04-27/991824-dMvXRxPX.png)

　んで、サンプルのソースを書き換える必要がある。ライブラリは、#include "MAX30100_PulseOximeter.h"で読み込む必要がある。

　ビルドできたので書き込む。指をあてるとシリアルにはこんなデータが出ている。

![](/2020-04-27/991824-ytiPlqov.png)

　しばらくすると安定してくる。
