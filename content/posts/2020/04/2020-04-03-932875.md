結論から書くと、あんまりうまくはいかなかったので、これ以下は読む必要はない。

　もうちょっとpandocを使ってみよう。docxから文書フォーマットを抽出する機能も持っているようなので使ってみる。

　いきなりエラーになった。

```
$ pandoc --print-default-data-file word.docx > templ.docx
```

　Could not find data file word.docx

　ファイル名がreference.docxじゃないとダメ？ それとも、リダイレクト先が同じファイル名じゃないとダメ？ 実験してみる。

```
$ pandoc --print-default-data-file reference.docx > reference.docx
$ ls -al reference.docx*
```

　-rw-r--r--@ 1 kinneko  staff  10151  4  1 15:17 reference.docx

　-rw-r--r--@ 1 kinneko  staff  48294  4  1 15:17 reference.docx.org

```
$ pandoc --print-default-data-file word.docx > reference.docx
```

　Could not find data file word.docx

```
$ pandoc --print-default-data-file reference.docx > word.docx
$ ls -al word.docx reference.docx.org
```

　-rw-r--r--@ 1 kinneko  staff  48294  4  1 15:17 reference.docx.org

　-rw-r--r--  1 kinneko  staff  10151  4  1 15:20 word.docx

　最初の結果からは当たり前なんだけど、どうやら参照元がreference.docxでないとダメなようだ。

　変換のリファレンスはdotxでなくてもいいのだろうか？ mdファイルは前のものと同じ。

```
$ pandoc md_data.md --reference-doc=word.docx -o word_format.docx
```

　こんどはPagesで開いて、PDFにしてから画像に変換。

　もとの文書は、枠線ありのキッチリとフォーマットされた文書なんだけど、その構造は捨てられてしまっている感じだ。文書のスタイル情報だけを残しているのかもしれない。

　ヘッダが有効にならないのは、改行が必要だったようだ。

　------------------------------------------------------------------------------

　## ヘッダ1.1

　記号付きリスト

　* リスト１

　* リスト2

　インデントはスペース４つ

　さらにインデント

　### ヘッダ1.1.1

　順序付きリスト

　1. リスト１

　2. リスト2
